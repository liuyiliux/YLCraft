创建一张 16:9 的艺术性角色身份板，使用参考图像中的同一角色作为唯一主体。 纯白色 / 柔和的米白色背景。无环境、无道具、无标志、无水印。
设计方向
这不是标准角色设定表，而是一张兼具艺术呈现与制作参考价值的角色身份板。目标是在保持艺术感的同时，清楚锁定角色的脸、发型、服装、身体比例、姿势语言与情绪范围，使其适合未来图像与视频生成中的角色一致性参考。避免网格、蓝图设计、目录布局和重复的转场展示。
重要布局规则
不要重叠任何角色图像。
不要出现区块标题，画面可以使用标注文字，但不得遮挡或影响画面。
每个视角必须有清晰的分离和呼吸空间。
保持所有身体、肖像、轮廓和细节研究的视觉区分。
无裁剪面部、无隐藏肢体、无堆叠人物、无合并姿势。
区块设置（左侧占四分之一宽度，右侧占四分之三宽度）
左侧上方｜角色 ID 区
仅包含：定位、简介、视觉标签
简要说明、排版简约
左侧下方｜面部识别区
紧贴下边缘放置一个较大的头部肖像，正面清楚展示面部形状、五官比例、发型、皮肤特征与眼神气质等。
这是脸部识别锚点。
右侧上方区域，高度占比三分之二
左侧为标准视图区：展示正面、侧面、背面全身像。
要求视角干净、中性、标准化，重点锁定身体比例、服装结构、背影与侧影轮廓。
右侧为姿态动作区：
展示 4 个小型辅助姿态研究，包括坐姿、蹲姿、俯视角度、仰视角度。
所有姿态必须保持同一角色身份、同一服装、同一身体比例。
右侧下方区域｜表情与细节研究区
左侧为表情研究区：
紧凑展示 3 个正面小头像，呈现符合角色设定的明显情绪变化，如开心、愤怒、悲伤等，不能破坏脸部一致性。
右侧为细节研究区域：
紧凑展示 3-5 个关键特征，如头发纹理、领口、军牌等局部识别细节，并简单标注。
文本设计
添加一个时尚的角色 ID 块。 使用中文、保持简约、大胆且艺术导向。 仅在有帮助的地方使用小型手写风格标签。 允许使用细微的编辑箭头和标注标记，但保持简约和优雅。
风格
要尽可能地保留参考图中角色的相关信息，维持统一的风格以及相关的细节。 最终图像应感觉像一张艺术性的角色身份板，重在帮助 AI 模型理解角色的面部、轮廓、服装、姿势和情感范围。
