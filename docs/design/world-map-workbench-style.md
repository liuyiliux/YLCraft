# 样式规范 · 世界地图工作台（`/world-map`）

> 落地前的样式契约：改任何视觉前先改本文，再改代码（文档为源、代码为果）。
> 上游依据：`.codebuddy/prototypes/world-map-workbench/req/ui-context.md`（原型令牌）、
> `req/REQUIREMENTS.md`（需求真相）、`req/prototype-design.md`（交互对齐）。
> 与原型不一致处，一律以本文为准（本文记录的是**真实前端**可落地的规格）。

---

## 1. 整体风格（Design Read）

**气质定位**：专业创作者的**编辑工作台**，不是插画展示页。关键词：克制、秩序、可预期。

- **秩序感来自分层**：左「控制」— 中「内容（画布）」— 右「详情」，三栏职责不互换；
  派生能力（AI 成图）一律降权到抽屉，视觉权重永远低于正典编辑区。
- **低干扰中性底 + 单一高对比主色**：页面冷灰底，只有 antd 蓝承载主行动与选中态；
  区域色板仅用于「区分数据」，不用于强调。
- **不做**：底图铺满叠标记、AI 区抢戏、emoji 当图标、AI 紫/霓虹渐变、玻璃拟态、重阴影、装饰性插画。

**与原型的关系**：原型用 CSS 模拟 antd 外观，本规范把它的令牌落到真实 antd v5 + Leaflet 上；
原型的 `#fafafa` 卡片底统一改为令牌 `--p-surface`，`#d9d9d9` 边框统一改为 `--p-border`。

## 2. 信息架构与骨架尺寸

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 56px（固定）                                              │
├────────────┬───────────────────────────────┬─────────────────┤
│ 左：图层    │ 中：地图画布（flex:1）          │ 右：选中详情      │
│ 260px      │                               │ 320px           │
└────────────┴───────────────────────────────┴─────────────────┘
                  抽屉 400px（视觉稿）/ 模态（导出、版本）
```

| 区域 | 宽度 | 说明 |
|---|---|---|
| 顶栏 | 高 56px，水平内边距 16px | 地图选择 + 标题 + 主行动（保存）+ 次行动（视觉稿/导出/版本/从地点实体生成/新建） |
| 左图层面板 | 260px，内边距 12px | 位面 Segmented → 图层开关 → 类型筛选 → 图例 → 统计 |
| 中画布 | `flex:1`，最小宽 0 | 圆角 8px，`1px` 边框，背景 `--p-surface`，高 520px（可随视口增长） |
| 右详情面板 | 320px，内边距 12px | 未选中态 → 据点详情 → 编辑表单 |
| 视觉稿抽屉 | 400px | 右滑出，遮罩 `rgba(0,0,0,.45)` |
| 模态 | 640px（导出/版本） | 居中，圆角 8px |

**层级与权重**：正典编辑（保存、据点编辑）> 导航（切换地图/位面）> 派生动作（生成视觉稿、设为底图）。
同一行内主行动只能有一个实心蓝按钮，其余为描边或文字按钮。

## 3. 色彩

### 3.1 令牌（`light-dark()` 承载，实现落在 `worldmap.css` 的 `:root`）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--p-bg` | `#f5f7fa` | `#14161a` | 页面底 |
| `--p-surface` | `#ffffff` | `#1e2227` | 卡片/面板/画布表面 |
| `--p-fg` | `#1f2329` | `#e8e9ec` | 正文/标题 |
| `--p-muted` | `#5f6b7a` | `#9aa3b0` | 次级文字/说明 |
| `--p-border` | `#e2e6ec` | `#333a43` | 分割线/描边 |
| `--p-accent` | `#1677ff` | `#3c8cff` | 主色（CTA/选中/聚焦） |
| `--p-danger` | `#ff4d4f` | `#ff7a7c` | 删除/危险 |
| `--p-success` | `#52c41a` | `#6bd04d` | 成功/已关联实体 |
| `--p-warn` | `#fa8c16` | `#ffa940` | 游离标记/需处理 |

**区域/节点区分色**沿用存量 `REGION_HUES`（保证与既有视觉资产一致）：
`#1677ff` `#52c41a` `#fa8c16` `#eb2f96` `#722ed1` `#13c2c2`，按区域顺序取模复用。

**语义映射（antd 组件）**：`ConfigProvider` 的 `colorPrimary = var(--p-accent)`，
`colorError/Success/Warning` 对齐上表；`colorBgContainer = var(--p-surface)`，
`colorBorderSecondary = var(--p-border)`。禁止在组件里写死 hex（除区域色板与 Leaflet 内联样式）。

### 3.2 使用纪律

- 主色只出现在：主按钮、选中态、聚焦环、链接、据点图标底（按区域色）。
- `--p-warn` 只用于「游离标记/需关联实体」这类待处理状态，不用于装饰。
- 底图参考层固定 `opacity:.18`；设为底图后仍可一键关闭。
- 深色模式只换令牌，不改布局与透明度层级。

## 4. 字体与排版

- **字族**：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
  （与 antd 同栈，不引入标题字体——工具界面无需 display 型字体）。
- **等宽**（坐标、点位 JSON、版本号）：
  `ui-monospace, SFMono-Regular, "Cascadia Mono", Consolas, monospace`。

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H（卡片/抽屉标题） | 14 / 22 | 600 | 面板分区标题 |
| 正文 | 13 / 20 | 400 | 说明、列表项 |
| 次级 | 12 / 18 | 400 | 提示、单位、时间戳（色 `--p-muted`） |
| 微标 | 11 / 16 | 400 | Tag、图例、徽标数字 |
| 数据（坐标/计数） | 13 / 20 | 500 | 等宽，右对齐成列 |

数字（版本号、坐标、计数）统一等宽并右对齐，避免跳动；中文与数字间不加空格。

---

## 5. 间距与密度

- 基础网格 **4px**；控件高 **32px**（紧凑型）；圆角 **6px**（控件/卡片）、**8px**（画布/抽屉/模态）、**999px**（徽标/图例色点）。
- 面板内边距 12px，卡片内边距 12–16px，同组控件间距 8px，分组之间 16px。
- 阴影仅一层：`0 1px 2px rgba(0,0,0,.04)`（卡片）；浮层（抽屉/模态/下拉）用 `0 6px 16px rgba(0,0,0,.08)`。
- 分割线 `1px var(--p-border)`，不用加粗线或双线。

## 6. 关键组件规格

### 6.1 顶栏
- 高 56px，底边 `1px` 边框，背景 `--p-surface`（与页面底区分）。
- 左：地图选择 `Select`（宽 200）；标题 `Input`（宽 240，边框透明，hover 才显边框）。
- 右：主行动「保存」实心蓝（有未保存更改时带 `Badge` 圆点）；其余为次按钮。
- 按钮顺序固定：`保存 → 视觉稿 → 导出 → 版本 → 从地点实体生成 → 新建`。

### 6.2 图层面板（左）
- **位面 Segmented**：横向分段，激活段主色底 + 白字，宽满面板。
- **图层开关**：`Switch` + 图例色点 + 名称 + 右侧计数（`徽标`，等宽）。四项：据点/区域/路线/底图。
- **类型筛选**：`Select` 多选，placeholder「按类型筛选」。
- **图例**：色点 8px（`999px`）+ 12px 文字；区域色点与多边形同色。
- **统计**：底部 12px 次级文字，形如 `5 据点 · 1 区域 · 0 路线`。

### 6.3 画布（中）
- 圆角 8px、`1px` 边框、背景 `--p-surface`；`overflow:hidden`。
- **据点标记**：`divIcon`，胶囊标签（高 22px、圆角 12px、内边距 `3px 10px`、11px/600 白字），
  底色取区域色，1px 深色描边 + `0 1px 3px rgba(0,0,0,.25)`；不透明。
- **区域多边形**：填充 `opacity:.12` + 描边 1.5px，同区域色。
- **路线**：`#94a3b8`、2px；`kind=边界` 用 `4 4` 虚线。
- **底图**：`opacity:.18`（固定值，不可调）。
- 缩放控件放左上，`attributionControl` 关闭（保持干净）。

### 6.4 选中详情面板（右）
- 未选中：居中提示「点击地图上的据点查看详情并编辑」+ 12px 次级说明（说清去哪建第一个据点）。
- 已选中：名称（14/600）→ 类型/区域/坐标（等宽）→ 描述 → **来源实体**卡片（成功色标注已关联）
  → 证据锚点列表 → 关联章节/角色（可跳转）→ 底部「编辑 / 删除」。
- 游离标记（无 `entity_id`）：顶部 `--p-warn` 提示条「未关联地点实体（正典应在 world_entities）」+ 去关联入口。

### 6.5 视觉稿抽屉（400px）
- 分区：生成模式 Segmented → 后端/模型/尺寸 → **视觉基准** → **画风预设（AutoComplete）**
  → 参考图（历史成图网格 + 上传）→ 提示词覆盖 + AI 优化 → 生成按钮 → 多稿网格 + 最近成图。
- 每张稿：缩略图（1:1、圆角 6px）+ 标题 + 「设为底图 / 下载 / 删除」三个文字按钮。
- 顶部固定 `Alert`（info）：「成图是派生视觉资产，不影响地图数据」。
- **视觉基准**：已设置 → `Tag`（主色）+ 更换/清除；未设置 → 「选择视觉基准」次按钮。
  选择弹窗素材网格 `minmax(110px,1fr)`，选中 2px 主色描边。

### 6.6 导出 / 版本（模态）
- 导出：三段式（SVG / PNG / 点位 JSON），切换即换预览面板；JSON 预览等宽、可复制。
- 版本：列表（版本号 / 时间 / 操作者 / 变更摘要）+ 选两版「对比」→ 并排 diff（新增主色、删除危险色、修改警告色）。

### 6.7 通用控件
- 按钮：主（实心蓝白字）/ 次（白底 + `--p-border` 描边）/ 危险（红字红边）/ 文字按钮。高 32px，圆角 6px。
- 输入：高 32px，`placeholder` 用 `--p-muted`；聚焦 `2px` 主色环（见 §8）。
- Tag：11/16，圆角 4px；语义色：主色=进行中，成功=已关联，警告=待处理，默认=中性。
- Toast：`message` 默认配置（顶部居中、2s），成功/失败语义色，不放图标。

## 7. 图标

- **一律 Lucide 内联 SVG**（24×24 视口，`stroke-width:1.75`，`stroke:currentColor`，`fill:none`）。
- 尺寸：工具栏/按钮内 14px，面板标题前 14px，空态插画 32px。
- **禁止** emoji 当图标（含 ✅/⚠️/📍）；**禁止**第三方图标库与 PNG 图标。
- 语义映射：地图=`map`、保存=`save`、导出=`download`、版本=`history`、新建=`plus`、
  视觉稿=`image`、删除=`trash-2`、设为底图=`layers`、编辑=`pencil`、关联=`link`、证据=`quote`。

## 8. 交互与状态

| 状态 | 规格 |
|---|---|
| hover | 背景 `rgba(22,119,255,.06)`（列表项/卡片），按钮加深一档 |
| active/选中 | 2px 主色描边（卡片/缩略图）/ 主色底白字（Segmented） |
| focus-visible | `2px` 主色环 + `2px` 偏移，键盘可达；**不用** `outline:none` |
| disabled | 文字/描边 `opacity:.45`，不改色相；禁用原因放 `title` |
| loading | 按钮内 `Spin`（14px），禁止同时可点 |
| 拖拽据点 | 拖影 `opacity:.7`，落点吸附到整数坐标（0–100） |
| 空态 | 32px 图标 + 14/600 说明「为什么空」+ 12px「去哪做第一件事」+ 一个主行动按钮 |
| 错误 | 就近展示（字段下 / Toast），不说「出错了」，说清原因与下一步 |

- 动效：仅 `120–160ms`、`cubic-bezier(.4,0,.2,1)`；只允许 opacity / transform / 背景色过渡。
  禁止弹跳、缩放弹窗、长于 300ms 的动画。
- 深浅主题：右上角切换（工作台类默认提供），写入 `localStorage`，只换令牌不重排。

## 9. 可访问性与响应式

- 对比度 **WCAG AA**：正文 12:1、主按钮 4.6:1、次级 4.8:1（均达标）。
- 键盘：`Tab` 顺序 = 顶栏 → 左 → 中 → 右；抽屉/模态内焦点循环，`Esc` 关闭。
- 语义：面板用 `<section>` + 标题；图标按钮必带 `aria-label`/`title`。
- 断点：
  - `<1024px`：右侧详情面板改为抽屉（从右滑出，宽 340px）。
  - `<768px`：左侧图层面板可收起（汉堡按钮唤出，遮罩关闭），画布全宽、高降至 420px。
- 缩放：画布支持滚轮/控件缩放，不锁定 `user-scalable`。

## 10. 实施清单（按顺序开发）

1. **令牌落地**：新建 `frontend/src/components/world/worldmap.css`，定义 §3 令牌与 §5 基础变量；
   在 `WorldMapEditor` 引入，并用 `ConfigProvider`（局部）把主色/危险/成功/背景映射到 antd。
2. **骨架**：顶栏 56px + 三栏 260/320 + 画布圆角/边框/背景。
3. **组件替换**：`LayerPanel` / `DataPanel` / `NodeDetailPanel` / `VisualDrawer` /
   `BatchDrawer` / `ExportModal` / `VersionModal` 逐个去掉硬编码 hex，改引用令牌。
4. **画布细节**：`MapCanvas` 的据点胶囊、区域/路线样式、底图 `opacity:.18`。
5. **图标**：`@ant-design/icons` → Lucide 内联 SVG（按 §7 映射）。
6. **状态与空态**：focus 环、hover、空态文案与行动按钮、游离标记警告条。
7. **响应式与主题**：`ConfigProvider` 主题切换 + `<1024` / `<768` 断点。
8. **验收**：逐条对照本文 §2–§9 自检，并在 OpenSpec 任务里登记。
