# 参考分析 · Azgaar Fantasy-Map-Generator

> 调研对象：https://github.com/Azgaar/Fantasy-Map-Generator（5.9k★，活跃开发中）
> 受众与我们高度重合：奇幻小说作者、跑团 GM、地图制作者。
> 本文只提炼**对我们世界地图工作台有用**的部分；不照搬它的程序化生成（我们是结构化手绘地图，不做世界生成）。
> 信息来源：README + Wiki（User Interface 页）；clone 因网络受限未完成，细节以官方 Wiki 为准。

## 1. 架构启发：四层分离（README 明确的方向）

`世界数据与样式 → 生成器（模型）→ 编辑器（控制器）→ 渲染器（视图）`，
约束是**数据层不含渲染代码，渲染器不得修改世界数据**。

这与我们已定的纪律同构（`map_json` 是正典、画布/成图都是派生渲染），可直接引用它的表述
强化架构文档；也印证我们把 `WorldMapEditor`（状态）与 `components/world/*`（渲染+回调注入）
拆开的路线是对的。

## 2. 图层系统（Wiki User-Interface 页）

它的图层分三类，这个**分组思想**值得我们抄：

| Azgaar 分类 | 例子 | 对应我们 |
|---|---|---|
| 全图竞争层（互相遮盖、可调顺序与透明度） | Texture / Heightmap / Biomes | **底图**（我们只有一层，天然不冲突） |
| 半透明叠加层 | States / Cultures / Religion / Temperature | **区域**（势力淡晕 + 虚线疆界，已实现） |
| 开关层 | Rivers / Icons(burg) / Borders | **据点 / 路线**（已实现） |

其它可借鉴点（按优先级）：
1. **图层预设组合**（Political map / Physical map / Biomes map / Pure landmass…）——
   我们可做「视图预设」：政治视图（区域+据点+路线）、自然视图（底图+纹理）、纯结构（全关底图）。
2. **悬停 tooltip 显示要素信息**（高度/biome/城镇名+人口+编辑入口）——我们据点 Popup 已有。
3. **Ctrl+点击图层开关直达样式编辑器**——远期。
4. **图层显示顺序可拖拽**——远期（当前固定层级够用）。

## 3. 样式系统（对「小说地图感」价值最大）

- **12 个内置样式预设**：`default / ancient / gloom / pale / light / watercolor / clean /
  atlas / darkSeas / cyberpunk / night / monochrome`，可另存自定义预设。
  → 我们的「画风预设」目前**只影响生图提示词**；借鉴方向是把它升级为
  **画布样式主题 + 生图提示词双用**（选「水墨」= 画布变水墨滤镜 + 生图提示词带水墨）。
- **全局滤镜**：`Sepia / Dingy / Paper / Crumpled / Pencil / Blur / Turbulence / Tint`。
  → 我们可以用 CSS `filter` + 纸纹叠加低成本实现「做旧/水墨/羊皮纸」画布观感，
  不需要引入任何图形库。
- 透明度 / 裁剪（仅陆地/仅海洋）/ 虚线端点样式等控件 → 我们暂固定值，远期开放。

## 4. 标签与缩放（Wiki 未详述，结合其行为）

Azgaar 的标签是**分级 + 随缩放显隐**：海洋名沿曲线大间距排版、国家名大衬线、
城镇名小字，zoom 越高出现越多（LOD），避免一屏几十个标签互相打架。

→ 我们**立即可借鉴**：据点标签按 zoom LOD 显隐——zoom 低（看全图）时只显示
区域名（大衬线）与首府，zoom 高才显示全部据点标签。当前所有标签常显，据点多时会糊成一团。

## 5. 地图元素对照

| 元素 | Azgaar | 我们 | 结论 |
|---|---|---|---|
| 高度图/山脉 | 程序生成 + 梯田化/色带 | 不做（结构化手绘） | 不适用 |
| 河流 | 沿高度梯度程序生成 | 无 | 远期：装饰笔刷（手动画河） |
| 海岸线 | 程序生成 | 无海岸线概念 | 不适用（无海洋） |
| 国家边界 | 半透明淡晕 + 边界线 | 区域虚线疆界（已实现） | 已对齐 |
| 城镇图标/分级 | capital/城市/镇 不同大小 | 按 kind 分形图标（已实现） | 可加「首府」强调 |
| 比例尺/指北针/图例 | 有 | 罗盘 + 坐标读数 + 图例（已实现） | 可加比例尺 |
| 导出 | SVG/PNG/GeoJSON/JSON | SVG/PNG/点位 JSON（已实现） | 已对齐 |

## 6. 落地清单（按优先级）

1. **标签 LOD**：zoom 阈值以下隐藏据点标签、保留区域名——防拥挤，成本低。
2. **画布样式主题**：画风预设从「生图提示词」升级为「画布主题 + 生图提示词」双用
   （纸张/水墨/夜晚三套 CSS 变量组合起步）。
3. **做旧滤镜**：CSS `filter: sepia()/contrast()` + 纸纹叠加，挂到主题上。
4. **视图预设**：政治 / 自然 / 纯结构 三组图层组合快捷切换。
5. 远期：装饰笔刷（山/树/河流符号层）、图层顺序拖拽、比例尺、首府标记。
