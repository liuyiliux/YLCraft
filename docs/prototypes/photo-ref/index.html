反思不是待办清单，它不会「完成」。 一条经验不代表学会了就永远不犯 —— 它只在相似条件再出现时提醒你一下。
所以每条反思挂的是「会在什么情况下重现」，不是「已改掉 / 还会犯」。 你犯一次它就热一次，很久不犯它就冷静下去，但永远不会被删掉。
