我看完两张图的参数了。硬数据上差在这几处：
· 光圈 f/1.2 → f/4（你的背景虚化不够）

但有一件事参数看不出来：参考是侧逆光，你像是顺光。 这是你当时站的方位问题。
我问你三个问题，答完我帮你写成偷师点： ① 你当时是正对着光拍的吗？ ② 收小光圈是故意的吗？ ③ 下次会先绕到侧后方吗？
