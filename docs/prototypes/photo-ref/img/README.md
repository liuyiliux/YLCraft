
## 规格建议

| 项 | 建议 |
|---|---|
| 尺寸 | 横图 1200×800 / 竖图 900×1200 |
| 格式 | JPG |
| 质量 | 80 |
| 大小 | 单张 ≤ 300 KB |
| 比例 | 同一组对照图**必须同比例**，不然横向对比会错位 |

## 为什么要同场景同机位

景别五级那组**必须**是同一个场景、同一个人、同一个机位，
只改变拍摄距离或焦段。不然读者看不出「景别」本身的影响，
会误以为是换了地方。

**这也是各组对照图的通用要求**：只变一个变量。
