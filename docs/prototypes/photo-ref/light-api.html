③ 几点能拍什么（这才是摄影师要的）
逆光 / 剪影 16:20 – 17:00
太阳在你的正前方，脸留暗部，光勾轮廓
为什么这个时段 太阳高度降到 8° 以下，光穿过树/建筑的角度低， 才会出现那种「光从背后漏过来」的效果。正午太阳在头顶，拍不出。
风险 光比极大，脸很容易全黑。要么带反光板，要么就要暗部（剪影也好看）。
侧逆光（最保险） 15:30 – 16:30
太阳在侧后方 45°，脸有一半受光，轮廓也在
为什么推荐这个 高度还有 10–20°，光有方向但不算太斜， 脸上既有立体感又不会全黑。人像最稳的光位。
风险 鼻子会在脸侧投一条长影，要微调角度避开。
正午顶光11:30 – 13:00
太阳在头顶，眼下出阴影
为什么不推荐 太阳高度 33°，从头顶正上方打下来——眼窝、鼻子下面全是黑的， 人像最难看的光。除非你要的就是这个效果。

❓ 我们确实没查到的

具体人流攻略只说「旅行团多」，没给具体时段数据 实时人流量没有公开数据源 建筑遮挡园区内的楼阁会不会挡光，没算
这些怎么办 攻略里提到的就引用，没提到的就写「没查到」——不猜，也不假装能做。 需要精确判断的时候，还是得实地去一次。
