③ 参数一图流 动它，画面变什么

参数影响数值大数值小
焦段透视长焦压缩、脸更「正」广角夸张、脸易变形
光圈景深 + 写实度f 大：前后清楚、写实f 小：虚化梦幻
快门动的东西1/1000：凝固1/30：拖影、动感
ISO亮度 + 噪点高：亮但噪点多低：干净但可能欠曝
白平衡冷暖 + 色调相机数值大更暖相机数值小更冷
一句话：焦段决定你站多远，光圈决定背景多糊，快门决定动不动，ISO 决定能不能拍。先保高光，再谈风格。

④ 柔光 vs 硬光 判据：影子边缘

硬光

影子深、边缘锐利，像刀切。反差大、质感强，会放大瑕疵。来源：裸灯、聚光筒、正午太阳。

图例待补
硬光 · 影子边缘锐利

柔光

影子没有边界、亮暗过渡均匀。反差小、皮肤平滑。来源：柔光箱、双层柔光布、阴天、纱帘。

图例待补

⑤ 后期顺序五步 顺序错了就白做

1
修瑕疵
痘、斑、碎发、背景杂物，先打底
2
框动态范围
曲线保住最亮最暗，高光别爆
3
磨皮
只修脏阴影，不动结构，保留毛孔
4
肤色
脸 / 脖子 / 手一致，自然有血色
5
调色风格化
先全局后局部，风格化最后做

⑥ 常见错误清单 对一下自己有没有

顺序错没修皮先调色 → 按固定顺序重做
下手太狠颜色浓、磨皮塑料 → 关层对比，滑杆不过半
亮度过头脸死白、没细节 → 转黑白看是不是一块亮斑
肤色假发绿 / 发青 / 惨白 → 吸管取色，和脖子对比
磨皮塑料没毛孔、和头发锐度不匹配 → 保留纹理，加细颗粒
液化过头三角形脸、背景线歪 → 只推 5%–10%，检查背景
曝光不注意高光溢出、暗部死黑 → 拍前看直方图 / 高光警告
背景没检查电线、垃圾桶、路人 → 按快门前扫一遍四边
