# 画布样式：六平台优点聚合（2026-10-18）

> 前提已定：**画布 = 节点流程工作台**（节点图，不是自由画布）。  
> 本文把这个月调研的六家平台的优点，逐条落到画布样式上，**每条标来源**。

---

## 一、总览：从谁那借了什么

| #  | 样式决策                            | 来源                                          | 为什么适合我们         |
| -- | ------------------------------- | ------------------------------------------- | --------------- |
| 1  | 顶部**品牌胶囊 + 面包屑 + 保存点**          | BeefTV                                      | 一眼知道"在哪、存没存"    |

## 二、骨架布局

```
┌───────────────────────────────────────────────────────────────────────┐
│ [YL] YLCraft   我的短剧 / 画布 3  ●已保存到本地    [编辑|运行]          │ 52px
│                              [版本记录][自动整理][▶ 运行][出片]         │
├──────────┬────────────────────────────────────────────┬───────────────┤
│ 节点库    │                                            │  检查器         │
│          │        ┌────────┐     ┌────────┐          │               │
│ ▾ 输入    │        │ 提示词  ├────▶│ 生图   │          │  参数          │
│  ▸ 文本   │        └────────┘     └───┬────┘          │  模型 ▾        │
│  ▸ 提示词 │                          │               │  比例 16:9     │
│ ▾ 能力    │                     ┌────▼───┐           │  张数 1        │
│  ▸ 生图   │                     │  图片   │           │               │
│  ▸ 生视频 │                     └────────┘           │  成本 ≈14      │
│  ▸ 处理   │                                          │  [运行此节点]   │
│ ▾ 产物    │                                          │               │
│          │  ┌────────┐                                │               │
│ 240px    │  │ 小地图  │                                │  280px        │
├──────────┴────────────────────────────────────────────┴───────────────┤
│ [+节点][选择][连线][隐藏连线][吸附]  100%  [⛶]         [运行日志 ▲]      │
└───────────────────────────────────────────────────────────────────────┘
```

### 逐块来源

| 区块                     | 借自                                   | 细节                              |
| ---------------------- | ------------------------------------ | ------------------------------- |
| 品牌胶囊 + 面包屑 + `●已保存到本地` | **BeefTV**（`BF ▾ 未命名工作区 画布1 ▾ ✓`）    | 保存状态写明"本地"                      |
| `编辑 \| 运行` 分段控件        | **ArtCraft**（`Build \| Record`）      | 编辑态不误触运行                        |
| 工具分组带分隔                | **ArtCraft**（`Move/Rotate/Scale` 成组） | `[+节点] │ [选择][连线] │ [隐藏连线][吸附]` |
| 白色圆形主操作                | **BeefTV**（那排工具里的白圆 `+`）             | 用在 `▶ 运行`                       |
| 右侧检查器                  | **我们自己的约定**（Ant Design 惯例）           | ArtCraft/BeefTV 都没有，但节点图需要      |
| 小地图                    | **BeefTV** `Float minimap toggle`    | 右下角浮层                           |

## 三、节点卡片

```
         ╭──────────────────────────────╮
   text  │ ⚡  生图模型         ● 成功    │  ← 图标 名字 状态点
   ─○───┤                              ├───○─→  image
         │  ┌────────────────────────┐  │
         │  │      预览 / 缩略图      │  │  ← 有了就跑出结果
         │  └────────────────────────┘  │
         │  GPT Image 2 · 1:1 · 1 张     │  ← 参数一行
         │  ⏱ 1.2s ·  ⚡14               │  ← 耗时 · 成本
         ╰──────────────────────────────╯
```

### 来源

| 元素                 | 借自                                    | 说明                                   |
| ------------------ | ------------------------------------- | ------------------------------------ |
| 头部图标 + 名字          | ArtCraft                              | 图标区分类型                               |
| **状态点**（不是彩色 tag）  | **BeefTV**                            | `● 已生成` / `● 待生成`                    |
| **参数一行**（模型·比例·张数） | **Lovart**                            | `GPT Image 2 · 中 · 9:16(4k) · 1 img` |
| **耗时 + 成本**        | **OhMyGame**（用时）/ **ArtCraft**（Costs） | 两个都要                                 |
| 端口在左/右边缘           | ComfyUI                               | 左进右出                                 |

### 五态视觉

| 状态        | 卡片              | 状态点               |
| --------- | --------------- | ----------------- |
| `queued`  | 正常              | 灰虚线圈              |
| `running` | 边框青色微光          | **青色脉冲**（1.4s 呼吸） |
| `success` | 正常              | 绿点                |
| `error`   | **边框红 + 内部淡红底** | 红点                |
| `skipped` | 整体 40% 透明       | 灰点                |

> **`running` 的脉冲动画**是 BeefTV 那种"活着"的感觉；  
> **`error` 整张卡变红**是 ArtCraft 的强反馈做法。

## 四、端口与连线（按类型上色 —— 我们自己的加法）

| dataType | 端口色         | 连线色    | 例子       |
| -------- | ----------- | ------ | -------- |
| `text`   | `#60a5fa` 蓝 | 同色 60% | 提示词 → 生图 |
| `image`  | `#22d3ee` 青 | 同色 60% | 生图 → 图片  |
| `asset`  | `#a78bfa` 紫 | 同色 60% | 素材       |
| `json`   | `#71717a` 灰 | 同色 60% | 搜索结果     |

**交互（借 BeefTV 的"隐藏连线" + 我们自己的"上游高亮"）：**

| 动作      | 效果                 |
| ------- | ------------------ |
| 悬停连线    | 连线加粗发光             |
| 选中节点    | **上下游节点微亮**（看清这条链） |
| 点「隐藏连线」 | 只留节点，线全隐           |
| 拖端口到空白  | 弹节点库（快速接一个）        |

## 五、模板选择（Lovart 的技能卡做法）

**现在是下拉菜单，改成卡片：**

```
┌──────────────────────────────────────────────────────────────────┐
│ 新建画布 · 选一个起点                                             │
├──────────────────────────────────────────────────────────────────┤
│ ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐    │
│ │  [成品缩略] │ │  [成品缩略] │ │  [成品缩略] │ │  [成品缩略] │    │
│ │            │ │            │ │            │ │            │    │
│ │ 创意到生图  │ │ 搜索参考生图│ │ 批量角色    │ │ 批量场景    │    │
│ │ 3 节点     │ │ 4 节点     │ │ 5 节点     │ │ 5 节点     │    │
│ │ 用过 128 次 │ │ 用过 64 次  │ │ 用过 210 次 │ │ 用过 87 次  │    │
│ └────────────┘ └────────────┘ └────────────┘ └────────────┘    │
│ ┌────────────┐ ┌────────────┐                                   │
│ │  空白画布   │ │  我的模板   │                                   │
│ └────────────┘ └────────────┘                                   │
└──────────────────────────────────────────────────────────────────┘
```

**四条都从 Lovart 学：**

1. **成品缩略图**（不是图标）—— 让人知道产出长什么样
2. **节点数** —— 知道这套流程多复杂
3. **使用次数** —— 哪个好用有数据支撑
4. **用途分类**（漫剧/电商/工具）—— 按用途不按功能

## 六、右键上下文菜单（Lovart 12 项的做法）

Lovart 的菜单证明了：**操作不该全堆在工具条上。**

**节点右键：**

```
┌─ 生图模型 ──────────────┐
│ ▶ 运行此节点             │
│ ─────────────────────   │
│ 复制节点                 │
│ 断开所有连线             │
│ 只看这一支 ├────────────▶ │  ← 高亮上下游
│ ─────────────────────   │
│ 换成别的模型 ├──────────▶ │
│ 编辑参数                 │
│ ─────────────────────   │
│ 删除                     │
└─────────────────────────┘
```

**图片节点右键（借 Lovart 那套 AI 操作）：**

```
┌─ 图片 ──────────────────┐
│ 打开图层编辑器           │  ← 双击也能进
│ ─────────────────────   │
│ 局部重绘                 │
│ 扩展画布                 │
│ 抠出主体                 │
│ 生成多角度               │
│ ─────────────────────   │
│ 存到素材库               │
│ 复制 / 删除              │
└─────────────────────────┘
```

> Lovart 那 12 项里，`图层拆分 / 编辑文字 / 多角度 / 扩展 / 矢量`  
> **正好都是"对一张成品图的操作"** —— 放进图片节点右键最合适。

## 七、成本与参数（ArtCraft + Lovart 的结合）

### 检查器底部常驻一行

```
⚡ 14 点 · ≈ $0.14        [明细 ▾]
```

点开（借 ArtCraft `COST BREAKDOWN`）：

```
COST BREAKDOWN
生图模型
  模型        GPT Image 2
  比例        1:1
  张数        1
  ───────────────────
  点数        14
  约合        $0.14
```

### 运行前汇总

```
本次运行
  3 个节点 · 2 个会花钱
  预计 ⚡28 · 约 40 秒
  [取消] [运行]
```

> **理由**：ArtCraft 把成本做成常驻 chip，Lovart 把参数压成一行。  
> 我们要**两个都有**：常驻 chip（随时知道）+ 展开明细（决定前看）。

## 八、空态 / 加载 / 错误（三态必须齐）

### 空态（借 design skill 要求 + Lovart 的引导感）

```
        ┌────────┐
        │  ◇    │
        └────────┘
        还没有节点
   从左边拖一个节点进来，
   或按 ⌘J 让智能体搭草稿
```

### 加载（骨架，不是转圈）

节点里画**和结果同尺寸的骨架方块 + 微光扫过**。

### 错误（借 BeefTV 的"就地重试" + OhMyGame 的"说人话"）

```
┌─────────────────────────────────────────┐
│ ⚠ 图像模型未通过鉴权                      │
│   用的是 chybenzun/gpt-image-2，返回 403。 │
│   不是画布的问题，画布结构没动。           │
│   [去检查模型配置] [换模型重试] [复制详情] │
│   ─────────────────────────────────     │
│   POST /v1/images/generations → 403      │  ← 技术细节折叠在最后
└─────────────────────────────────────────┘
```

## 九、动效（克制）

| 场景       | 动效                                              | 来源            |
| -------- | ----------------------------------------------- | ------------- |
| 节点悬停     | 上浮 1px + 边框提亮                                   | ArtCraft 卡片   |
| 运行中      | 边框青色脉冲 1.4s 循环                                  | BeefTV 的"活着"感 |
| 连线选中     | 加粗 + `drop-shadow`                              | 我们自己的         |
| 面板滑出     | `translateX` + 300ms `cubic-bezier(.16,1,.3,1)` | v2 定的         |
| 成功 toast | 从下往上淡入 8px                                      | BeefTV        |

**统一缓动**：`cubic-bezier(.16,1,.3,1)`  
**只动 `transform` / `opacity`** —— 不动 width/height。

## 十一、这份样式**没抄**的东西（也是判断）

| 不抄              | 来自          | 为什么           |
| --------------- | ----------- | ------------- |
| ❌ 自由画布 + 图层条在顶部 | 我自己的 v5     | 和节点图风格冲突      |
| ❌ 节点图无限嵌套分组     | ComfyUI     | "节点地狱"，违背降低门槛 |
| ❌ 模板即画布类型       | 我误判的 Lovart | 实测它不分型        |
| ❌ 大而全的工具条       | n8n         | 我们用户不是工程师     |
