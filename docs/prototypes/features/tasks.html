每条事件都挂在它所属的任务上，点「展开」看当时发生了什么。对话负责沟通，这里负责事实。
ⓘ
原型口径：状态推进、重试、取消都是本地模拟，不会真的调模型、不会真的扣积分。 真实实现里任务详情有诊断字段与结构化事件时间线（见 task-observability 规格）， 失败原因必须给人看，不能把 SQL、堆栈或内部异常类名甩到界面上。
对应真实功能：/tasks（列表 / 详情 / 重试 / 取消）、/logs、平台事件日志与运行日志三个 Tab。 规格见 task-observability、platform-event-logging。
