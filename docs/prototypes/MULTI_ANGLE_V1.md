# 多角度编辑 · 原型

> 用户确认「模型支持多角度条件生成」，所以这条路线可以继续。
> 参考即梦的多角度编辑面板（球体 + 9 方位 + 3 滑块）+ 节点连线溯源。
>
> 文件：`docs/prototypes/canvas/multi-angle.html`
> 打开：`http://127.0.0.1:8901/canvas/multi-angle.html`

---

## 1. 为什么做这个

用户在即梦看到「多角度编辑」：
- 左边一个 3D 球体，相机小球在球面上
- 右边 9 个方位按钮（左上/上方/右上/左侧/正面/右侧/左下/下方/右下）
- 三个滑块：水平 0-360°、垂直 -30~60°、景别缩放（近/标准/远）

**我们能不能做？** 用户确认**模型支持多角度条件生成**，所以：

| 部分 | 状态 |
|---|---|
| UI（球体 + 9 方位 + 3 滑块） | ✅ 原型已做 |
| 相机映射（yaw/pitch/zoom → 模型参数） | ✅ 逻辑已写 |
| 生成多角度图 | ✅ 模型支持 |

---

## 2. ⭐ 关键设计：连线溯源

即梦用一条线表示「这张是从那张生成的」，线上带剪刀图标可断开。

**我们一定要做这个**，理由三条：

| 作用 | 说明 |
|---|---|
| **溯源** | 点开图就知道它从哪来 |
| **批量重生成** | 改了原图，顺着线全部重来 |
| **留痕** | 谁改了什么，链路上看得见 |

而且我们已经有 `asset_lineage` / `asset_provenance` 两个服务，**这个能力是现成的**。

### 节点上标注来源

生成的新节点底部写：

```
来自 图片 1 · 左上 315°
```

**不用点开就知道它是哪个方向生成的。**

---

## 3. 交互细节

### 球体上的相机可以直接拖

不只是拖滑块 —— **在球体上抓相机小球拖动**，滑块会跟着变。

因为对摄影师来说，「绕着人走一圈」比「记住 315 度」直观。

### 9 方位与滑块双向联动

- 点「左上」→ 水平变 225°、垂直变 30°
- 拖滑块 → 最近的方位按钮自动高亮

### 生成后

- 新节点出现在源节点右下方
- **自动画一条线连过去**
- 线中间有剪刀，点了断开（并提示「已断开 · 这两张不再算上下游」）

---

## 4. 和即梦的差异

| | 即梦 | 我们 |
|---|---|---|
| 球体预览 | 静态球体 | **可拖相机** |
| 方位 ↔ 滑块 | 各自独立 | **双向联动** |
| 生成后 | 面板里出现结果 | **画布上新增节点 + 连线** |
| 溯源 | 有线，但只在本画布 | **接入资产血缘，可全局追溯** |

## 6. ⚠️ 一个踩到的坑（值得记）

做这个原型时，`http://127.0.0.1:8899/` **被另一个项目的服务器占用了**
（在服务 `G:\摄影\YL摄影\site`）。

我一开始重启服务器，结果**没能绑定端口、静默失败**，页面一直 404。

**后来改用 8901 端口才通。**

**教训**：起本地服务器前先确认端口是否被别的项目占用；
不要杀掉不认识的进程 —— 那可能是别的项目在跑。
