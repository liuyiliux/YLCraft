# 四、🔴 这个体量单文件撑不住了

## 现状问题

| 问题 | 证据 |
| --- | --- |
| 单文件 260KB | 一次 `ReadAllText` + 替换就可能写坏（**已经写坏过一次**） |
| 6000 行里靠 20 多个注释分块 | 找代码靠搜，改一处要确认没影响别处 |
| 没有模块边界 | 同名函数/变量冲突风险（`let editingElem` 重复声明就整块 JS 挂掉过一次） |
| PowerShell 改动不可靠 | 反引号/引号/方括号反复被吃（踩了 4 次） |

## 已经踩过的事故

| 事故 | 后果 |
| --- | --- |
| PowerShell 行切片负索引 | 文件 193KB → 200KB，开头变成 `<!DOCTYPE html></html></body>` |
| `let` 重复声明 | 整块 JS `SyntaxError`，全页面 `JS BROKEN` |

| `.empty` 类名冲突 | 卡片继承 `position:absolute`，铺满全屏 |

# 五、建议：现在拆

## 拆法（按三层 + 模块）

```
docs/prototypes/canvas/
  index.html            ← 骨架 + 挂载
  css/
    base.css            ← 变量 / 重置 / 通用
    canvas.css          ← 画布 / 节点 / 连线
    agent.css           ← 对话面板
    panels.css          ← 图层/历史/精调/巡检/导出
  js/
    data.js             ← CAPS / SCHEMAS / IMG_OPS / 演示数据
    state.js            ← DOC / LOCAL_ADJ / FIXED / HISTORY
    canvas.js           ← 三模式渲染 / 拖拽 / 连线
    agent.js            ← 对话 / 报告 / 引用
    search.js           ← 搜索链路 / 要素编辑
    localedit.js        ← 曲线 / 色阶 / 直方图
    inspect.js          ← 巡检
    export.js           ← 图层 / 导出 / 历史
    panels.js           ← 提示词库等
```

**好处：**
- 每个文件 200-600 行，一眼看得完
- 改哪个模块只动那个文件
- **不会再出现"整块 JS 挂掉"**

**代价：**
- 需要一次性的拆分工作（~1 小时）
- 原型要起 http server 才能跑（现在已经是了）

## 不拆的代价

按还剩 5590 行算，最终 11600 行。
**每改一次，写坏的风险线性上升。**

## 7.7 A4：节点与页面接到同一份能力（2026-10-20，浏览器实测）

盘点写 A4 要 ~400 行 —— **实测只差接线，最后写了 ~90 行**。
机制早就在（`capOfNode` / `invokeCap` / `openPage`），漏的是三处接线：

| 漏的地方 | 症状 | 修法 |
| --- | --- | --- |
| 演示图节点没挂 `cap` | 点节点看不到「打开完整页面」，E1 演不出来 | `buildGraph` 每个节点指到一个 capKey；`script`/`board` 用 `data:true` 明说「读文档、不调能力」 |
| `27-graphrun.js` 按 `node.id` 硬编码 cap+cost | 从节点库加的「生图工作台」指不到 id → 落到兜底分支，**免费跑完、什么都不报** | 删掉这张表，只留 `say`/`ms` 表现层；成本、接口、名字一律从 `CAPS` 读 |
| `LIB_DEFS['clip-page']` 指 `image-editor` | 一个节点指着「不是能力的能力」（`image-editor` 自己标了 `node:false`） | 改指 `clip`；出片另加本地能力 `clip-render`（`shared/clip#render`，⚡0） |

顺手补掉两个同类的"两份事实"：

- `chargeFor()` 定义了**从来没人调** → 顶栏「今天花了」永远 ¥0。现在跑图/跑单节点都按 `PRICE_BOOK` 落账；
  能力上没配 `price` 的（previs / clip / motion-gif）**只记 ⚡ 不记 ¥，并写明"没配价"**，不编人民币数字。
- ▶ 单节点**从来不过门禁**，⚡14 直接花出去（跑整图反而有门禁）。新增 `node-run` 规则，跑之前先报能力+接口+参数+价。
- `runnable` 标记删了：它和"指不指得到能力"必然漂移，现在 `capKeyOfNode(n)` 是唯一判据（节点上的 ▶、面板按钮都读它）。
