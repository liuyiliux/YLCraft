## 1. ⭐ 核心发现：右栏不能固定成素材库

查了 Agent 的工具清单 —— **199 个工具，覆盖整个平台**：

| 业务域 | 工具数 |
|---|---|
| 创作项目（章节/分镜/场景/角色） | **43** |
| 素材 | 27 |
| 世界设定（地图/实体/矛盾检测） | 23 |
| 采集（B站/抖音/小红书/番茄/快手） | 13 |
| 小说（书源/目录/章节索引） | 10 |
| AI 配置（供应商/连接器） | 9 |
| 视频（生成/剪辑/BGM） | 8 |
| 图像 | 7 |
| 知识检索 | 5 |
| 音频 / 任务 / 导出 / 画布 | 各 4 |
| 其他（写作文风/爆款分析/字幕） | 40 |

**它是一个能承包整个平台创作的 Agent，不是生图工具。**

所以 v2 里把右栏固定成「素材库」是错的 —— 用户在写小说时，右栏不该给他看图片。

## 2. 右栏改成「上下文面板」（用户选 C 方案）

```
┌─────────────────────────────┐
│ 📁 [面板名]      [自动 ▾] 28项│  ← 可切手动
├─────────────────────────────┤
│                             │
│   当前任务相关的面板内容       │
│                             │
├─────────────────────────────┤
│ 这次在做什么                  │  ← 常驻底座
│ 秋天颐和园 · 第 2 组片         │
│ 已生成 6 张 · 用了 ⚡84       │
│              [查看项目]      │
└─────────────────────────────┘
```

### 四个面板

| 面板 | 内容 | 自动跟随时机 |
|---|---|---|
| **素材库** | 图片/视频/角色 + 筛选 + 搜索 | Agent 在生成/找素材 |
| **创作项目** | 项目名 + 章节列表 + 这组用到的元素 | Agent 在写章节/做分镜 |
| **任务队列** | 生成中/完成/失败 + 进度条 | 有任务在跑 |
| **世界观** | 地图示意 + 实体列表 | Agent 在改设定 |

### 自动 vs 手动

- **默认「自动」**：Agent 做什么就显示什么
- **点右上角切「手动」**：选哪个面板就是哪个
- **手动状态下**：自动跟随暂停
- **随时可切回自动**

### 常驻底座（关键）

不管哪个面板，底部一直显示「这次在做什么」：
- 项目名 + 第几组
- 已生成几张 + 花了多少
- 「查看项目」跳转

**这样无论切到哪个面板，都不会迷路。**

## 3. 主对话：结果区照即梦重做

### 之前（v2）：单张大图

### 现在：横向排列 4 张（照即梦）

```
┌────┐┌────┐┌────┐┌────┐
│    ││ ▣  ││    ││    │   ← 悬停出操作条（↓下载 ＋存素材 ✎去画布）
└────┘└────┘└────┘└────┘
一次生成 4 张 · 2048×3072 · png            ⚡14

你可以试试这样改： [把背景换成海边日落 ↗] [再生成一版古风造型的 ↗] [试试赛博朋克风格 ↗]

[↻ 重新编辑] [⟳ 再次生成] [展开详情 ›]
```

### 三个照抄即梦的设计

| 设计 | 说明 |
|---|---|
| **横向排列** | 一次生成 4 张并排看，选一张 |
| **试试这样改** | 3 个改写建议，点了**直接填进输入框** |
| **悬停操作条** | 下载/存素材/去画布，贴在图上 |

## 4. ⭐ 和即梦的关键区别：我们不去结果页做编辑

看即梦那张详情图，它把编辑放在结果页（局部重绘/扩图/消除笔）。

**我们不该学这个。** 因为：

| | 即梦 | YLCraft |
|---|---|---|
| 编辑能力 | 简化版，就地做 | **专业画布**（19 个工序 / 124 KB 代码）|
| 做法 | 结果页放一堆编辑按钮 | **结果页只放「去画布编辑」** |

### 「图片详情」面板（点开详情才出现）

```
┌──────────────────────────┐
│ [缩略×4，可切]             │
│                          │
│ 图片提示词                 │
│ 秋天颐和园，靠窗侧坐…        │
│ GPT Image 2 · 3:4 · 2048² │
│                          │
│ [生成视频] [去画布编辑 ›]   │  ← 专业编辑只有这一个入口
│ [用作参考图] [存为素材]     │
│                          │
│ 编辑（专业操作去画布）        │
│ [局部重绘] [扩图]          │
│ [消除笔] [智能超清]         │
│                          │
│ [↩ 回到自动]               │
└──────────────────────────┘
```

**注意「编辑（专业操作去画布）」这个小标题** —— 明确告诉用户：想真修图，去画布。
