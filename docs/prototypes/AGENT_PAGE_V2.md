## 1. 右栏：动作管家 → 素材库

### 之前的问题

右栏做成了「动作管家」（问花多少、看用量明细）。
但用户实际需要的是：**生成的时候手边能看到有什么素材**。

### 现在

```
┌─────────────────────────────┐
│ 📁 素材库              28 项 │
├─────────────────────────────┤
│ [全部][图片][视频][角色]     │
│ ⌕ 搜素材名 / 标签            │
├─────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐        │
│ │刚生成│ │已存 │ │    │        │
│ │2048²│ │1536²│ │    │        │
│ │坐姿横│ │坐姿竖│ │秋颐│        │
│ └────┘ └────┘ └────┘        │
│ ┌────┐ ┌────┐ ┌────┐        │
│ │银杏 │ │ 林 │ │ 芸 │        │
│ └────┘ └────┘ └────┘        │
│ ┌────┐ ┌────┐ ┌────┐        │
│ │▶ 08s│ │桥洞│ │长廊│        │
│ └────┘ └────┘ └────┘        │
├─────────────────────────────┤
│ 坐姿全身·横图 [@加进对话][拿去除理][重命名]│
└─────────────────────────────┘
```

### 设计要点

| 要素 | 为什么 |
|---|---|
| **「刚生成」黄标** | 生成完立刻能在右栏看到，不用去主对话翻 |
| **三列小格子** | 420px 宽看不下大图，小格子能扫更多 |
| **类型筛选** | 全部/图片/视频/角色，对应后端 `AssetType` 枚举 |
| **搜索** | 素材多了必须能搜 |
| **选中后底部出操作** | 不占用格子空间 |
| **「@加进对话」** | 一键把素材引用到输入框（主对话那边接 `@` 引用）|

### 对应后端

`backend/app/db/models/asset_hub.py` 的 `AssetType` 枚举：
`IMAGE / VIDEO / AUDIO / TEXT / MODEL / CHARACTER / WORLD_SETTING / WORKFLOW / 3D_MODEL / ANIMATION / SUBTITLE`

原型只展示了 image / video / character 三类，其他类型接入时按枚举补。

## 2. ⭐ 确认卡加四档权限（回答「每次都要问吗」）

### 行业做法

**不是每次都问。** 主流有四种粒度：

| 粒度 | 典型 |
|---|---|
| 每次问 | 只在危险操作上 |
| **会话内不再问** | 即梦、Midjourney 类 |
| **按工具不再问** | Cursor allowlist |
| **按额度自动过** | API 平台 |

### 我们现在的实际情况（查代码）

`backend/app/services/agent/runtime/tools.py`：

```python
CONFIRMATION_RISK_LEVELS = {"write", "delete", "costly"}
AUTO_CONFIRMED_WRITE_TOOLS = {
    "upsert_provider_metadata",
    "create_ai_connector",
    "update_ai_connector",
}
```

**三个问题**：
1. 白名单是**写死在代码里**的，用户改不了
2. **没有「会话内记住」**
3. `costly` 每次必问，用户没有选择权

**所以「确认总不生效」不是设计，是根本没做这一层。**

### 原型里的四档

```
以后这类操作
 ○ 本次对话不再问       这一轮里再花钱不打断你
 ● 这个工具永远不问      换对话也生效 · 能在设置里撤销
 ○ 低于 ⚡50 自动过      超过这个额度才问你
 ○ 每次都问            最安全，但会很烦
```

选中非「每次问」后，**顶部出现授权条**：

```
✓ 本会话已授权：这个工具永远不问                    撤销
```

### ⚠️ 安全底线（不能省）

| 类型 | 能否记忆 |
|---|---|
| `read` | 本来不问 |
| `write` | ✅ 可记 |
| `costly` | ✅ 可记，**但要有额度上限** |
| `delete` | ⚠️ 每会话限记一次，且明确「删除不可撤销」|

**理由**：花钱可以设上限，删除不能。
