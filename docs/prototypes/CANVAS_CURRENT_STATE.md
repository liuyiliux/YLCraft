# 五、改动前必读的三条坑

## 坑 1：加载顺序（踩了三次）

`08-events.js` 在顶层调用后面文件定义的函数 → `ReferenceError` → **中断后面所有脚本**。

已修：所有依赖后续文件的启动逻辑推迟到 `DOMContentLoaded` + `typeof` 守卫。

**新加跨文件调用时，一定要放在函数里，不能在顶层直接执行。**

## 坑 2：改文件要用 edit 工具，不要用 PowerShell

PowerShell 的 `.Replace()` 会吃掉反引号/引号/中文引号，导致语法错误。

**已经踩了 4 次。**

## 坑 3：改完要 `bsk reload --hard`

`bsk navigate` 不绕 HTTP 缓存，会看到旧版本，然后误判"函数不存在"。

排查顺序：`node --check` → 查服务器文件 → `bsk reload --hard` → **`bsk console` 看真实报错**。
