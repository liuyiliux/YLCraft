## 2.2 PS 有、我们仍然缺的

| PS 功能 | 状态 | 说明 |
|---|---|---|
| **可选颜色** | ❌ 缺 | 按 CMYK 通道单独调色，比 HSL 更精细 |
| **色彩平衡** | ❌ 缺 | 阴影/中间调/高光分别调冷暖 |
| **局部模糊（高斯/镜头）** | ❌ 缺 | 背景虚化 |
| **径向滤镜** | ❌ 缺 | 圆形局部调整（我们有椭圆区域，但不是滤镜）|
| **渐变滤镜** | ⚠️ 部分 | 有线性渐变区域，但没做成可拖的滤镜 |
| **污点修复画笔** | ⚠️ 部分 | 旧版 `26-retouch.js` 有，新面板没接 |
| **液化** | ⚠️ 部分 | 旧版有，新面板没接 |
| **内容识别填充** | ❌ 缺 | AI 补全（要真接模型）|
| **最值/阈值/色调分离** | ❌ 缺 | 分析类工具，人像用不上 |
| **变换（透视/变形）** | ❌ 缺 | |
| **分通道调整（RGB 独立曲线）** | ⚠️ 待验证 | UI 有，需要确认真的生效 |
| **动作 / 批处理** | ❌ 缺 | 批量套同一套参数 |

## 2.3 我们比 PS 强的地方

| 我们 | PS |
|---|---|
| **AI 读图给建议 → 一键采纳成图层** | PS 2024 有「生成式填充」，但没有「整张图给你一组建议」|
| **参数不烘焙（非破坏，随时改）** | PS 靠图层 + 智能对象，也行但要会用 |
| **一键免费（本地像素运算）** | — |
| **区域限定和图层绑定，一眼看出「仅椭圆」** | PS 要进蒙版才知道 |

# 三、对照课程知识库

课程里讲的修图重点 vs 我们的承接：

| 课程知识点 | 我们有没有 | 说明 |
|---|---|---|
| **磨皮不能破坏光**（高低频）| ⚠️ 在旧版人像 Tab | 新面板没接到精调里 |
| **观察层：修前先找高光阴影分布** | ✅ 直方图 + 256 级 | 直方图就是这个作用 |
| **曲线先限动态范围** | ⚠️ 有曲线但没默认动作 | 可以做成「一键限动态」预设 |
| **肤色不能偏蓝偏绿** | ❌ 缺检查 | **该加：肤色检查** |
| **下手别太狠** | ⚠️ 无提示 | 可以加「参数过大」提醒 |
| **顺序：修瑕疵→限动态→磨皮→肤色→调色** | ❌ 缺 | **该加：顺序检查** |
| **「油腻」= 皮肤太光溜，缺真实质感** | ❌ 缺 | 磨皮强度提示 |
| **「过分柔会显得假」** | ❌ 缺 | 同上 |
| **参考的是摄影师/风格，不是单张图** | ✅ 预设（日系/胶片/清冷/暗调）| 就是按风格给的 |
| **修图术前分析** | ❌ 缺 | 拍之前的交接单在拍摄端有，修图端没接 |

## 3.1 最该补的三条（来自课程）

1. **肤色检查**：「鼠标移到脸上看肤色有没有偏蓝偏绿」→ 可以做成一个按钮，取样脸部算平均色相，偏离肤色范围就报警
2. **参数别太狠**：任何参数超过阈值时给提示（课程原话「大家调色总是调不好，就是下手太狠」）
3. **修图顺序引导**：给一个五步清单，勾掉一步再进行下一步

# 五、本批实际做了什么

## 5.1 导出（真的能导出）

```js
leBuildPixels()          // 取底图像素（真实图或演示图）
lePixelApply(px, p)      // 一整套参数作用到像素：曝光→对比→影调LUT→色阶→曲线→饱和→色调
// 全图图层逐个叠
// 区域图层：临时 canvas 跑一遍，按遮罩贴回
canvas.toBlob(...)       // 下载
```

**实测**：720×960 JPEG，13,330 字节，文件名 `export_<时间戳>.jpg`。

## 5.2 拖框裁切

四个角可拖，中间可移动，最小 12%，锁在画面内。

```js
LE_CROP_BOX = { x, y, w, h }   // 归一化
leCropDown / leCropMove / leCropUp
leCropApply()  // 转成 background-size / background-position
```

**实测**：框 538×845，4 个手柄，拖后 `backgroundSize: 166.67% 166.67%`。

## 5.3 画笔擦除

`globalCompositeOperation = 'destination-out'` —— 擦掉的从遮罩里减掉。

**实测**：加模式 `LE_BRUSH_ERASE=false`，擦模式 `true`，切换正常。

## 5.4 重绘真合成

选中候选 → 生成一个 `__inpaint__` 图层 → 按区域遮罩叠加到图上。

> 底下的视觉效果仍是**滤镜模拟**（黄字标注了），但**合成链路是真的** ——
> 以后换成真 AI 返回的图，只要替换 `fx` 那一段。

## 5.5 HSL（7 个色相）

红/橙/黄/绿/青/蓝/紫，每个独立饱和度滑块。
像素级实现：RGB → HSL → 找最近色相 → 调饱和 → HSL → RGB。

## 5.6 白平衡吸管

开启后在图上点一下，按点的位置算色温/色调偏移。

> ⚠️ 原型里是**按位置估算**，不是真读像素算中性点。真实现要读那个点的 RGB。

## 5.7 暗角

用容器的 `box-shadow: inset` 做 —— 比 CSS filter 更像真的暗角。

## 5.8 颗粒

SVG `feTurbulence` 噪点 + `feBlend multiply`。

**踩的坑**：一开始 filter 没限 `x/y/width/height`，
噪点铺满了整个画布区（图片外面也是）。加上范围限制 + 容器 `overflow:hidden` 才好。

## 5.9 预设（4 套）

按课程里说的「参考摄影师风格，不是单张图」：
- **日系小清新**（滨田英明那种）
- **胶片暖调**（SP3000 扫描色）
- **清冷疏离**
- **情绪暗调**

# 七、结论

**现在的编辑面板已经覆盖了 PS 人像调色的绝大部分常用能力**，
并且在两件事上比 PS 好：

1. **AI 建议直接变图层**（PS 没有这种整张建议）
2. **参数非破坏 + 免费本地运算**

**比课程差的主要是「怎么想」的引导**（肤色检查、下手别太狠、修图顺序），
**比 PhotoMaster 差的是「接真 AI」和工程细节**（EXIF、自动保存、原分辨率）。
