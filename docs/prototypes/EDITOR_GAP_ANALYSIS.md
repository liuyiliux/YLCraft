## 2.2 肤色检查怎么做的

课程原话：
> 「鼠标移到脸上，仔细看一看，**肤色有没有偏蓝偏绿的痕迹**。」
> 「这**绿色跟红色已经很接近了**，这是不合适的。」
> 「我们**首要的任务就是自然**。」

实现：取脸区（中间 40%×30%）平均色，判断比例

| 条件 | 提示 |
|---|---|
| 红−绿 < 8 | 太不红，偏灰/偏青 |
| 红−绿 > 75 | 太红，可能通道溢出 |
| 绿−蓝 < 5 | 蓝太多，肤色偏蓝 |
| 绿−蓝 > 65 | 绿太多，偏绿/偏黄 |
| **绿 > 红×0.85** | **「绿快追上红了 —— 这就是课程说的不合适」** |

## 2.3 下手别太狠怎么做的

课程原话：「大家调色总是调不好，**就是下手太狠**。」

8 个参数各设阈值，超了就出黄条：

| 参数 | 安全范围 |
|---|---|
| 曝光 | ±0.6EV |
| 对比度 | 0.8 ~ 1.25 |
| 饱和度 | 0.7 ~ 1.3 |
| 高光 | −0.8 ~ 0.6 |
| 阴影 | −0.6 ~ 0.7 |
| 清晰度 | ±0.6 |
| 锐化 | < 0.65 |
| 降噪 | < 0.7 |

## 2.4 修图顺序怎么做的

课程原话：
> 「这顺序不对，**这顺序错了**。」
> 「**啥都没做，皮肤也没调，啥都没做，你就调色了**。」

五步清单，点一下标记做完：
```
1 修瑕疵      → 痘痘 / 纹 / 不要的东西先清干净
2 限动态范围  → 曲线先保留最亮最黑
3 磨皮        → 高低频，不能破坏光
4 肤色调整    → 可选颜色，别偏蓝偏绿
5 调色风格化  → 颜色分级 / 预设
```

**如果后面做了、前面没做** → 那一步标黄「前一步还没做」
**如果只勾了第 5 步** → 底部出课程原话警告

# 七、结论

**已经覆盖 PS 人像调色的绝大部分常用能力（21 项），
并且补上了课程知识库里最难机械化的三件事（肤色检查 / 下手别太狠 / 修图顺序）。**

**剩下的缺口分两类**：
1. **要真接 AI 的**（重绘、结构化降级、流式）—— 原型阶段不做
2. **PS 高级功能**（可选颜色、色彩平衡、局部模糊）—— 超出当前范围

**比 PhotoMaster 差的最后一块是工程细节**（EXIF、自动保存），
**比课程差的最后一块是把旧版磨皮/液化接进新面板。**
