## 三、占位页：从「还没做」改成「会有什么」

### 之前长什么样

```
这一页还没做。
它属于「工作台」这一层，真实现时是原有的页面（如 /image-gen），在导航里挂到这里。
```

**问题**：用户点进去只看到一句话，不知道这页将来是什么样，也没有"这产品有多大"的感觉。

### 现在长什么样

每页给：

1. **一句话说明**（这页是干什么的）
2. **架构层徽章**（L1 基础 / L2 组合 / L3 画布）
3. **黄色横幅：这是原型占位 · 功能没实现**（不假装）
4. **3-4 张卡片**，每张写：这页会有什么模块 + 一句话说明 + 骨架条 + 占位按钮
5. **底部说明**：原型只证明入口能收进这一层

### 写了多少页的规格

| 分类 | 页数 | 举例 |
|---|---|---|
| 项目 | 3 | 创作项目 / 分镜表 / 出片发布 |
| 工作台 | 10 | AI 生成图片 / 动图 / 视频生成 / 图生 3D / 3D 预演 / 图片编辑 / 视频剪辑 / 字幕提取 / BGM 配乐 / Live2D |
| 工具 | 5 | 裁剪缩放 / 滤镜调色 / 抠图 / 提示词优化 / OCR |
| 资产 | 6 | 素材库 / 角色 / 世界观地图 / 提示词库 / 阅读中心 / 采集下载 |

**共 24 页，每页 2-4 个模块卡，全部写了。**

比如「AI 生成图片」这页会显示：
- 提示词（写描述或从提示词库挑）
- 参考图（垫一张图定风格）＋ 尺寸与数量
- 出图结果（四宫格预览，挑一张进画布）

## 四、⚠️ 踩的坑

### 坑一：CSS 变量名对不上，卡片全是透明的

我按 photo-ref/canvas 的变量习惯写了 `--bgElev` / `--bd2` / `--bd3` / `--tx1`，
**但平台壳的变量叫** `--s1` / `--ln2` / `--ln3` / `--tx`。

结果：卡片背景、边框全都不生效，页面上只剩文字飘着。

**教训**：往已有文件里加 CSS，**先 grep 那个文件的变量定义**，别按别的文件的习惯写。

```powershell
# 先看这个文件定义了哪些变量
[regex]::Matches($c, '--([a-zA-Z0-9]+)\s*:') | %{ $_.Groups[1].Value } | Sort-Object -Unique
```

### 坑二：iframe 切来切去会重复加载

**修法**：用 `data-src` 记住当前 src，一样就不重设。

```js
if (frame.getAttribute('data-src') !== src){
  frame.src = src;
  frame.setAttribute('data-src', src);
}
```
