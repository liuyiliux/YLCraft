# 原型 v2：样式优化说明（2026-10-18）

> v1：`canvas_agent_prototype.html`（4 屏）
> **v2：`canvas_agent_prototype_v2.html`（4 屏，推荐看这个）**
> 截图：`docs/prototypes/v2/01~04_*.png`

## 一、从三个平台各借了什么

### 借 ArtCraft（3D Stage）

| 做法 | 在 v2 哪里 | 为什么 |
| --- | --- | --- |
| 🔴 **工具分组带分隔线**（Move/Rotate/Scale 成组） | 工具条：`+` \| 选择·连线 \| 平移·显示连线·吸附 \| `16:9` | 之前工具是散的一排，用户分不清哪些是一类 |
| 🔴 **分段控件**（`Build \| Record`） | 顶栏「编辑 / 预览」 | 给画布一个明确的模式概念 |
| **画幅 chip**（`Viewport 16:9`） | 工具条末尾 `16:9` | 画幅是场景级设置，不该藏进节点参数 |
| **成本 chip**（`Costs 14`）+ Help | 右下角 `消耗 14` + `?` | 成本常驻可见 |
| **底部播放条 pill**（`0:00 —— 0:10`） | 底部中央播放条 | 为后面"出片/时间线"预留位置 |

### 借 BeefTV

| 做法 | 在 v2 哪里 | 为什么 |
| --- | --- | --- |
| 🔴 **白色圆形主操作按钮** | 工具条最左的 `+` | v1 是青色，不够跳；白色在暗底上识别度最高 |
| 🔴 **青色 toast 提示** | 「点击可显示/隐藏连线」 | v1 没有即时提示，用户不知道这个功能存在 |
| **面板顶部 tab** | Agent 面板 `对话 / 执行轨迹 / 文件改动` | v1 的 tab 样式太平，看不出可切换 |
| **品牌胶囊**（`BF ▾ 工作区`） | 左上 `YL YLCraft` 胶囊 | 比纯文字更有归属感 |

### 借 OhMyGame

| 做法 | 在 v2 哪里 | 为什么 |
| --- | --- | --- |
| 🔴 **改动规模紧凑一行**（`更改了 5 个文件 +122 -0`） | 报告底部 `更改了 3 个文件 +18 −4` | v1 做成了大卡片，占地方；一行就够 |
| **运行时长常驻** | 报告头 `用时 1 分 12 秒` | 让用户知道花了多久 |
| **节点状态点**（不是彩色 tag） | 节点头 `● 已生成` / `● 待生成` | tag 太抢眼，小圆点更克制 |

## 二、v1 → v2 的具体改动

### 画布页

| 元素 | v1 | v2 |
| --- | --- | --- |
| 左上 | 纯文字面包屑 | **品牌胶囊 + 面包屑 + 保存点** |
| 模式切换 | 无 | **编辑 / 预览 分段控件** |
| 工具条 | 一排小按钮，无分组 | **分组 + 分隔线 + 白色圆形主按钮 + 画幅** |
| 节点状态 | 彩色 tag（`已生成`/`待生成`） | **小圆点 + 文字**，更克制 |
| 节点悬停 | 无反馈 | **上浮 1px + 边框提亮** |
| 连线 | 静态 | **选中链路青色发光**（`drop-shadow`） |
| 提示 | 无 | **青色 toast**（可关闭） |
| 时间轴 | 无 | **播放条 pill**（0:00–0:10） |
| 成本 | 无 | **右下 `消耗 14` chip** |
| 小地图 | 有 | 位置调整，加 `总览` 标签 |

### 版本面板

| 元素 | v1 | v2 |
| --- | --- | --- |
| 行密度 | 较松 | 收紧（11px 间距） |
| 操作按钮 | 一直显示 | **hover 才浮出**（带位移过渡） |
| 时间轴 | 有竖线 | 竖线更细，当前版本青色光晕 |
| 标签 | `智能体`/`手动`/`自动` | 保留，但色调更收敛 |

### Agent 报告

| 元素 | v1 | v2 |
| --- | --- | --- |
| 段落标签 | 大写字 + 竖条 | **竖条更明显 + 字距加大** |
| 自检 | 一行文字 | **四个状态 tag**（三个绿一个黄） |
| 改动规模 | 大卡片行 | **紧凑一行** |
| 能力边界 | 黄框 | 保留，文案更短 |
| 面板宽度 | 460px | **470px**（报告更长） |

### 错误态

| 元素 | v1 | v2 |
| --- | --- | --- |
| 按钮 | 主/次混 | **主按钮实心青，次按钮描边** |
| 技术细节 | 有滚动条 | **隐藏滚动条** |
| 原则说明 | 4 条文字 | 保留，加序号更易读 |

## 三、视觉规范（v2 定稿）

```css
背景     #08080a   （off-black，非纯黑）
面板     #101013
卡片     #16161a
描边     rgba(255,255,255,.065) / .11 / .17 三档
文字     #f0f0f3 / #9c9ca8 / #63636e 三档
强调     #22d3ee  （唯一强调色，对齐 theme.tsx 的 Deep 主题）
语义     ok #34d399  warn #fbbf24  danger #f87171
圆角     5 / 8 / 12 / 16 / 22
阴影     3 档（1px / 4px / 18px 扩散）
缓动     cubic-bezier(.16,1,.3,1)  统一
字号     13 基础 / 12.5 正文 / 11.5 次要 / 10.5 标签
```

**三条纪律：**
1. **只有一个强调色**（青），语义色只用在状态
2. **不用纯黑**（`#08080a` 不是 `#000`）
3. **动效只动 transform / opacity**，统一缓动
