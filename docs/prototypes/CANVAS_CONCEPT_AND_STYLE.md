# 画布：思路 + 样式 定稿提案（2026-10-18）

> **先把思路和样式定下来，节点慢慢补。**
> 本文纠正我前面原型的一个**风格错误**，并给出可确认的视觉规范。

---

## 0. 先纠错：我的原型画错了

| | 我的 v4/v5 原型 | 我们的实际画布 |
| --- | --- | --- |
| 风格 | 自由摆放的图片（tldraw 那种） | **节点流程图**（ComfyUI 那种） |
| 节点 | 没有端口 | **有端口**（`CanvasPort` / `dataType`） |
| 连线 | 几乎没有 | **类型化连线**（`CanvasConnection`） |
| 代码依据 | — | `InfiniteCanvasSurface.tsx` 有 `port` / `connection` / `viewport` |

**所以 v5 那个"图层条 + 拖出画框"不是画布的样子。**

**但图层那套没白做** —— 它应该变成「**双击图片节点后打开的编辑器**」。

---

## 一、思路（一句话）

> **画布 = 把能力连成一条线，跑出产物的工作台。**

不是：
- ❌ 不是"把成片摆在一起看"的白板
- ❌ 不是"画十步流程"的流程图
- ❌ 不是"PS 那种图层编辑"

是：
- ✅ **节点 = 一步能做的事**（生图 / 生视频 / LLM / 搜索 / 图片处理…）
- ✅ **连线 = 数据流向**（上一个节点的输出，喂给下一个）
- ✅ **模板 = 预连好的节点图**
- ✅ **跑 = 按依赖顺序执行，有轨迹**

---

## 二、画布上有三类东西（都已存在）

| 类型 | 已有节点 | 作用 |
| --- | --- | --- |
| **输入节点** | `text` `prompt` `asset` | 提供原料 |
| **能力节点** | `llm` `image_model` `image_batch` `image_transform` `platform_search` `media_picker` | 干活 |
| **产物节点** | `image` | 存结果 |

**要补的（慢慢来）：**
```
❌ 视频生成节点
❌ 角色提取节点
❌ 剧本 / 分镜节点
❌ 出片节点
```

> 你说"节点可以慢慢迭代补" —— 对，**思路和样式定死之后，加节点就是加一个类型 + 一个渲染分支**。

---

## 三、用户走的路（三条）

### 路径 A：用模板（大多数用户）

```
新建画布 → 选模板（可视化卡片）→ 图已经连好了 → 填参数 → 点运行 → 产物落地
```

### 路径 B：改模板（进阶）

```
选模板 → 删几个节点 / 加一个节点 / 改连线 → 跑 → 「存为我的模板」
```

### 路径 C：从零搭（高手）

```
空白画布 → 从左侧节点库拖节点 → 连 → 跑
```

> 🔴 **降低门槛的关键**：路径 A 的用户**看不到节点图也能用**（模板填参数就行）。
> 这正是 `DESIGN.md` 第一条约束要求的。

## 四、样式（定稿提案）

### 4.1 画布骨架

```
┌──────────────────────────────────────────────────────────────────┐
│ YL  我的短剧 / 画布 3   ●已保存        [模板▾] [运行] [出片]      │ 52px
├────────┬─────────────────────────────────────────────┬───────────┤
│        │                                             │           │
│ 节点库  │                                             │  检查器    │
│ (可收)  │              画布（点阵背景）                 │  属性/参数 │
│ 240px  │                                             │  280px    │
│        │        ┌────────┐      ┌────────┐          │           │
│ 输入    │        │ 提示词  ├─────▶│ 生图    │          │           │
│ 能力    │        └────────┘      └───┬────┘          │           │
│ 产物    │                            │               │           │
│        │                        ┌───▼────┐          │           │
│        │                        │  图片   │          │           │
│        │                        └────────┘          │           │
├────────┴─────────────────────────────────────────────┴───────────┤
│ [▷][✥]│[层][连线][吸附] 100% [⛶]                    [运行日志]     │
└──────────────────────────────────────────────────────────────────┘
```

**三个新区域（相对现在）：**
- **左侧节点库**（可收起）—— 拖节点进来
- **右侧检查器** —— 选中节点后改参数
- **底部运行日志** —— `WorkflowTrace` 的可视化

### 4.2 节点卡片

```
         ╭─────────────────────────╮
   输入  │ ⚡  生图模型      ● 成功  │  ← 头部：图标 + 名字 + 状态点
   ─○───┤                         ├───○─→  输出
         │  ┌───────────────────┐  │
         │  │   预览 / 缩略图    │  │  ← 主体：预览或参数摘要
         │  └───────────────────┘  │
         │  GPT Image 2 · 1:1 · 1张 │  ← 底行：关键参数一行
         ╰─────────────────────────╯
           宽 240~300，随类型变
```

**状态点四态：**

| 状态 | 视觉 |
| --- | --- |
| `queued` | 灰色虚线圆 |
| `running` | **青色脉冲**（呼吸动画） |
| `success` | 绿点 |
| `error` | 红点 + 节点边框变红 |
| `skipped` | 整体 40% 透明 |

### 4.3 端口与连线（按类型上色）

| dataType | 颜色 | 用在哪 |
| --- | --- | --- |
| `text` | 蓝 `#60a5fa` | 提示词 → 生图 |
| `image` | 青 `#22d3ee` | 生图 → 图片 |
| `asset` | 紫 `#a78bfa` | 素材 |
| `json` | 灰 `#71717a` | 搜索结果 |

- 端口画在节点左/右边缘，**左进右出**
- 连线走**贝塞尔曲线**，颜色 = 源端口颜色
- **悬停连线高亮，上下游节点微亮**（这是"看清链路"的正确做法，不是画阶段框）

### 4.4 模板选择（升级现在那个下拉菜单）

现在是：
```
[模板 ▾]
 创意到生图
 搜索参考生图
 图片处理
 批量角色 / 批量场景 / 批量道具
```

**升级成可视化卡片（像 Lovart 的技能卡）：**

```
┌────────────────────────────────────────────────────────────┐
│ 新建画布 · 选一个起点                                        │
├────────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐      │
│ │ [缩略图]  │ │ [缩略图]  │ │ [缩略图]  │ │ [缩略图]  │      │
│ │ 创意到生图│ │ 搜索参考  │ │ 批量角色  │ │ 批量场景  │      │
│ │ 3 节点    │ │ 4 节点    │ │ 5 节点    │ │ 5 节点    │      │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘      │
│ ┌──────────┐ ┌──────────┐                                 │
│ │ 空白画布  │ │ 我的模板… │                                 │
│ └──────────┘ └──────────┘                                 │
└────────────────────────────────────────────────────────────┘
```

**关键：每个模板卡显示「缩略图 + 名字 + 几个节点」** —— 让人知道选它会得到什么。

### 4.5 🔴 图层编辑器在哪（把 v5 那套放对位置）

**双击一个「图片」节点** → 打开**全屏图层编辑器**：

```
┌──────────────────────────────────────────────────────────┐
│ ← 返回画布     分镜 3 · 图层编辑                          │
├──────────────────────────────────────────────────────────┤
│ 图层 [暗角][角色★][背景] [+]        [保存到素材库][打光]  │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                 ┌────────────────┐                       │
│                 │   画框（16:9）   │                       │
│                 │   [角色 选中]    │                       │
│                 └────────────────┘                       │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**这样两套东西各归各位：**
- **画布** = 节点流程图（跑流程）
- **图层编辑器** = 双击节点后进入（改这一张图）
