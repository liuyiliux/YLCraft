## 2. 原型做了什么

### 布局

```
┌──────────┬───────────────────────┬──────────────┐
│ 场景对象  │      3D 视口           │  预演助手     │
│ 4 个      │  人形/桌子/机位框      │  （抄画布）   │
└──────────┴───────────────────────┴──────────────┘
```

右栏 392px，用的是画布那套 `--s1/--ln/--ac` 变量和气泡样式。

### ⭐ 核心：改动卡（操作留痕）

助手不直接把场景改了，而是给一张**逐条可查**的卡：

```
┌─────────────────────────────────────────┐
│ 我想这么改                    1 处       │
├─────────────────────────────────────────┤
│ ☑ 机位 主视角                            │
│     角度  正面      →  右前方            │
│     焦距  35mm      →  50mm              │
│     距离  3.2 米    →  2.1 米            │
│   ⚠ 会动到镜头 3、镜头 5 这两个地方       │
├─────────────────────────────────────────┤
│ 它改不了：灯光不在我的能力里 ——           │
│ 机位能动，但要加补光得去「打光」面板。     │
├─────────────────────────────────────────┤
│ [应用这 1 处改动]          影响 2 个镜头  │
└─────────────────────────────────────────┘
```

**四个设计点**：
1. **逐条列「现在 → 改成」** —— 不是一句「已调整机位」，是能核对的数字
2. **写明影响面** —— 「会动到镜头 3、镜头 5」，改之前就知道后果
3. **写明能力边界** —— 「灯光不在我的能力里」，不假装什么都能做
4. **只有一个按钮** —— 符合铁律「同一动作只允许一个按钮」

### 应用后：永久留痕

```
┌─────────────────────────────────────────┐
│ 已应用              第 7 版 → 第 8 版     │
├─────────────────────────────────────────┤
│ ☑ 机位 主视角                            │
│     角度  正面  →  右前方                │
│     焦距  35mm  →  50mm                  │
│     距离  3.2 米 →  2.1 米               │
├─────────────────────────────────────────┤
│ 改动已经存进这个场景了    [撤销这次]      │
└─────────────────────────────────────────┘
```

**卡片不会消失**，改动记录永久留在对话里。

### 助手汇报：四项（interaction-quality 铁律 19）

```
做了   机位 主视角改成右前方 50mm 2.1 米；场景从第 7 版存成第 8 版
没做   没动小林的姿势和动作；没动书桌；没改另外两个镜头
自检   机位没穿进人物身体、没有对象跑出画面 —— 3 项都过了
规模   1 处改动 · 影响 2 个镜头 · 用时 0.6 秒
```

**「没做」和「自检」是最容易省略、但最影响信任的两项。**

### 空态：三个入口，不是「暂无数据」

```
说你想怎么改，我来摆。
我只会提议，动了什么会逐条写给你看，你点应用才生效。

[把机位推近一点，再偏到右前方]
  会改：机位的距离和角度
[让人物转向镜头，抬起手]
  会改：朝向 + 动作
[在画面左边加一张桌子]
  会加：一个新的物体
```

**每个入口都标了「会改什么」**，用户点之前就知道代价。

## 3. 遵守的门禁

| 门禁 | 怎么做的 | 验证 |
|---|---|---|
| **界面不许泄漏引擎术语** | `set_camera`→机位、`assign_motion`→动作、`poseJoints`→姿势角度、`revision`→第 N 版 | ✅ 实测扫描 7 个术语，**泄漏 0 个** |
| **同一动作只有一个按钮** | 卡片底部只有「应用这 N 处改动」 | ✅ 实测按钮数 = 1 |
| **状态用小圆点不用色块** | 「已应用」用绿点 + 文字 | ✅ |
| **空态给 ≥3 入口** | 3 个，每个带「会改什么」 | ✅ 实测 3 个 |
| **Agent 汇报四项** | 做了/没做/自检/规模 | ✅ 实测 4 项 |
| **判据只能是画面** | 应用后视口机位框真的从「正面·35mm」变成「右前方·50mm」 | ✅ 实测 DOM 变化 |

## 5. 修过的一个逻辑矛盾

第一版原型里，机位方案一边显示「已应用」，一边又写
「它改不了：这个机位是**锁着**的」—— **自相矛盾**。

改成真正的能力边界：

> 它改不了：**灯光**不在我的能力里 —— 机位能动，但要加补光得去「打光」面板。

**教训**：「说它改不了什么」必须是真的边界，不能和刚做完的事打架。
