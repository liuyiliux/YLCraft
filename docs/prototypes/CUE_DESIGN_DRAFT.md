# 〇、五个改变设计的发现

## 0.1 ⭐⭐ 最重要的：这不是知识问题，是检索问题

Cue & Capture（SLR Lounge / Pye Jirsa）的定位词：

> **「That is not a knowledge problem. It is a retrieval problem.」**
> （这不是知识问题，是**现场想不起来说什么**的问题）

它的产品设计直接对抗图库模式：

> 「图库给你的是一张成品照片。它不告诉你**怎么把两个紧张的人**带到那个结果，
> 更不告诉你**过程中该说什么**。」

**所以入口不是图，是「我现在想让哪里变」。**

## 0.2 ⚠️ 一个我之前完全没想到的失败模式：坐标系歧义

> **「头往左一点」是摄影现场最容易卡住的指令。因为左边是谁的左边？**
> 摄影师的左边，还是被摄者的左边？

这是**坐标系歧义**，不是说服力问题。

**而且它能被机器检测**，任何含裸「左/右/多/少」而没有参照系的指令都该被拦。

解法：给**参照物**（「远一点那边的肩膀」「鼻尖朝窗户」）或**单位**（「一厘米，不要更多」）。

## 0.3 ⭐ 第一次说不对是常态（Peter Hurley 亲口）

> 「**十次里有七次，第一次说的不对。要第二次，有时第三次。**」

**所以口令必须有「重试说法」这个字段。** 我原设计漏了。

中文侧的完整结构（成都王老师）：

> 「小姐姐，手低一点，手低一点，**诶，很好很好，就是这里**」
> = 微调 → **重复一遍** → 确认 → 正向锁定

**「手低一点」说两遍**，因为现场吵、对方紧张，单遍指令经常不执行。

## 0.4 ⚠️ 行业最著名的单句口令，被眼科医生证伪

**squinch**（Peter Hurley 的招牌）定义是「缩小下眼睑和瞳孔的距离」。

眼科医生公开质疑：

> 「**我们没有单独的肌肉能抬起下眼睑，所以你不能单独眯下眼睑。**」

医生给的替代是流程式的：

> 做一个完整的真笑 → 松眉 → 让脸颊抬起 → **非常轻微地把眼睛睁开**

而 **Hurley 自己后来也承认**：他讲「squint」讲了很多年才发现用错了。

> **行情共识可以传抄一个错误二十年。**
> → 口令库必须有「**证据强度**」字段。

## 0.5 动词，不是形容词（verbs, not adjectives）

> 「形容词描述你要的结果；动词描述模特能执行的动作。」

> 「『看起来自信』是一个形容词请求——它让人**去表演自信，而且演得很差**。」

**这解释了为什么「放松」没用**：
> 「你说这句话的时候看看对方的身体——肩膀升起来了，手死了，
> 脸组装成一张礼貌的面具。你是在**要求一个人当场自发**——这是紧张的人唯一做不到的事。」

# 一、口令条目的字段（最终版）

## 1.1 从 Cue & Capture 抄的 4 段

| 段 | 内容 |
|---|---|
| **Setup** | 身体的物理指令（不含话术） |
| **Cue** | **你说出口的原话**，按情绪而非解剖学措辞，**写明对谁说、什么语气** |
| **How to Capture** | 机位高度、快门、拍几张 |
| **What Could Go Wrong** | 可预见的失败 |

## 1.2 我补充的 10 个

| 字段 | 为什么必须 | 例 |
|---|---|---|
| **原文逐字** | 整个库的资产，不改写 | 「下巴先轻轻往前，再往下放一点。」 |
| **来源 URL + 时间码** | **无来源不入口令库** | |
| **作用位置** | 检索轴 | 下巴/眼神/手/肩/重心/表情/全身 |
| **句式类型** | 决定用哪种说法 | 指令/任务/场景/反问/禁止/计数 |
| **⭐ 重试说法** | 七成第一次不对 | 「再往前一点点就好，不用探脖子」 |
| **确认说法** | 正向锁定 | 「诶，很好很好，就是这里」 |
| **救场说法** | 做过头怎么拉回来 | 「太远了，退三分之一」 |
| **⭐ 证据强度** | 网红口令不一定对 | 多来源共识 / 单来源 / **有专业反证** |
| **失败分类** | 拆成三态 | 做过头 / 没效果 / 副作用 |
| **链的前后** | 口令有顺序 | 走 → 耳语 → 抓笑 |

## 1.3 完整结构

```
口令 Cue
├── 原文逐字         「下巴先轻轻往前，再往下放一点。」
├── 来源             shephe.com / Lindsay Adler 教材整理
├── 作用位置         下巴
├── 句式类型         指令式（分两步）
├── 力度             micro（<2cm）
├── 为什么有效        向前+向下是两个动作，缺一则双下巴或憋气
├── 失败分类
│   ├── 做过头       整个脖子前探，像在憋气
│   └── 没效果       只做了「往下」，出了双下巴
├── ⭐ 重试说法      「再往前一点点就好，不用探脖子」   ← 标记「非原文，实测沉淀」
├── 确认说法         「对，就是这个，先别动」
├── 救场说法         「太远了，退三分之一」
├── ⭐ 证据强度      多来源共识 / 单来源 / 有专业反证
├── 适合谁           素人 / 专业模特 / 儿童 / 内向型
├── 不适合谁         颈椎受限别用面部控制类
├── 链               上一条 / 下一条
└── 样片             成功样片 + ⭐做过了的样片
```

# 二、⭐ 五条机器可检的质量闸门

**录入时就拦，不做事后清洗。** 这五条全部来自调研里的反证：

| # | 检查 | 动作 |
|---|---|---|
| 1 | 含**形容词**（自然/放松/自信/高级） | **拦** |
| 2 | 含**无参照的「左/右/多/少」** | **拦**（问：谁的左？） |
| 3 | 是**禁止式**且没有正向替代（「不要耸肩」） | **告警** |
| 4 | 没有**重试说法** | **标「未完成」**（因为七成第一次不对） |
| 5 | 没有**来源 URL** | **拦** |

> 第 2 条是我认为最巧的：**坐标系歧义可以靠字符串规则抓住**，不需要 AI。

# 三、真实口令库

## 3.1 中文（来源已标）

| 原句 | 作用 | 关键设计点 |
|---|---|---|
| 「脸先转向窗边，停住。」 | 脸朝向 | **用参照物代替左右** |
| 「现在眼睛看我手指，不用转脸。」 | 眼神 | **把脸和眼解耦，一句管两件事** |
| 「下巴先轻轻往前，再往下放一点。」 | 下颌 | **向前+向下两个动作** |
| 「远一点那边的肩膀往后走半步。」 | 肩 | **「远一点那边」替代左右** |
| 「手指甩一下，再轻轻放回衣服上。」 | 手 | **先给动作，再给落点** |
| 「把额头轻轻送向镜头。」 | 下颌 | 不强调下巴，下巴自己找到位置 |
| 「现在只是试一下，别管表情。」 | 全脸 | **降低「被考核」压力** |
| 「小姐姐，手低一点，手低一点，诶，很好很好，就是这里」 | 现场结构 | **微调→重复→确认→锁定** |
| 「嘴巴放松一点，不错，不错，就是这种感觉」 | 确认 | 正向锁定 |

## 3.2 中文任务式（最适合素人）

| 原句 |
|---|
| 「你侧过身，回头看我」 |
| 「你向前奔跑，我来抓拍」 |
| 「你慢慢地向前走，我叫你时回头」 |
| 「对着我的镜头打个招呼」 |
| 「我数到三时跳起来，我抓拍」 |

> 共同点：**每句都明说「我来抓拍」= 告诉对方不用自己负责结果。**

## 3.3 儿童专用（全部任务式）

| 原句 |
|---|
| 「给妈妈看看你的口袋在哪里呀？」 |
| 「跑到那棵树那儿，转过来，再飞快地跑回来！」 |
| 「你能给我摆一个最棒的芭蕾舞姿势吗？」 |

> **六句里没有一句描述姿势，姿势是任务的副产物。**

## 3.4 英文（Peter Hurley / podium.im）

| 原句 | 位置 | 备注 |
|---|---|---|
| `Bring your forehead toward the camera` | 下颌 | **替代「抬头」** |
| `Bring your ear toward the camera` | 头 | |
| `Allow a little space between their lips` | 嘴 | **替代「笑一个」** |
| `Get your Eastwood on` | 眼 | 比喻式 |
| `Nose towards the window, eyes back to me` | 鼻/眼 | 作者称「单句价值最高」 |
| `Ear towards that shoulder — a centimetre, not more` | 头 | **给了量化单位** |
| `Chin down and towards me` | 下巴 | 强调绝不能说单独的 `chin down` |
| `Show me the line from ear to shoulder` | 颈 | **用「给我看一条线」替代「你脖子短」** |
| `All the weight on the back leg` | 重心 | **一句修三处** |
| `If it bends, bend it` | 关节 | |
| `Touch, don't grab` | 手 | |
| `Close your eyes. Open them on three` | 表情 | **计数式** |
| `Laugh badly. Worst fake laugh you can do` | 表情 | 反向操作 |
| **`squinch`** | 眼 | **⚠️ 有专业反证** |

## 3.5 场景式（解决情绪，不解决位置）

| 原句 |
|---|
| `You're waiting to find out if you got the job—and you really need it` |
| `You just walked into a party where you don't know anyone` |
| `You're dressed up for a fancy dinner, but everyone else is in jeans` |

> **⚠️ 场景式只解决情绪，不能拿来定下巴和手的位置**——否则对方自由发挥跑偏。

# 四、六条失败模式（全部有据）

| # | 失败 | 本质 |
|---|---|---|
| 1 | 说「放松」 | **要求的是状态不是动作**；对方已知道自己不放松，缺的是步骤 |
| 2 | 说「自然一点」 | **没给出任何可执行动作**；「问题多数不在被摄者，他只是没收到能执行的指令」 |
| 3 | 「看镜头笑一个」 | **制造「执行态」**；注意力落到自己嘴上，而真笑时注意力在外部 |
| 4 | 一口气说多个指令 | **工作记忆只有 1–2 格**；「每次只改一两件事」 |
| 5 | ⭐ **没有参照系的指令** | **坐标系歧义**（谁的左？） |
| 6 | ⭐ **口令本身可能是错的** | squinch 就是例子，而且没人告诉你 |

### 引导还有顺序（跨语种共识）

中文侧：**脚 → 腿 → 胯 → 腰 → 胸 → 手臂 → 手指 → 头 → 眼神**
英文侧（Hurley）：**feet → body → shoulders → 只有到这里才是脸**

> 理由：「下半身站不稳的情况下，上半身是不可能好看的。」
> **指令乱序 = 每句话都在推翻上一句。**

# 五、三个使用场景

## 5.1 出门前检查（写脚本时）

不是「这一类的姿势」，是「**这一类的口令**」，而且**按作用位置分**：
下巴 / 眼神 / 手 / 肩 / 重心 / 表情

## 5.2 现场模式（手机，超大字）

### 三层信息架构

**第一层：一个格子，一句话**
满屏只显示当前一条口令，字号大到抬眼就能读。下面三个按钮：

```
┌────────────────────────┐
│                        │
│     [姿势图]            │
│                        │
├────────────────────────┤
│  手摸一下围巾就好        │  ← 超大，黑底白字
├────────────────────────┤
│  重试   过头了   ✓ 好   │  ← 三个按钮对应三个字段
└────────────────────────┘
```

**这三个按钮直接映射数据结构**：`retry_phrase` / `recover_phrase` / `confirm_phrase`

**第二层：长按出「为什么」**
长按 → 弹出作用位置、适合谁、**做过头长什么样（那张失败样片）**
只在长按时出现，因为现场没空读。

**第三层：收工后对账**
现场只勾不评价；回来看「今天哪三条用得多、哪条总是要重试」。

### 现场硬约束

| 约束 | 推论 |
|---|---|
| 单手操作 | 全在**拇指区**，不做 hover、不做精准点击 |
| 强光下 | **黑底白字，字号 ≥24pt，不要灰字** |
| 客户就在两米外看着 | 屏幕上**不能出现令人尴尬的文字**，要能一键黑屏 |
| 噪音大、时间压力 | **一次只显示一句**，不做列表 |

## 5.3 修图前（反向）

客户说「这张脸看着不自然」，**可能是当时的引导问题**，不是修图问题。
→ 反思挂「下次这种情况换一句口令」。

# 六、⭐ 最有差异化的一个功能（如果只做一个）

**「我说砸了 → 按钮 → 给我三句能把场子拉回来的话」**

调研里反复出现的是**说错之后怎么救**，不是第一句：

| 来源 | 原话 |
|---|---|
| podium.im | 「Correct by redirection, not negation」 |
| podium.im | 「**Never go silent**」（沉默几秒会被读作否定） |
| 中文侧 | 「对，就是这个，先别动」 |
| 成都王老师 | 「诶，很好很好，就是这里」 |

**而所有这些补救话术，在现有产品里都不是结构化字段。**

# 七、中文网红原句：没拿到（诚实标注）

| 平台 | 原因 |
|---|---|
| 小红书 | 强制登录 |
| 抖音 | 只有 JS 框架页 |
| B站 | 视频无字幕轨（subtitle list 为空），AI 总结接口 403 |
| peterhurley.com | DNS 被解析到内网 |

**只有标题级证据**：B站一个 13.1 万播放的视频标题就叫
**「别再喊自然点，i人拍照的正确打开方式」**——中文从业者的共识已经凝结成一个标题。

### 采集方式必须定死：人工转录，不爬

两条可行路径：
1. **邀请摄影师自报口令**（UGC，带署名和链接）
2. **与头部博主谈转录授权**

> 这直接决定冷启动成本。

# 八、待定

- 「重试说法」需要**实测沉淀**，不能伪装成专家原话（我在原型里会标「非原文」）
- 现场要不要做语音念口令（手上有相机时）
- 中文语料冷启动走 UGC 还是谈授权
- `expected_first_try_success`（第一次成功率）需要真实使用数据才能填
