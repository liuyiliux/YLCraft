# 一、为什么口令比姿势图值钱

之前调研已经确认的一件事（SLR Lounge 原话）：

> 「图库给你的是一张成品照片。它不告诉你**怎么把两个紧张的人**从现在的位置带到那个结果，
> 更不告诉你**过程中该说什么**。」

所以：
- **姿势图**回答「拍成什么样」
- **口令**回答「怎么让他们变成那样」

一个只有图的姿势库 = Eagle 就够了。

# 二、口令条目的字段设计（草案）

## 2.1 核心字段

| 字段 | 说明 | 例 |
|---|---|---|
| **原句** | 摄影师嗓子眼里说出来的那句话 | 「下巴往前送一点点」 |
| **改哪里** | 作用在身体哪个部位 | 下巴 |
| **力度** | 小 / 中 / 大 | 小（送一点，不是抬头） |
| **适合谁** | 人群类型 | 大多数 / 老年 / 儿童 |
| **失败点** | 这句话最容易搞砸的地方 | 用力过猛会变成「抬头」 |

## 2.2 ⭐ 还需要三个字段（我认为关键）

| 字段 | 为什么需要 |
|---|---|
| **为什么这句话有效** | 不知道原理就记不住、也变不通 |
| **什么时候别说这句** | 有些口令对某些人反而更僵 |
| **替代表达** | 同效果的另一句话，客户听不懂可以换 |

## 2.3 完整结构

```
口令 Cue
├── 原句         「下巴往前送一点点」
├── 作用位置      下巴
├── 力度          小 / 中 / 大
├── 为什么有效    下巴往前 = 加强下颌线，同时避免抬头的双下巴
├── 失败点        说成「抬下巴」会拍出鼻孔
├── 什么时候别用  老年客户说「往前送」可能听不懂，要示范
├── 替代表达      「下巴低一点，眼睛还是看我」
├── 适合人群      通用 / 老年 / 儿童 / 情侣
└── 关联姿势      → 哪些姿势会用到这句
```

# 三、口令的分类（待调研确认）

## 3.1 按作用位置

下巴 / 眼神 / 手 / 肩 / 腿 / 重心 / 表情 / 整体朝向

## 3.2 按句式类型（我的猜测，待验证）

| 类型 | 例 | 特点 |
|---|---|---|
| **指令式** | 「往左移一点」 | 直接，但客户容易紧张 |
| **任务式** | 「把头发撩到耳后」 | **给一件事做，身体自己会摆对** |
| **比喻式** | 「像刚睡醒一样」 | 有画面感，但吃理解力 |
| **反问式** | 「你平时怎么笑的」 | 让她做自己 |
| **禁止式** | 「不要看镜头」 | 负向，但对僵的人有效 |

# 四、三个使用场景怎么用口令

## 4.1 出门前检查（写脚本时）

不是「这一类的姿势」，而是「**这一类的口令**」。

> 老年 → 「手碰一下围巾」（任务式，不用解释姿势）

## 4.2 现场模式（手机）

**口令要大字。**

现场的真实情况：手上有相机、客户在等、光线在变。
→ 屏幕上只需要 **一句话**，不是一段描述。

```
┌──────────────────────┐
│                      │
│      [姿势图]         │
│                      │
├──────────────────────┤
│  手摸一下围巾就好      │  ← 一句话，超大字
├──────────────────────┤
│  失败点：别让她"摆"    │  ← 小字，扫一眼
└──────────────────────┘
```

## 4.3 修图前（客户意见 → 反向口令）

客户说「这张脸看着不自然」，可能是**当时的引导**出了问题，不是修图问题。
→ 反思可以挂「下次这种情况换一句口令」。
