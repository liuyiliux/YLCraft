# 二、🔴 高严重度缺口（必须补）

## 2.1 焦段 —— 最影响风格的参数，居然没有

### 知识说

> 「对拍摄风格影响最大的**三个参数：焦段、光圈、快门**。」
> 「讲焦段的时候，重点强调**焦段带来的透视感**。」

| 焦段 | 效果 |
|---|---|
| 广角 14-35mm | 透视夸张、脸变形 |
| 标准 50mm | 接近人眼 |
| 中长焦 85-135mm | 压缩、脸更「正」，人像最常用 |

### 原型现状

**现场页只有「快门/光圈/ISO」，没有焦段。**
ISO 恰恰是**不影响风格**的，而焦段是最影响风格的 —— **优先级完全反了**。

### 要补

拍摄参数应该是 **焦段 / 光圈 / 快门**（三个影响风格的），ISO 和白平衡另列。
并且每个焦段要说明「会带来什么透视」。

---

## 2.2 光位 —— 七种光位需要受控词表

### 知识说

> 「一共有**七种光线**，都会影响到人脸的结构。」

| # | 光位 | 角度 | 特征 |
|---|---|---|---|
| 1 | 顺光 | 相机方向 | 脸全亮，缺立体感 |
| 2 | 侧顺光 | 两侧 45° | 过渡 |
| 3 | 侧光 | 90° | **阴阳脸** |
| 4 | 侧逆光 | 身后 45° | 轮廓 + 鼻头光 |
| 5 | 逆光 | 正后方 | **轮廓最强** |
| 6 | 顶光 | 头顶 | **鼻头影子** |
| 7 | 底光 | 下巴往上 | 恐怖感 |

### 原型现状

元素清单里的「光线」是**自由填写的 chip**：「侧逆光」「逆光勾轮廓」「正午顶光」。

**问题**：
- 没有统一的七种，填法混乱（「侧逆光」和「逆光勾轮廓」两个维度混在一起）
- 没法统计「我拍过哪些光位」
- 没法做筛选

### 要补

**受控词表 + 每个光位的「脸上特征」说明**。
并且和「地点光线」联动：算出某个时刻太阳方位 → 提示「这个方位对应什么光位」。

---

## 2.3 柔光/硬光 —— 有可判定的判据，但没用上

### 知识说

> 「**影子比较深、有边缘** = 硬光；**影子没有边缘**，或亮部到暗部过渡均匀 = 柔光。」
> 「边缘非常的有轮廓，**跟刀一样**。」

**这是整门课里最适合机器检查的一条** —— 因为判据是「看影子的边缘」。

### 原型现状

**完全没有。**

### 要补

一个**两选一 + 判据提示**的字段：

```
光质：  [硬光]  [柔光]  [不确定]
提示：  看鼻子在脸上的影子 —— 边缘像刀=硬光，没边缘=柔光
```

「不确定」这个选项很重要 —— 逼人去看，而不是瞎选。

---

## 2.4 白平衡/色温 —— 两个数字相反，最容易记错

### 知识说

> 「**光的色温**和**相机里设置的色温**，这两个数字是**相反**的。」

- 相机色温数值变小 → 画面变**冷**
- 光源色温 3000K 是暖光

### 原型现状

**完全没有。**

灯光人像里这是必记项 —— 不记两个数字，**根本复现不了现场**。

### 要补

```
光源色温：  [2700K 白炽] [3200K 钨丝] [5600K 日光] [自定义]
相机白平衡： [自动] [日光] [阴天] [自定义 ___K]
⚠️ 这两个数字是相反的：光源越暖 K 越小，相机设的 K 越小画面越冷
```

---

## 2.5 光比 / 主辅光 —— 灯光人像的核心

### 知识说

> 「基本是用**一盏灯来控制整个环境的光线**和色彩，
> **另一盏灯来制作一个造型**。」
> 「聚光筒（可装造型片/色片）+ **滤色片**」

### 原型现状

**完全没有。**

个性灯光人像是三种专题之一，但没有承接它的字段。

### 要补

一个简单的**布光图**（不用画得专业，摆位置就行）：

```
      [主光]  30% 功率  5600K
         ↘
          [模特]
         ↙
      [造型光] 15% 功率  + 蓝色色片
```

字段：几盏灯 / 每盏的位置 / 功率 / 色片 / 光比。

---

## 2.6 构图：「秩序」和「看点」两个可检查项

### 知识说

> 「**构图**是对画面做出规划。**构图法**是一种公式。」
> 「长期只套构图法来拍照，**人会变得特别死板**。」
> 「**秩序**：画面里有很多线条、色彩、元素，它们都在**有序地排列**。」
> 「**每张图都需要一个看点**，这个看点说白了就是这张图……」

### 原型现状

**完全没有构图相关的任何东西。**
分镜里有「景别/构图」显示文本，但没有选、没有检查。

### 要补

**两个自检问题**（不要做成「三分法/居中/对称」的选择题，那正是他反对的）：

```
① 这张图的「看点」是什么？
   [输入一句话]

② 画面有「秩序」吗？
   ○ 有 —— 线条/色彩/元素在有序排列
   ○ 没有 —— 画面上东西太多，没有主次
   ○ 刻意制造混乱（这也是风格）
```

**第 3 个选项很重要** —— 他讲了个日本摄影师全川石花「思路老跟别人反着来」，所以「没有秩序」也可能是对的。

---

## 2.7 后期顺序 —— 顺序错了等于白做

### 知识说（第 12 课讲评里最好的一段）

> 「这顺序不对，**这顺序错了**。」
> 「你现在……**啥都没做，皮肤也没调，啥都没做，你就调色了**。」

**正确顺序**（综合 11/12/15 课）：

```
① 修瑕疵（痘痘/纹/不要的东西清干净）
② 保留动态范围（曲线限制最亮最黑）
③ 磨皮（高低频，不能破坏光）
④ 肤色调整（可选颜色）
⑤ 调色/风格化（颜色分级）
```

### 原型现状

「出门前检查」里有个「修图前」区块，但**没有顺序检查**。

### 要补

**一个能勾选的顺序清单**，勾的顺序不对就提示。
或者更简单：**拍照时就把「后期要做哪几步」写下来**。

---

## 2.8 ⭐ 后期交接 —— 拍完到修图之间的信息会丢

### 这不是课程里的知识点，是课程里反复出现的现象

第 12 课讲评里他反复问学生：
- 「你拍摄的思路是什么？」
- 「这个背景是什么？」
- 「你为什么要加这个？」

**说明：拍的时候的想法，到修图时就忘了。**

而且第 25 课讲「术前分析」：
> 「每次拿到图以后，**先分析**这个图哪些地方需要修、需要修什么。」

**分析要有依据 —— 依据就是拍的时候留下了什么。**

### 原型现状

**完全没有。** 拍完就结束了，没有交接。

### 要补

**「后期交接单」** —— 拍完后自动生成一张卡：

```
┌─ 后期交接 ──────────────────────────────┐
│ 这组要什么                                │
│ 秋天小清新，暖但不是假的暖，皮肤要真实      │
│                                          │
│ 拍的时候什么条件                          │
│ 黄金时段 16:26-17:05 · 逆光 · 云量 12%   │
│ 85mm f/1.8 1/2000 ISO100                │
│                                          │
│ 已经知道要修的                            │
│ · 脸部逆光偏暗，要提亮但别丢轮廓           │
│ · 第 3 镜桥上人多，背景虚得不够            │
│                                          │
│ 客户提过的要求                            │
│ · 「不要太磨皮」（小林第 3 次说了）        │
└──────────────────────────────────────────┘
```

**这张卡在修图时打开，直接告诉你当时怎么想的。**

# 三、中严重度缺口

## 3.1 景别没系统化

知识里明确「要认识景别」：远景/全景/中景/近景/特写。

**现在只有现场页显示「全身/近景/半身」，策划和分镜里没有系统选项，也没有「一组片景别要有变化」的检查。**

## 3.2 「表情」元素缺失

十个画面元素里有「**表情** —— 人物状态」，但原型元素清单只有「姿势/口令」，**没有表情**。

而第 14 课整节在讲「模特的个性 / 本色出演 / 角色扮演」——
**表情是「演什么」的直接表现**，应该单独一类。

## 3.3 三种专题没有风格模板

小清新 / 个性灯光 / 情绪人像，每种有自己的：
- 元素组合特征
- 后期调色方向
- 典型坑

**现在新建项目时没有「这次拍哪种」的选择。**

## 3.4 情绪是整组级，不是单张级

> 「这个片子我当时想的思路就是情感。他的表达是从**平静**，慢慢地有些**爆发**，然后再到**完全安静下来**。」
> 「在片子的最后，会有一个感觉到好像**看到希望**，因为最后放了一个窗户。」

**这需要一个「整组叙事曲线」字段**，不是给每张打标签。

## 3.5 「客人视角」判断

> 「像这样的视角，观感上看**客人可能就会买单**。
> 但是像这样的视角，**客人就不一定会买单**。」

**拍之前/选片时的判断：这一张客人会不会买单。**

# 四、低严重度缺口

| 缺口 | 说明 |
|---|---|
| 直方图/曝光策略 | 「拍完了以后看照片直方图」—— 现场页可以提示 |
| 观察层 | 修图时的辅助手段，产品里做不成功能，但可以做「检查清单」 |
| 遮光技巧 | 「用手遮光」 | 
| 反光板用法 | 只提了「补脸」 |
| 电池/存储卡 | 摄影师最基础的忘带项，必带清单里应该有 |

# 五、总结：最该补的五个

按「**不补就不能用 / 补了马上顺手**」排序：

| # | 缺口 | 为什么优先 |
|---|---|---|
| **1** | **焦段 + 白平衡** | 拍之前就要定，缺了参数记录不完整 |
| **2** | **光位受控词表（七种）+ 柔硬光** | 整门课最核心的知识，原型完全没接 |
| **3** | **后期交接单** | 拍完到修图之间最大的信息断层 |
| **4** | **构图自检（看点/秩序）** | 每按一次快门都该问的两句 |
| **5** | **布光图（灯光场景）** | 个性灯光人像必需，否则这个专题做不了 |

# 六、一个更根本的问题

**现在的原型是「为拍照的人做工具」，但课程教的是「怎么想」。**

对照一下：

| 课程教的 | 原型做的 |
|---|---|
| 为什么要拍这个（主题/情绪曲线） | 只记「拍什么」 |
| 元素之间怎么自洽 | 有元素清单，但没检查自洽 |
| 光线怎么影响人脸结构 | 只记光位名，不记「脸变成什么样」 |
| 后期怎么想 | 只有「修图前」一个模糊区块 |

**最该加的一条**：**「这次要表达什么」** ——
课程里每一组片子他都会先说这个，而原型里完全没有这一格。
