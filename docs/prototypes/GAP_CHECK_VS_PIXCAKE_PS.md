# 对照检查：按像素蛋糕 + PS 平替，我们原型还缺什么

> 依据：
> - 像素蛋糕功能目录（官方帮助中心实读，2026-10-19）
> - darktable / RawTherapee / GIMP（PS 平替）核心能力
>
> **结论先说：我们偏「AI 生成」，几乎完全没有「基础修图」。**
> 而且有三处「半套」：有图层没混合模式、有精调没预设、有批量出图没批量改图。

# 四、🔴 三处「半套」值得单独说

## 4.1 有图层，没混合模式

现在图层面板能做：加层、可见性、透明度、删除。
**但所有层只能"正常"叠加。**

PS 的图层之所以有用，一半在**混合模式**：
- 正片叠底（变暗）
- 滤色（变亮）
- 叠加 / 柔光（增强对比）
- 颜色 / 色相（只应用颜色）

**没有混合模式，分层就只是"多层叠加" —— 等于半个图层系统。**

## 4.2 有精调，没预设

能调曝光/色阶/曲线/色温，**但调完不能存下来复用。**

12 镜要统一色调 → 得在 12 张上各调一遍。
**这就是为什么「批量应用」和「预设」必须一起做。**

## 4.3 有批量出图，没批量改图

我们能一次出 25 宫格、批量生图（往外出）。
**但出完了要统一调整，只能一张一张改（往里收）。**

**这是最不对称的地方。**

# 六、判断标准：什么该补，什么不该补

拿到一个像素蛋糕的功能，问三句：

1. **它是"改生成的结果"还是"改拍摄的原片"？**
   - 改结果 → 我们该有（因为我们产出图）
   - 改原片（镜头校正/透视） → 我们不需要

2. **它是本地能算的，还是必须调模型？**
   - 本地能算（色阶/虚化/发光/降噪） → 优先做，免费
   - 必须调模型（磨皮/瘦脸/追色） → 看场景价值

3. **它是一次性的，还是批量刚需？**
   - 批量刚需（预设/批量应用） → **优先级最高**
   - 一次性（老照片修复） → 可以不做

按这三问，我们最该补的就是那四项 P0。
