4. **完整性**：字数（明显偏少说明在压缩内容）
5. **是否逐字**：有没有改写、加内容

### SenseVoice 的 5 个术语错误

| 它写的 | 应该是 | 性质 |
|---|---|---|
| 光**敏** | 光**比** | 完全不同的词 |
| 欠**爆** | 欠**曝** | 同音错字 |
| 脱**胶** | 脱**焦** | 同音错字 |
| 自色温 | 色温 | 多了个字 |
| 面**面**光 | 面部光 | 重复 |

### SenseVoice 的污染长什么样

输出里会混进这些（每 3 分钟 16 个）：

```
🎼 xxx…。😊お. 🎼这个在光敏比较大的情况下…
 ↑              ↑ ↑  ↑
emoji        表情 emoji 假名 emoji
```

（示意，不是原文。真实输出里这类符号会插在句子中间，平均每 3 分钟 16 个）

**这是 SenseVoice 的已知行为** —— 它把「情绪标签 / 语种标签」当正文输出了。

### Qwen3 的 2 个错误

只有「自色温」「面面光」两个小的，**光比 / 欠曝 / 脱焦 全对**。

### XingChen GSR 为什么「0 错误」却不能用

它**不改错，它重写**：

| 逐字转写（别的模型） | GSR 输出 |
|---|---|
| 「一般我会比较**建议**大家来做这个 M 档」 | 「我**通常建议**大家使用 M 档」← 语气被改 |
| 「脸部会非常的容易**欠曝**」 | 「脸部容易**产生反光**」← **意思变了** |
| 字数 821 | 字数 **563**（少 31%） |

（第一列也只是示意改写，不是原文）

**它是「总结/润色」模型，不是逐字转写。** 做知识库要的是原话，压缩 31% 就找不回细节了。

## 九、清洗函数（给导入用）

```python
import re

# SenseVoice 的污染：emoji + 日文假名
POLLUTION = re.compile(
    r'[\U0001F300-\U0001FAFF\U00002600-\U000027BF\U0001F900-\U0001F9FF]'
    r'|[\u3040-\u309F\u30A0-\u30FF]'
)

def clean_sensevoice(text):
    text = POLLUTION.sub('', text)
    text = re.sub(r'\s{2,}', ' ', text)
    return text.strip()

# 术语纠正（SenseVoice 常见）
TERM_FIX = {
    '光敏': '光比', '欠爆': '欠曝', '过爆': '过曝',
    '脱胶': '脱焦', '自色温': '色温',
}

def fix_terms(text):
    for bad, good in TERM_FIX.items():
        text = text.replace(bad, good)
    return text
```

**注意**：`TERM_FIX` 要小心 —— 「光敏」在某些语境下是对的（光敏元件）。
只在摄影课程文本里做替换。
