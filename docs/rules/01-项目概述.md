# 01 项目概述

> **面向受众**：AI 编程助手（CodeBuddy / GitHub Copilot / Cursor 等）
> **用途**：为 AI 提供 YLCraft 项目的全局上下文和架构认知

---

## 1. 项目简介

**YLCraft（逸流创作平台）** 是一个面向内容创作者的 AI 创作平台，覆盖电商/摄影/短剧三大垂直场景。

当前阶段已实现：模型配置管理、AI 图片生成、B站视频搜索与下载、B站账号登录等核心功能。

---

## 2. 技术栈

| 维度 | 技术选型 |
|------|---------|
| 后端框架 | FastAPI + Uvicorn |
| ORM | SQLModel + asyncpg（异步）、psycopg2（同步） |
| 数据库 | **PostgreSQL 16 + pgvector**（关系 + 向量 + 全文检索） |
| 数据库迁移 | Alembic |
| 向量嵌入 | sentence-transformers (paraphrase-multilingual-MiniLM-L12-v2, 384维) |
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite 5 |
| UI 库 | Ant Design 5（zh_CN 本地化） |
| 路由 | react-router-dom 6 |
| HTTP 客户端 | Axios / 原生 fetch |
| 任务队列 | Redis（可选）/ 内存模式自动降级 |
| 视频处理 | FFmpeg + yt-dlp |
| 语音识别 | faster-whisper |
| 3D 处理 | trimesh + assimp（glb/fbx 解析） |
| 部署 | Docker Compose 单容器（PostgreSQL + Redis） |

## 4. 已实现功能模块

### 4.1 AI 模型配置管理（AIConnector）
- **位置**：`backend/app/db/models/ai_connector.py` + `frontend/src/pages/settings/index.tsx`
- **数据模型**：`AIConnector` 模型存储在数据库表 `ai_connectors`
- **核心能力**：
  - 支持多种提供商类型：llm（大语言模型）、image（图像生成）、video（视频生成）、tts（文本转语音）、stt（语音转文本）、embedding（嵌入模型）
  - 支持视觉输入的 LLM 标记：`support_vision_input` 字段
  - 支持参考图的图像模型：`support_reference_image`、`support_multiple_reference_images` 字段
  - 通用配置方式：OpenAI 兼容 API 协议，可通过 `request_template`、`response_config` 自定义
- **关键字段**：
  - `provider_type`：AI 提供商类型（llm/image/video/tts/stt/embedding）
  - `support_vision_input`：是否支持视觉输入（多模态模型，如 Qwen/Qwen3-VL-32B-Instruct）
  - `support_reference_image`：是否支持参考图（图像生成用）
  - `default_model`：默认模型
  - `base_url`：API 基础 URL（用于代理/自托管）
- **API 端点**：
  - `GET /api/v1/llm/backends`：获取可用 LLM 后端列表
- **前端配置界面**：设置 → 模型管理

### 4.2 旧版模型配置管理（已废弃）
- **位置**：`backend/config/providers.yaml` + `backend/app/core/config.py`
- **状态**：已废弃，新项目使用 AIConnector 方式

### 4.3 AI 图片生成
- **位置**：`backend/app/services/image/` + `backend/app/services/comfyui/`
- **能力**：ComfyUI 工作流驱动，支持 SDXL/Flux 等模型
- **特性**：Prompt 模板系统，任务队列管理

### 4.4 B站视频搜索与下载
- **位置**：`backend/app/services/video/` + `backend/app/services/platforms/bilibili/`
- **能力**：B站搜索 API + yt-dlp 下载
- **特性**：支持 Cookie 认证，FFmpeg 后处理

### 4.5 B站账号登录
- **位置**：`backend/app/services/cookies/`
- **能力**：二维码登录流程，Cookie 自动获取与管理
- **特性**：Patchright 浏览器自动化，WebSocket 实时推送扫码状态
