## 1. Python 代码风格

### 1.1 命名约定

| 类型 | 风格 | 示例 |
|------|------|------|
| 类名 | PascalCase | `ImageService`, `VideoDownloadTask` |
| 函数/方法 | snake_case | `generate_image()`, `parse_cookie()` |
| 变量 | snake_case | `api_key`, `db_session` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT`, `DEFAULT_TIMEOUT` |
| 私有成员 | `_` 前缀 | `_cache`, `_validate_token()` |
| 文件名 | snake_case | `image_service.py`, `cookie_store.py` |
| 目录 | snake_case | `platform_connection/` |

### 1.2 文件头部顺序

```python
"""模块用途的 docstring。"""

# 1. 标准库导入（按字母序）
import logging
import os
from pathlib import Path

# 2. 第三方库导入（按字母序）
from fastapi import APIRouter, HTTPException
from sqlmodel import Field, SQLModel, select

# 3. 项目内导入
from app.core.config import ProvidersConfig
from app.db.models.task import VideoTask

# 4. 模块级常量
MAX_PAGE_SIZE = 100
```

### 1.3 类型注解（强制要求）

## 2. TypeScript 代码风格

### 2.1 命名约定

| 类型 | 风格 | 示例 |
|------|------|------|
| 组件 | PascalCase | `ImageGen.tsx`, `VideoPlayer.tsx` |
| 接口/类型 | PascalCase | `ImageGenerateParams`, `ApiResponse<T>` |
| 枚举 | PascalCase | `TaskStatus`, `ProcessingMode` |
| 函数/变量 | camelCase | `handleSubmit`, `isLoading` |
| 常量 | UPPER_SNAKE_CASE | `API_BASE_URL`, `MAX_FILE_SIZE` |
| 文件/目录 | kebab-case | `image-gen/`, `api-client.ts` |
| Hook | `use` + PascalCase | `useWebSocket`, `useVideoTask` |

### 2.2 文件头部顺序

```typescript
// 1. React 核心
import React, { useState, useEffect, useCallback } from 'react';
```

### 2.4 类型安全（强制要求）
- 禁止使用 `any`（处理不可知第三方数据时用 `unknown`）
- 优先 `interface` 而非 `type alias` 定义对象结构
- JSON 解析后使用类型守卫或 Zod 验证

```typescript
// 正确 ✅
interface VideoItem {
  bvid: string;
  title: string;
  duration: number;
}

// 禁止 ❌
const result: any = await fetchData();
```

## 3. 通用规范

### 3.1 注释规则
- **不要**：复述代码的无意义注释（`i++; // i加1`）
- **要**：解释"为什么这样做"而非"做了什么"
- **TODO/FIXME**：必须标注原因：`// TODO: 待 product 确认默认参数`

### 3.2 函数粒度
- 单一职责：一个函数只做一件事
- 长度建议：超过 50 行考虑拆分
- 避免深层嵌套（超过 3 层 if/for）

### 3.3 错误处理
- Python：优先异常传播，在路由层统一捕获
- TypeScript：API 调用 try-catch，UI 层友好提示

### 3.4 无副作用代码
- 纯函数优于有副作用函数
- 数据转换逻辑与 I/O 逻辑分离
