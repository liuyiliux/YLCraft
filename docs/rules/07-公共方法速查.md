## 1. 文件大小格式化

### 1.1 `BaseDownloader.calculate_filesize()` — **首选方法**
- **位置**：`backend/app/services/download/base.py` 第 41 行
- **签名**：
  ```python
  @staticmethod
  def calculate_filesize(
      filesize_bytes: Optional[int] = None,
      bitrate_bps: Optional[int] = None,
      duration_seconds: Optional[int] = None,
  ) -> str
  ```
- **功能**：已知字节数返回 `"12.5MB"`；只有码率+时长时返回 `"~50.0MB"`；都无返回 `"未知"`
- **用法**：
  ```python
  from app.services.download.base import BaseDownloader
  # 已知明确大小
  size = BaseDownloader.calculate_filesize(filesize_bytes=1048576)  # "1.0MB"
  # 按码率估算
  size = BaseDownloader.calculate_filesize(bitrate_bps=6_000_000, duration_seconds=120)  # "~87.9MB"
  ```

### 1.2 B站清晰度→文件大小
- **位置**：`backend/app/services/platforms/bilibili/utils.py` 的 `_get_filesize_for_qn()`
- **签名**：`_get_filesize_for_qn(qn: int, durl_size: int, duration_seconds: int) -> str`
- **功能**：优先用 durl 返回的 `size` 字段，否则用 `_QUALITY_BITRATE_MAP` 按典型码率估算
- **用法**：`from app.services.platforms.bilibili.utils import _get_filesize_for_qn`

### 1.3 前端文件大小（TS）
- **位置**：`frontend/src/utils/format.ts`
- **签名**：
  ```typescript
  formatFileSize(bytes: number | undefined | null, decimals?: number): string  // "1.5 MB"
  formatFileSizeShort(bytes: number | undefined | null): string                 // "1.5MB"
  ```

## 2. 分辨率格式化与转换

### 2.1 `_format_resolution()` — 显示用格式
- **位置**：`backend/app/api/v1/assets.py` 第 119 行
- **签名**：`_format_resolution(width: int, height: int) -> Optional[str]`
- **功能**：`_format_resolution(1280, 720)` → `"1280x720 (720P)"`
- **内部依赖**：`_get_resolution_label(width, height)` 判断标签（4K/1080P/720P…）

### 2.2 `_parse_resolution()` — 解析分辨率字符串
- **位置**：`backend/app/api/v1/download.py` 第 38 行
- **签名**：`_parse_resolution(resolution: str) -> tuple[int, int]`
- **功能**：支持 `"1920x1080"` 和 `"1080p"` 两种格式，返回 `(1920, 1080)`

### 2.3 `_normalize_resolution()` — 统一为 widthxheight
- **位置**：`backend/app/services/platforms/bilibili/utils.py`
- **签名**：`_normalize_resolution(res: str) -> str`
- **功能**：`"1080p"` → `"1920x1080"`，`"1920x1080"` 直接透传

### 2.4 `_quality_to_resolution()` — B站 qn→分辨率
- **位置**：`backend/app/services/platforms/bilibili/utils.py`
- **签名**：`_quality_to_resolution(qn: int, fallback_height: int = 0) -> str`
- **功能**：查 `BILI_RESOLUTION_MAP` 表，qn=80→`"1920x1080"`，未命中按 16:9 从高度推算
- **用法**：`from app.services.platforms.bilibili.utils import _quality_to_resolution`

## 4. 下载器基类（所有平台下载器的父类）

### 4.1 `BaseDownloader`
- **位置**：`backend/app/services/download/base.py`
- **子类必须实现**：
  - `async parse(url) -> Optional[VideoInfo]`
  - `async download(url, quality, title, is_audio) -> Tuple[str, Optional[VideoInfo]]`
- **基类提供**：
  - `calculate_filesize()` — 上面的文件大小格式化
  - `get_qualities(url) -> List[VideoQuality]` — 封装 `parse()` 取质检列表

### 4.2 数据模型
```python
from app.services.download.base import VideoInfo, VideoQuality

# VideoQuality 字段
quality: str       # "1080P" / "720P"
resolution: str    # "1920x1080"
filesize: str      # "12.5MB"
url: str           # 下载直链
format_id: str     # yt-dlp format_id（可选）

# VideoInfo 字段
title, author, platform, cover_url, duration, description
qualities: List[VideoQuality]
audio_url, page_url
```

## 9. AI 注意事项

1. **文件大小格式化**：永远用 `BaseDownloader.calculate_filesize()`，**禁止手写 bytes→MB 循环**
2. **分辨率格式化**：需要显示 `1280x720 (720P)` 格式时用 `_format_resolution()`；只转换格式用 `_normalize_resolution()`
3. **B站清晰度映射**：`download/platforms/bilibili.py` 和 `video/parser_bilibili.py` 各自有副本，不跨文件引用，在各自文件内直接使用
4. **重复方法**：创建新辅助函数前，先查本文档确认是否已有现成实现
5. **服务类**：新下载器继承 `BaseDownloader`，复用 `calculate_filesize()` 和 `get_qualities()`
