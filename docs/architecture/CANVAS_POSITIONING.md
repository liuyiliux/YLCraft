# 画布的定位：三个层次，不是二选一（2026-10-18）

> 讨论稿。回答两个问题：
> 1. 画布是**平台基础设施**，还是**项目下的功能**？
> 2. 我示例里的"分镜"是**画布的一种类型**吗（比如漫剧画布）？

---

## 一、先说结论

**都不是。它是三个层次，每层的归属不同。**

```
┌──────────────────────────────────────────────────────────┐
│ L1 画布引擎（基础设施，全平台共用，不属于任何项目）          │
│    选择 / 拖拽 / 缩放 / 连线 / 图层 / 版本 / 撤销            │
│    ← 这一层是"基础设施"                                    │
├──────────────────────────────────────────────────────────┤
│ L2 画布模板（按用途分型，也不属于项目）                      │
│    漫剧画布 / 电商画布 / 海报画布 / 自由画布                 │
│    每型预置：节点类型、工具栏、导出方式、默认技能             │
├──────────────────────────────────────────────────────────┤
│ L3 画布实例（用户建的，可挂项目也可独立）                    │
│    「我的短剧 · 分镜画布」                                  │
└──────────────────────────────────────────────────────────┘
```

**你问的"基础设施 vs 项目功能"，答案是：**
- **引擎和模板 = 基础设施**（平台级，所有项目共用）
- **实例 = 松耦合**（可以属于项目，也可以独立，靠 `project_id` 可选关联）

---

## 二、我示例里的"分镜"是哪一层

**是 L2 的一个模板 —— 「漫剧画布」。**

我前面画的那些（分镜1/2/3、镜头号、16:9、出片）**不是画布的通用能力，是漫剧模板预置的东西**。

如果换成「电商画布」，同样是这个引擎，但预置的完全不同：

| | 漫剧画布 | 电商画布 |
| --- | --- | --- |
| 画布对象 | 分镜（带镜号/时长/机位） | 商品主体（带 SKU/卖点） |
| 典型输出 | 16:9 视频片段 | 主图 / A+ / 详情页，多尺寸 |
| 关键约束 | 镜头连续性、角色一致 | 品牌规范、平台尺寸 |
| 默认技能 | 分镜导演、剧本 | 商品图、卖点文案 |
| 工具栏 | 时间线、出片 | 尺寸预设、批量套版 |

**所以"分镜"只是模板的一种形态，不是画布的本质。**

## 四、那"模板"和"Skill"到底差在哪

这是设计的关键，也是我建议的判据：

| | 决定什么 | 例子 |
| --- | --- | --- |
| **Skill** | 怎么**做**（提示词、流程、方法论） | 「叙事短片导演分镜」 |
| **画布模板** | 能装什么**数据**（节点类型、关系、导出） | 「漫剧画布」有镜号/时长；「电商画布」有 SKU/尺寸 |

**判据：**
- 如果两种用途**只是提示词不同、数据结构一样** → 用 Skill 区分就够
- 如果两种用途**数据结构不一样** → 需要画布模板

**按这个判据，我们需要画布模板，因为：**

| 用途 | 数据结构差异 |
| --- | --- |
| 漫剧 | 要**镜号、时长、机位**，要时间线，要出片 |
| 电商 | 要 **SKU、卖点、平台尺寸**，要批量套版，不要时间线 |
| 海报 | 要**文字层、排版约束**，要分层导出 |
| 摄影/COSER | 要**图层、蒙版**，不要镜头概念 |

**这四种的数据结构差异是真的大。** 一个画布硬塞会变成"什么都能干但什么都不好用"。

## 五、所以我建议的模板清单

按 `DESIGN.md` 写的「电商 / 摄影 / 短剧」三大场景：

| 模板 | 服务场景 | 预置什么 | 优先级 |
| --- | --- | --- | --- |
| **漫剧画布** | 短剧 / 漫剧 | 分镜对象（镜号/时长/机位）、时间线、出片、角色一致性 | 🔴 **P0**（我们最强、场景最明确） |
| **自由画布** | 通用 | 图片/视频/文本/图层组，无特殊约束 | **P0**（兜底，最简单） |
| **电商画布** | 电商 | 商品主体、多尺寸预设、批量套版 | P1 |
| **海报/品牌画布** | 品牌 | 文字层、分层导出、品牌规范 | P2 |
| **精修画布** | COSER/摄影 | 图层、蒙版、液化入口 | P2 |

**先做两个：漫剧 + 自由。** 其他等有真实需求再加。

## 六、L1 引擎该抽什么（不分模板的公共部分）

```
画布引擎（L1）
├── 视口：缩放 / 平移 / 适应屏幕
├── 选择：单选 / 多选 / 框选
├── 拖拽：移动 / 吸附 / 对齐
├── 连线：端口 / 关系类型 / 循环检测     ← 我们已有，比他们都强
├── 图层：可见性 / 锁定 / Z 序 / 拖出成对象
├── 版本：自动存 / 手动存 / 恢复
├── 历史：撤销 / 重做
└── 资产：保存到素材库（合成图 + 结构）
```

**这些不管什么模板都一样。** 抽出来才是"基础设施"。

## 八、一句话

**画布引擎是基础设施，画布模板是产品形态，画布实例是用户的东西。**

我前面的示例全是「漫剧画布」这个模板——**它不等于画布本身。**
