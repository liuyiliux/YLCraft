## 三、对齐后的模型

```
┌── L1 基础功能 ───────────────────────────────────┐
│  一个点，无复杂逻辑                                │
│  裁剪 / 滤镜 / 缩放 / 压缩                          │
│  AI 生图（一次调用）                                │
│  图生 3D（一次调用）                                │
│  AI 优化提示词 / OCR / 抠图                         │
│  代码里 = 一个 API 或一个函数                       │
└────────────────────┬────────────────────────────┘
                     │ 页面把多个基础功能拼起来
                     ▼
┌── L2 页面组合 ───────────────────────────────────┐
│  一个页面上拼接了功能                               │
│  「创建项目」= 基本信息 + 生产配置 + 分阶段进度       │
│  「生图页面」= 模型 + 参考图 + 参数 + 批量 + 动图     │
│  「3D 工作台」= 导入 + 绑骨 + 动画 + 导出           │
│  「3D 导演台」= 场景 + 人偶 + 姿势 + 关键帧          │
│  代码里 = 一个页面（44 个路由里的一个）              │
└────────────────────┬────────────────────────────┘
                     │ 画布把基础节点和复杂节点拼起来
                     ▼
┌── L3 画布 ───────────────────────────────────────┐
│  用【基础节点】和【复杂节点】拼接                   │
│                                                   │
│  基础节点 = L1 的一个功能包成节点                   │
│  复杂节点 = L2 的一个页面包成节点                   │
│                                                   │
│  例：剧本 → 分镜 → [基础:生图]×12 → [复杂:@动图]   │
│                    ↘ [基础:图生3D] → [复杂:@3D导演台]│
└───────────────────────────────────────────────────┘
```

## 四、关键：画布上同一种能力有两档

**以"生图"为例：**

### 基础节点（简单链用这个）
```
┌ 生图 ────────┐
│ 输入 prompt   │
│ 参数 比例     │
│ 输出 图片     │
└──────────────┘
```
**一个点。用起来快，但不带批量/参考图/风格。**

### 复杂节点（一整步用这个）
```
┌ @生图工作台 ──────────────┐
│ 输入 prompt + 参考图 ×N    │
│ 参数 模型 / 比例 / 张数     │
│      风格 / AI优化 / 动图开关│
│ 输出 图片 ×N               │
│                          │
│ [打开完整页面]             │
└──────────────────────────┘
```
**一步到位。参数多，但不用自己连。**

**用户按需要选：简单的事用基础节点，复杂的事用复杂节点。**

## 六、所以画布的节点库应该是两栏

```
节点库
├─ 基础节点（L1）
│   文本 / 图片 / 视频 / 音频 / 脚本
│   裁剪 / 滤镜 / 放大
│   AI 生图 / 图生 3D / 抠图 / 提示词优化
└─ 复杂节点（L2 · 页面包装）
    @ 生图工作台
    @ 动图工作台
    @ 3D 工作台
    @ 3D 导演台
    @ 视频生成
    @ 剪辑出片
```

**加新用途的两条路：**
1. 加一个基础节点（写新 API 封装）
2. 🔴 **把已有页面包成复杂节点（只写适配层，页面不动）**

**第 2 条是我们最大的杠杆 —— 44 个页面已经在了。**
