# 两种画布：自由画布 + 镜头序列（2026-10-19）

> 你问：**能不能既有 Lovart 那种自由画布（Coser/摄影/电商），又有漫剧那种带顺序的工作流？**
>
> **能。而且这是唯一正确的做法 —— 但我上一版把"两种活"混成了一个界面，那是错的。**

---

## 一、核心判断：两种活，复杂度根本不同

| | **单张成品类** | **多镜连续类** |
| --- | --- | --- |
| 典型用户 | Coser 修图 / 摄影师调色 / 电商做主图 | 漫剧 / 短剧创作者 |
| 一次要做几张 | 1 张（或几张备选） | **10~40 个镜头** |
| 有顺序吗 | ❌ 没有，"这张好看"就行 | ✅ 有，"第 1 镜→第 2 镜" |
| 要跨图一致吗 | ❌ 不需要 | ✅ 角色/场景必须一致 |
| 每张的步骤 | 1~2 步（出图→修） | **5~10 步**（提取→角色→剧本→分镜→出图→出片） |
| 需要浪费在哪 | 精细调整 | **批量 + 一致性 + 可控** |
| **需要工作流吗** | 🔴 **不需要** | ✅ **需要，但用户不该看见** |

**这就是为什么 Lovart 能纯对话** —— 它的活本来就简单，一两步，天然不需要"结构"。

**这也是为什么我们做漫剧必须有引擎** —— 十步链路靠舌头说不清、复不了现。

> 🔴 **所以不是"要不要工作流"，是"哪种活需要工作流"。**

## 三、为什么这样不冲突（跟上一版的区别）

上一版的问题是：**一个界面里同时有节点图和 Agent**，用户不知道看哪儿。

这版是：**一个模式里只有一个心智模型。**

| 模式 | 用户心智 | 看到的东西 | 看不到的东西 |
| --- | --- | --- | --- |
| **自由画布** | "我把图摆好看，点开修" | 图片 | 引擎、节点（**根本不存在**） |
| **镜头序列** | "我排出镜头，逐个改" | 镜头格子 + 顺序 | 节点图（藏在高级） |
| **流程视图** | "我改这条管线" | 节点图 | — |

**自由画布模式下节点图是"不存在的"，不是"藏起来"** —— 因为这类活真的只有 1~2 步，硬套节点图是过度设计。

---

## 四、模式怎么定（不让用户每次切）

**在新建时由模板决定，用户只需要选"我要做什么"。**

```
新建画布
  ├─ 「修一张图」           → 自由画布
  ├─ 「做个电商主图」        → 自由画布
  ├─ 「Cosplay 精修」       → 自由画布
  ├─ 「做一集短剧」          → 镜头序列
  ├─ 「做漫画分镜」          → 镜头序列
  └─ 「我自己搭」            → 自由画布（默认）
```

**顶栏只在高级里给一个切换**：`高级 ▾ → 切换为镜头序列 / 切换到流程视图`

> 因为**一个自由画布可以中途升级成镜头的**（用户先随便摆，后来发现要做成片子）。
> 反过来也允许，但会提示"顺序会丢"。

## 五、各模式的具体界面

### ① 自由画布（Coser / 摄影 / 电商）

```
┌──────────────────────────────────────────────┬───────────────┐
│  未命名画布 / 画布 1   ●已保存    [自由画布]    │  Agent         │
├──────────────────────────────────────────────┤               │
│                                              │ 你说"把这张脸   │
│   ┌────────┐   ┌────────┐                   │  磨皮，背景换成  │
│   │  图 1   │   │  图 2   │   ┌────────┐     │  赛博朋克"      │
│   └────────┘   └────────┘   │  图 3   │     │               │
│                              └────────┘     │  ✓ 已完成       │
│        ┌────────┐                            │               │
│        │  图 4   │                            │  ┌──────────┐ │
│        └────────┘                            │  │描述你的想法│ │
│                                              │  └──────────┘ │
├──────────────────────────────────────────────┤               │
│ 选择 | 画笔 | 文字 | 形状 | 上传              │               │
└──────────────────────────────────────────────┴───────────────┘
```

**交互**：
- 图自由摆放、可拖、可缩放、可叠
- **点图 → 放大居中**
- 放大后：右键 `局部重绘 / 扩展 / 抠主体 / 换背景 / 多角度`
- 顶部：`重新打光 / 保存到素材库`
- **没有端口、没有连线、没有节点**

**这基本就是 Lovart。**

### ② 镜头序列（漫剧 / 短剧）

```
┌──────────────────────────────────────────────┬───────────────┐
│  我的短剧 / 第 3 集    ●已保存   [镜头序列]     │  Agent         │
├──────────────────────────────────────────────┤               │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐        │ 你说"第 2 镜拆  │
│  │ 01│ │ 02│ │ 03│ │ 04│ │ 05│ │ 06│        │  成中景和特写"  │
│  │[图]│ │[图]│ │[图]│ │[图]│ │[图]│ │[图]│        │               │
│  │中景│ │近景│ │特写│ │全景│ │中景│ │过场│        │  ✓ 已完成       │
│  └───┘ └───┘ └───┘ └───┘ └───┘ └───┘        │               │
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐        │  结论/做了什么   │
│  │ 07│ │ 08│ │ 09│ │ 10│ │ 11│ │ 12│        │  没做什么/需要你 │
│  └───┘ └───┘ └───┘ └───┘ └───┘ └───┘        │  自检 chips     │
│                                              │               │
├──────────────────────────────────────────────┤  ┌──────────┐ │
│ ▶ ├──────────●─────────────────────┤ 00:42  │  │描述你的想法│ │
└──────────────────────────────────────────────┴───────────────┘
```

**交互**：
- **镜头墙**：格子 + 镜号，一眼看全片节奏
- **点镜 → 放大居中** → 就地编辑（同自由画布）
- 底部时间线（可选）：看时长、播放
- **顺序是显式的**：拖动能换镜号，插入会自动重排
- 一致性靠 Agent 检查（"第 5 镜角色不像，要重出吗"）

**这版没有节点图** —— 但底层是真的在跑节点。

### ③ 流程视图（高级，两者都能进）

```
顶栏：[自由画布] 或 [镜头序列]        [高级 ▾ → 看流程]
```

点进去才看到节点图。用来：
- 改流程顺序
- 看哪步失败
- 把这套存成模板
- 算成本

## 六、技术现状：三种里我们已经有两种

| 模式 | 现状 |
| --- | --- |
| **① 自由画布** | 🟢 **基本已有** —— `InfiniteCanvasSurface` 本来就是无限画布（上游就是"面向 AI 创作的无限画布工作台"） |
| **② 镜头序列** | 🔴 **要新做** —— 镜头墙 + 镜号 + 顺序 + 时间线 |
| **③ 流程视图** | 🟢 **已有** —— 节点 + 端口 + 连线 + WorkflowTrace 都在 |

> 💡 **这是个好消息**：自由画布是我们**最早有的东西**，节点图是后来加的。
> 现在等于"把节点图降级成高级，把自由画布还原成主界面之一"，再加一个镜头序列。

## 七、一个必须想清的问题

**自由画布模式下，Agent 怎么改图？**

| 方案 | 说明 |
| --- | --- |
| **A. 直接改画布对象** | Agent 输出"把图 2 换成这张新图"、"在右下角加一张" —— 像 Lovart |
| **B. 先出图再让用户放** | Agent 只出图，用户自己拖到位置 |
| **C. 混合** | 默认 A；用户说"我自己来"就 B |

**我建议 A 为主** —— 这就是 Lovart 那种"对话直接出图在画布上"的感觉。

**但要有边界**：Agent **不能自动删**你的图，只能加和改（删要确认）。

## 九、我先做什么

**建议：先做「自由画布」原型。**

理由：
1. 改动最小 —— 现有 `InfiniteCanvasSurface` 直接能用
2. 能立刻验证 Lovart 那套"对话出图 + 点图放大编辑"对不对
3. 镜头序列是新东西，等这版确认了再做，避免又白做

**做完自由画布，再回来做镜头序列，两个原型并排放着对比。**
