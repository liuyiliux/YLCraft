## 决策 1：复杂节点允许"解锁进入页面" ✅ 采纳

**范式**：Houdini Digital Asset —— 节点默认锁定，只露提升的参数；需要时"解锁"进内部改。

**我们的映射**：

| Houdini | 我们 |
| --- | --- |
| 节点界面露出 promoted parameters | 复杂节点上直接改 ≤3 个常用参数 |
| 解锁进入内部网络 | 「打开完整页面」→ 跳 `/image-gen` 等，带上当前参数 |
| 改完回节点 | 页面改完，参数和产物回填到节点 |

**实现**：节点底部 `[▶ 运行] [打开完整页面 ↗]` 两个按钮（原型已有）。

## 决策 2：用户打的组用 Tab 进出 ✅ 采纳并已实现

**范式**：Blender Node Group —— `Ctrl+G` 打组，**`Tab` 进出**（不是双击，双击容易跟"打开属性"冲突）。

**已实现**（`canvas_unified_v14.html`）：

| 操作 | 行为 |
| --- | --- |
| `Shift + 点节点` | 多选（节点左上角打勾） |
| 顶栏出现「已选 N 个节点 [打组] [取消]」 | — |
| 点「打组」 | 折叠成一个「我的流程」组节点（虚琥珀边框，标 N 个节点 · Tab 进入） |
| **`Tab`** | 进入组：展开成员，顶栏显示「在组内 [Tab 退出]」 |
| **`Tab`**（再按） | 退出组：收回去 |

**实测**：
```
nodes 18 -打组-> 16  (usergrp=true)
        -Tab进入-> 18  (顶栏"在组「我的流程」内部")
        -Tab退出-> 16
```

**约束**：
- 组里不能再套组（提示）
- 打组时跨边界的连线自动改接到组节点
- 退出时保存成员的新位置和状态

**未实现**：组的命名（现在写死"我的流程"）、组的保存/复用、组内新增节点后回写的边界边。

## 决策 3：模板升级 = 默认快照 + 手动升级 ✅ 采纳

**为什么不能全变**：n8n 的子工作流是"改了子流程，所有引用处全变"——方便但危险：
别人改了模板，我的画布会被打坏。

**定案**：

```
新建用模板 → 存的是那一刻的快照
       ↓
模板作者更新了 → 我的画布不变
       ↓
我看到「模板有新版 · 升级」→ 点了才变（会提示哪些参数会变）
```

**实现要点**（未做）：
- `CanvasDocument.template_ref = { template_id, version }`
- 打开画布时对比最新版，有新版在顶栏挂一个提示
- 升级前 diff：哪些节点会加/删/改参数

## 决策 4：给"不想看节点的人"单独的 Skill 表单入口 ✅ 采纳

**范式**：Lovart Skill —— 用户看到的是「美妆海报」这个**按钮**，点开是表单，
**连节点概念都没有**。

**为什么要**：`PLATFORM_REBUILD_BASELINE.md` P1「门槛优先于能力」。
不是所有人都要学节点图。

**三条入口并存**：

| 入口 | 用户看到 | 适合 |
| --- | --- | --- |
| **Skill 表单** | 按钮 → 表单 → 产物 | 完全不想学的人 |
| **画布·基础节点** | 节点 + 端口 | 想控细节的人 |
| **画布·复杂节点** | 节点（只露 3 参数）→ 点开是页面 | 想搭流程但不想配参数的人 |

**实现要点**（未做）：
- `Skill` 数据：`{ id, label, icon, fields:[...], invoke }`
- 首页/画布空态给「快速开始」区，列 4~6 个 Skill
- Skill 和复杂节点**共用同一个 `invoke`**（同一份后端能力）
