# 一、巧摄（PlanIt）—— 官方原文

## 1.1 产品线（已从官网核实）

巧摄**不是一个 App，是一个产品矩阵**（来源：[planitphoto.com](https://www.planitphoto.com)）：

| 产品 | 定位 | 平台 |
|---|---|---|
| **PlanIt Earth** | 主打，PlanIt Pro 的下一代。风光 + 天文摄影规划，太阳/月亮/银河/日食/卫星，任意地点任意日期 | iOS / Android / **HarmonyOS 5.0+** / macOS / Windows / **Web** |
| **PlanIt Live** | 现场伴侣，管「此刻此地」——时机、银河、潮汐、极光 | 移动端 |
| **PlanIt Pro** | 原版规划器，有 **VR 取景框** | **仅 iOS/Android**（手机平板） |
| AstroCameraProbe | 辅助工具，扫描相机参数提交给团队 | |

**关键信息**：官网明说 **「PlanIt Pro will eventually be replaced by PlanIt Earth」**（Pro 最终会被 Earth 取代）。

## 1.2 ⭐ 完整功能清单（App Store 官方描述原文）

> 「任何地点的 **GPS 坐标、海拔高度、两点距离、海拔高度差、以及从某一点是否可以看到某个景点**。」
>
> 「专门提供了**焦距**（水平方向和垂直方向）、**景深、超焦距和全景工具**。」
>
> 「**星历表**功能……可以查到**任何一天任何地点的日出日落时间、月出月落时间、曙暮光开始结束时间、黄金时段、蓝色时段**。甚至**任何时刻的太阳和月亮的位置**你都可以查到。还有**星星、星座、银河、星云**的位置。」
>
> 「**星轨计算器**和**延时摄影计算器**功能，**曝光自动计算**，**ND滤镜计算器**，**光度计**，**彩虹位置预测**，部分国家的**潮汐数据**。」
>
> 「和其它类似应用不同的是，我们这个应用把上面提到的所有功能都在**地图上或者取景框方式下直观地显示出来**，各个功能之间还可以**结合使用**。」
>
> 「只要您预装**离线海拔文件和离线 mbtiles 地图**，您可以**完全离线使用**。」

### 结构化后的能力表

| 类别 | 具体能力 |
|---|---|
| **位置** | GPS 坐标、海拔、两点距离、**海拔高度差**、**从某点能否看到某景点** |
| **光学** | 焦距（水平/垂直）、景深、超焦距、全景工具 |
| **天文** | 日出日落、月出月落、曙暮光、**黄金时段**、**蓝色时段**、任意时刻日月位置、星星/星座/银河/星云位置 |
| **计算器** | 星轨计算器、延时摄影计算器、曝光自动计算、ND 滤镜计算器、光度计、彩虹位置预测、潮汐数据 |
| **可视化** | 地图叠加、**取景框（VR）方式**、功能可**组合使用** |
| **离线** | **离线海拔文件 + 离线 mbtiles 地图，完全离线可用** |

## 1.3 ⭐⭐ 最关键的一条：它怎么解决地形遮挡

**官方原文**：
> 「**从某一点是否可以看到某个景点**」（line-of-sight）
>
> 「预装**离线海拔文件**」

**结论**：
- 巧摄的遮挡能力建立在自己打包的**离线海拔数据**上
- 提供的是「**A 点到 B 点是否可见**」这类**视线判断**
- **没有说它做建筑遮挡**——海拔文件是地形，不含建筑

> 这和我们的实测一致：我们的地形仰角算法（Open-Elevation 采样）做的就是同一个事，
> 巧摄把它做成了离线的、内置的。

> 以及『**机位攻略**』为核心差异点。」

> 搭配**蓝白框线构图引导**，实现**一键拍摄 Live 实况大片**，
> 精准解决年轻人『**不会摆姿势、构图能力弱**』的痛点。」
>
> 「**二是，机位地图**，**基于地理位置聚合全球优质拍照点位**，
> 配套**用户实拍成片、详细机位说明及一键导航**功能，
> 无需跨平台搜索攻略，实现『**找机位、拍大片**』的闭环体验。」

### 结构化

| 功能 | 具体做什么 |
|---|---|
| **AI 灵感跟拍** | 扫描场景 → **自动推荐姿势模板** → **蓝白框线构图引导** → 一键拍 Live 实况 |
| **机位地图** | 按地理位置聚合**全球拍照点位** + **用户实拍成片** + **机位说明** + **一键导航** |

**用户原话**（媒体引用）：
> 「现在出门拍照必打开可颂，**机位地图能直接导航到最佳拍摄点**，
> AI灵感跟拍再也不用麻烦朋友帮忙，手残党也能轻松拍出氛围感大片。」

## 2.3 ⚠️⚠️ 这和我们高度重叠——必须正视

| 可颂做的 | 我们在做的 | 重叠度 |
|---|---|---|
| **AI 推荐姿势模板** | **口令库 / 姿势参考** | **🔴 高** |
| **机位地图 + 导航** | 地点知识 + 机位 | **🔴 高** |
| **蓝白框线构图引导** | 构图参考 | 🟡 中 |
| 用户实拍成片 + 机位说明 | 作品库 + 反思库 | 🟡 中 |

### 但关键差异在我们这边

| 维度 | 可颂 | 我们 |
|---|---|---|
| 用户 | **C 端大众**（手残党、普通用户） | **职业/半职业摄影师** |
| 姿势 | **给模板照着摆** | **给口令说出来**（这是本质区别） |
| 机位 | 用户上传的 POI | **算出来的**（太阳方位+地形遮挡） |
| 商业模式 | 无（砍掉电商，纯工具） | 待定 |
| 深度 | 轻（3秒出片） | 重（整套工作流） |

> **可颂解决的是「我不会摆姿势」。**
> **我们解决的是「我该怎么让她摆」——摄影师给客户引导。**
>
> 前者是**照着摆**，后者是**说出来**。这是两件事。

## 2.4 ⚠️ 可颂的隐忧（媒体分析，值得参考）

> 「当前可颂的内容生态呈现明显的『**工具化导向**』……**缺乏情感化、生活化内容沉淀**，
> 用户互动多集中于『教程询问』『机位求更』，**缺乏深度讨论与社交连接**。」
>
> 「可颂若长期无法摆脱『工具属性大于社区属性』的困境，
> 用户可能仅在有拍照需求时**临时使用**，难以形成长期留存。」

> 这对我们的含义：**纯工具型产品有留存问题**。
> 我们做的「反思库」和「作品库」正好是对抗这个的——它们随时间增值。

# 五、⭐ 最重要的结论

## 5.1 技术链路我们完全能自己实现（逐环节验证过）

```
Nominatim 地理编码 → NOAA 算太阳方位高度
→ Open-Elevation 沿方位采样算地形仰角
→ 太阳高度 vs 地形仰角 → 能不能拍到光
→ 太阳方位 vs 拍摄方向 → 是不是逆光
→ 输出「几点站哪朝哪拍」
```

**全链路公开数据 + 纯计算，免费可跑通。**

## 5.2 竞争格局的真实位置

| 产品 | 做什么 | 不做什么 |
|---|---|---|
| **巧摄** | 风光/天文规划（日月银河日食卫星） | **人像、引导口令、建筑遮挡** |
| **可颂** | AI 姿势模板 + 机位地图 + 导航 | **专业工作流、口令、反思** |
| **Cue & Capture** | 婚礼引导口令 | 中文、太阳计算、机位 |
| **Eagle/PureRef** | 存参考图 | 一切规划 |

**空位**：
> **人像 + 算出来的光线 + 说出口的口令 + 参考对照 + 元素清单**
> 五个都没有竞品同时做。

## 5.3 但要正视可颂的威胁

**可颂的「AI 推荐姿势模板」和「机位地图」直接覆盖了我们的一部分价值。**

**我们的差异必须落在**：
1. **口令 ≠ 姿势模板**（说出来 vs 照着摆）
2. **机位是算出来的**（太阳方位+地形）而不是用户上传的
3. **整套工作流**（策划→现场→修图→反思）而不是单点工具
4. **专业摄影师**而不是 C 端大众

# 六、给产品的具体建议

## 6.1 立刻能做

1. **Open-Elevation + Nominatim 接后端** → 做地点光线 API
2. **地形遮挡已跑通**，可以产品化
3. **建筑遮挡先不做**（数据难，巧摄也没做）

## 6.2 不要做

- ❌ **不要做天文摄影**（巧摄做到极致了：日月银河日食卫星）
- ❌ **不要做 C 端姿势模板**（可颂在做，而且它有抖音流量）
- ❌ **不要做通用摄影社区**（小红书/图虫/米拍）
- ❌ **不要做机位 UGC 地图**（可颂已经在做）

## 6.3 差异化必须坚持

| 我们的 | 为什么别人做不了/不做 |
|---|---|
| **口令库（中文、分人群）** | Cue&Capture 只有英文婚礼；可颂是模板不是话术 |
| **算出来的光线** | 巧摄算的是大尺度风光，不做「这个人在这个位置的光」 |
| **反思库（触发条件）** | 没有任何竞品做「下次别忘了」 |
| **参考 vs 实拍对照** | 调查过的产品全都没有 |
| **元素清单工作流** | 巧摄/可颂都是单点工具 |
