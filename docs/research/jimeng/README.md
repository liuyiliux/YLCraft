## 四、和我们的原型对照

⚠️ **先分清是哪个原型**。我们有两套，布局完全不同：

| | 布局 | 对话在哪 |
|---|---|---|
| **画布原型** `canvas/index.html` | 画布 `#stage` 1180px + 右侧 `.ag` 面板 **420px** | **右边** ✅ 与即梦同向 |
| **Agent 页原型** `photo-ref/agent-page.html` | 左对话栏 246 / 中主区 / 右面板 400 | 左边（多对话按项目分组）|

**所以「即梦画布在左、对话在右」对我们不构成反差** —— 我们的画布原型本来就是这样，
而且面板更宽（420 vs 300）。第一版对照表拿 Agent 页去比，写「左右反转」是错的，已更正。

### 画布页：即梦 vs 我们（截图 `03_canvas.png` / `04_canvas_chat.png` vs
`docs/screenshots/canvas-prototype-2026-11-01.png`）

| 项 | 即梦 | 我们画布原型 | 谁更完整 |
|---|---|---|---|
| 布局 | 画布左 + 对话右 300px | 画布左 + 智能体右 **420px** | 我们面板更大 |
| 空态标题 | 这次创作想从哪里开始？ | 从一个想法开始 | 即梦是**问句**，我们是**结论** |
| 空态入口 | **2 个**（本地上传 / 选择资产）| **4 个**（写剧本拆分镜 / 上传参考 / 用模板 / 直接说）| **我们** |
| 右面板结构 | 只有一个对话 | 对话 + **制作实况** 两个 tab | **我们**（多一层）|
| 面板头 | `未命名对话 ▾` + 筛选/清空/更多 三个图标 | 智能体 + 设置 | 即梦的清空/筛选更实用 |
| 底部输入 | placeholder 带模型名 | `说你想做什么，或用 @ 引用素材` + `2:3 · GPT Image 2 · @ 引用 · 更多 · ⚡14` | **我们**（比例/模型/消耗都在）|
| 工具条位置 | **左侧竖排 4 个**（上传/图片/网格/文字）| **顶部横排**（工作台/技能/模板/本地调整/RAW/质检/出片）| 两套思路，我们功能多 |
| 技能入口 | 输入框 `/` + 技能弹层 | 顶部「技能」按钮 | ✅ **已对齐**（2026-11-01：两个原型都加了 `/` 触发）|

### Agent 页：即梦首页 vs 我们（两回事，别硬套）

| 维度 | 即梦首页 | 我们 Agent 页 | 说明 |
|---|---|---|---|
| 生成 / 画布 两视图 | 顶部 segment | `[创作] [画布]` tab | ✅ 同一思路 |
| 技能弹层方向 | 输入框**下方** | 门禁 J 节原写"上方" | ⚠️ 已更正门禁 |
| 左栏 | 导航 + 对话列表 + 画布列表 | 对话（按项目分组）| 即梦导航与列表混在一条，我们分得更开 |
| 空态给什么 | **素材入口** | **4 张任务卡** | 它是"我有素材"，我们是"帮我干活" |
| 输入框 placeholder | 带模型名 + 教用法 | 只有「继续说…」 | 可借鉴 |

**结论**：画布页我们和即梦同一套路且更细；Agent 页的「左对话」是两个产品的定位差异
（它是单会话面板，我们是多线程按项目分组），不是谁对谁错。

## 六、抓取方式（留给下一个人）

用 `bsk`（browser-skill）连本机已登录的 Chrome，**新开 Agent Window** 抓：

```powershell
bsk session start --name xxx --width 1600 --height 1000 --no-focus
bsk navigate --session <SID> "<url>"      # 空白页时不需要上下文
bsk screenshot --session <SID> --out <path>
```

**两个坑**：

1. 即梦顶部有个**每秒刷新的倒计时**，导致 `bsk` 的「页面已同步」校验永远失败 ——
   任何 `click` 都会报 `The action's observed content changed`。
   → 想点击只能**先开新空白会话 → navigate → 立刻点**（页面还没开始动），或换个不依赖快照的工具。
2. `bsk` 的 `cooperate sync` 一次只授权一个动作，动作后要重新 sync；`--depends-on` 声明
   目标区域能容忍**部分**无关变化，但容忍不了全页每秒变。
