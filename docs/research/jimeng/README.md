## 四、和我们 Agent 页原型的对照

| 维度 | 即梦 | 我们原型 | 判断 |
|---|---|---|---|
| 生成 / 画布 两视图 | 顶部 segment 切换 | 顶部 `[创作] [画布]` tab | ✅ 一致 |
| **画布与对话的位置** | **画布在左、对话在右** | 左对话 / 中主区 / 右面板 | ⚠️ **左右反转**，要讨论 |
| 技能弹层方向 | 输入框**下方** | 门禁写"上方" | ⚠️ 更正门禁 |
| 输入框 placeholder | 带模型名 + 教用法 | 只有「继续说…」 | 可借鉴（门禁铁律 7：参数要么真生效要么别显示）|
| 空态给什么 | **素材入口**（本地上传 / 选择资产）| **4 张任务卡** | 两种思路：它是"我有素材"，我们是"帮我干活" |
| 左导航 | 6 项 + 主体一级 + 对话/画布列表 | 7 项横向（概览→发布运营）| 它是纯创作工具，我们是平台 |
| 技能 | `/` 触发 + 弹层搜索 + 官方标记 | 原型还没有技能入口 | ❌ **我们还缺** |

## 六、抓取方式（留给下一个人）

用 `bsk`（browser-skill）连本机已登录的 Chrome，**新开 Agent Window** 抓：

```powershell
bsk session start --name xxx --width 1600 --height 1000 --no-focus
bsk navigate --session <SID> "<url>"      # 空白页时不需要上下文
bsk screenshot --session <SID> --out <path>
```

**两个坑**：

1. 即梦顶部有个**每秒刷新的倒计时**，导致 `bsk` 的「页面已同步」校验永远失败 ——
   任何 `click` 都会报 `The action's observed content changed`。
   → 想点击只能**先开新空白会话 → navigate → 立刻点**（页面还没开始动），或换个不依赖快照的工具。
2. `bsk` 的 `cooperate sync` 一次只授权一个动作，动作后要重新 sync；`--depends-on` 声明
   目标区域能容忍**部分**无关变化，但容忍不了全页每秒变。
