## 二、🔴 为什么会"每次都要你提醒"

### 根因（三个）

**① 结论散在 40 份文档里，没有一张总表**
每次要看"某某平台的某某做法我们抄了没"，得翻文档。

**② "调研"和"决策"没有硬链接**
我写了调研文档，但决策的时候**不会自动去查它**。

**③ 没有"还欠什么"的清单**
采纳的记住了，没采纳的忘了。于是同一个东西可能被重复调研。

| 项 | 内容 |

| **对象** | `workrally.qq.com` · 页面标题自称「漫剧视频创作全流程 - 腾讯视频智能制作平台」· **公开可访问**（实测） |

| **它的骨架** | 导航就是四段流水线：**1 剧本创作 → 2 资产库 → 3 批量制作 → 4 智能剪辑**，无限画布 / Agent配置 是横向能力 |

| ⚠️ 抓取坑 | 微信对非浏览器客户端返回「环境异常」验证页，**WebFetch 抓不到**，必须用本机登录浏览器读 |

### 采纳了什么

| 采纳 | 怎么用 |
| --- | --- |
| ✅ **资产库 = 生成时的输入，不是仓库** | 它靠「已确认素材入库 → 后续用『参考主体』方式生成」锁一致性。我们 `asset_hub` 现在只是存，**没当生成输入用** —— 这是最实质的形态差距 |
| ✅ **音色也是资产** | 角色说话视频 → 导出 WAV → 入角色资产库 → 后续复用。我们讨论一致性只想过画面，没想到声音 |
| ✅ **入库判据是「跨镜头复现」** | 不是「是不是人」—— 片里的龙、反复出现的道具和场景都入库 |
| ✅ **角色先定正面，再出三视图备用** | 三视图是后续所有镜头的参考物 |
| ✅ **先参考搜索再出图** | 出图前查实物参考，防常识错误（季节、农作物形态、人稻比例） |
| ✅ **多接口来回切是正常操作** | GPT-image2 / Nano Banana / 元宝 / 三谦 各有擅长，同一指令不同接口结果不同，达不到就换 |
| ✅ **生成片段统一禁 BGM** | 只要说话声和音效，音乐留到配乐环节统一做 |
| ✅ **无声模型 → 参考主体补音效** | Zen-07 出形变（无声）→ 拿成片当主体参考换 Zen-SD2.0 重跑补声音。两段式串模型，不限于视频 |
