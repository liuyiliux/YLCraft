# 一、OpenMontage（242 行，最贴近我们定位）

## 一句话

**第一个开源的 Agent 驱动视频生产系统。它的很多设计正好回答我们的问题。**
⚠️ **AGPL-3.0，只能学思路不能抄代码。**

## 🔴 最有价值的一条：对话 vs 制作实况要分开

> 「Chat tells you what the agent **said**. Backlot shows you what the production
> is actually **doing**.」

**对话告诉你 Agent 说了什么；Backlot 告诉你制作实际在做什么。**

**这正是我们 Agent 页面的病根**：现在只有对话，把过程压成文字摘要。

## 架构：三层知识

| 层 | 位置 | 回答 |
| --- | --- | --- |
| L1 | `tools/` + `pipeline_defs/` | **What exists** 有什么能力 |
| L2 | `skills/` | **How to use it** 本项目怎么用 |
| L3 | `.agents/skills/` | **How it works** 外部技术原理 |

🔴 **它用的就是 `.agents/skills/` 约定 —— 和我们完全一致。**

## 生产治理（最值得学）

| 机制 | 原文要点 | 我们的差距 |
| --- | --- | --- |
| **人工批准是强制的** | 「Human approval gates are **enforced, not suggested**」<br>checkpoint writer **拒绝**没有批准记录的完成态 | 我们有确认流程，但**点了不生效** |
| **Pre-compose 校验** | 违背交付承诺 → **阻止渲染**，「在浪费 GPU 前抓出坏计划」 | 无 |
| **Post-render 自审** | ffprobe + 4 处抽帧 + 音频电平，**失败则不展示** | 无 |
| **Slideshow 风险评分** | 6 维分析防"动画版 PPT" | 无 |
| **供应商 7 维打分** | task fit 30% / quality 20% / control 15% / reliability 15% / cost 10% / latency 5% / continuity 5%<br>**赢家和落选者都记日志** | 有 provider 选择，无打分 |
| **决策审计链** | 每个选择都记 **alternatives + confidence + reasoning** | 有日志，无"为什么选它" |
| **预算治理** | Estimate → Reserve → Reconcile；observe/warn/cap 三档 | 有 CostMeter，无门禁 |

## 采纳决定

| 抄什么 | 决定 | 理由 |
| --- | --- | --- |
| **对话 vs 制作实况分开** | ✅ **P0** | 直接治我们"Agent 不在点" |
| 门禁强制（不批准就不许过） | ✅ **P0** | 我们现在的确认按钮点了不生效 |
| Post-render 自审 | ✅ P1 | ffmpeg 已在用，能复用 |
| 供应商 7 维打分 | 🟡 P2 | 我们现在只有 2-3 家，打分收益小 |
| 决策审计链（记为什么） | ✅ P1 | 和"引用留痕"同一个思路 |
| 预算 Estimate/Reserve/Reconcile | 🟡 P2 | 自用阶段先简单 |
| Backlot 看板 | ✅ P1 | 「derive everything from project files」思路可抄 |

## ⚠️ 许可

**AGPL-3.0 强传染**：抄代码可能要求我们整体开源。
**只能学设计，不能抄代码。**

# 二、RunningHub / 仙宫云（184 行）

## RunningHub 是什么

**ComfyUI 工作流市场 + 漫剧创作平台。**
🔴 **它的漫剧功能和我们的重合度最高。**

| RHSTORY 的功能 | 我们的对应物 |
| --- | --- |
| AI 漫剧 文案自动生成提示词 | `comic_image_prompt` skill |
| AI 漫剧 批量资产创建 | 角色库 / 资产中枢 |
| AI 漫剧 批量分镜图生成 | `storyboard-generation` |

**又一次"竞品已实现"的发现。**

## 🔴 最有价值的一条：**工作流本身就是商品**

> 「由全球创作者基于 ComfyUI 打造」
> **创作者发布、用户直接运行、创作者拿收益分成。**

热门工作流标题就是产品名：
- 一键生成多角色对话动画片
- AI唱歌数字人对口型
- QWEN3VL + NEXT SCENE（自动分镜）
- 电商详情页生成 V3（直出 10 张）

**这是"作品/工作流即资产"的模式** —— 和 LibTV 的「审美资产」、像素蛋糕的「第三方创作者工具包」是**同一个模式**。

🔴 **三家的共同结论**：
> **做工具的终极形态不是卖工具，是让用户互相卖工作流。**

## 商业模式观察到什么

| 手段 | 说明 |
| --- | --- |
| 会员分层 | 最高立减 2000 元 |
| 积分/币 | RH 币 |
| 创作者激励 + 收益榜 | 让创作者赚钱 |

🔴 **「限时免费时段」聪明在**：把**闲置算力**变成用户福利。
（我们自用不需要，但如果对外可以是思路）

- 按量计费，部署不计费
- 社区镜像（创作者分享整套运行环境）

**和我们关系不大**，除非我们自建模型推理。

| 抄什么 | 决定 |

# 三、深海导演（334 行，BeefTV 最热技能，2,372 次使用 / 469 赞）

## 它是什么

**BeefTV 排名第一的技能：《叙事短片导演分场》，9 个 Phase。**

## 🔴 六个可直接搬的机制

### 3.1 导演意图书（结构化创作意图）

```
【基本信息】作品名 / 集数·场次 / 导演
【叙事目标】核心事件 / 观众情绪目标 / 情绪曲线 / 关键信息揭示
【视觉目标】视觉基调 / 主色调 / 核心镜头语言 / 禁止出现
【声音目标】环境音 / 音乐风格 / 音画关系 / 关键声音时刻
【节奏目标】目标时长 / 节奏型 / 镜头密度 / 节奏标记
【特殊指示】道具锚点 / AI生成重点 / 自检点
```

**「禁止出现」字段很关键** —— 视觉目标里既有要什么，也有**不要什么**。

### 3.2 导演三问

1. 这场戏**观众知道什么，角色不知道什么**？（→ 悬念）
2. 这场戏想让观众**感受到什么情绪**？（→ 景别/光线/色彩）
3. 这场戏的"电影感"**来自什么**？（→ 区别于小说/话剧的表达）

### 3.3 🔴🔴 「叙事目的」强制字段 —— 最有价值的一条

九列分镜表（实际十列），最后一列是**叙事目的**：

> 「看到某场戏 → 问这个镜头的叙事目的是什么？
> **答不上来 → 考虑删除或合并**；
> 答得上来 → 这个目的是否最优？」

七种分类：建立 / 推进 / 揭示 / 强调 / 过渡 / 情绪 / 反射

### 3.4 🔴🔴🔴 好/坏写法对照 —— 这段最该抄

**好写法**（具体到视听手段）：
> ✅「用**背对背构图**展现两人关系的疏离感，为后续冲突做铺垫」
> ✅「**视觉奇观升华主旨**，将个体行为扩展为群体现象，隐喻现代都市的复制性」

**坏写法**：
> ❌「展现角色的内心矛盾」（**没说怎么展现**）
> ❌「推进剧情发展」（所有镜头都在推进）
> ❌「表达主题」（主题是结果不是目的）

🔴 **这解决了 AI 写文档最大的病：写空话。**
不是要求"要具体"，而是**直接给正反例**。

### 3.5 🔴 技巧库带「AI 适配度星级」

30 个技法，每条都标：

```
★★★★★ 极易实现（已有大量训练数据）
★★★★  较易（需精确描述镜头参数）
★★★   可实现（需复杂提示词）
★★    需后期处理或特殊技术
```

举例：
| 技法 | 星级 | 提示词 |
| --- | --- | --- |
| 荷兰角 | ★★★★★ | `dutch angle, tilted frame` |
| 逆光/剪影 | ★★★★★ | `silhouette, backlit, rim lighting` |
| 隐藏动作 | ★★★★★ | `off-screen action, sound driven` |
| 延时拍摄 | ★★ | `time-lapse, hyperlapse` |

**还给了质量底线**：优先调 ★★★★★ 的那些。

🔴 **把"AI 到底能不能做到"量化成星级** ——
**直接解决了"提示词写得很美但生成不出来"的问题。**

### 3.6 VISUAL DNA（项目级一致性约束）

```
VISUAL DNA — 《项目名》
COLOR & LIGHT:
  Color palette / Color temperature / Contrast ratio
  Shadow tone / Highlight tone
...（项目级，所有镜头必须符合）
```

# 四、三家合起来的三条结论

## 结论 1：对话和实际动作要分开

- OpenMontage：Chat vs Backlot
- 我们：只有对话

**这条要立刻做。**

## 结论 2：AI 能不能做到，要量化

- 深海导演：AI 适配度星级

搜到的要素应该标「AI 容易生成吗」，不然提示词写得再好也出不来。

- RunningHub：工作流市场，创作者分成
- LibTV：审美资产
- 像素蛋糕：第三方创作者工具包

**三家同一个模式。** 自用阶段不做，但方向记着。
