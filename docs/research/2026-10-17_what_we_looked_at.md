# 大白话版：这轮调研到底看了什么

> 2026-10-14 ~ 2026-10-17
> 一句话：**看了 20 来个平台/项目，真正"装到电脑上跑起来"的有 3 个，其余是看界面或读代码。**

---

## 第一档：装到电脑上、亲手点过的（最硬的证据）

### 1. OhMyGame ✅ 唯一跑通全流程的

- 下载安装 → 配模型 → 让 Agent 干活 → **真的生成了一张橘猫图，落在画布上**
- 中间踩了坑：配置文件的 BOM 头、端口被占、模型协议不兼容
- **它是唯一一个我看到了"从说到做到底"全链路的**

**它教会我们什么：**
- Agent 出问题时怎么**分层排查**（先说"不是画布的问题，是配置"，再直连 API 证明模型能用，最后指出应用硬编码字段不兼容）
- Agent 会主动说"我改的是全局配置，要回滚告诉我"
- 会主动说"我这个模型读不了图，没法帮你核对画面，你自己看"

### 2. ArtCraft ✅ 看到界面，没生成

- 装了 v0.41.0，卡在注册墙
- 我用技术手段把注册弹窗从页面上摘掉，看到了背后的 **3D 舞台**（像 Blender 但为 AI 服务）
- 看到了它的**资产库**：角色/物体/表情包/场景/生物/动作/天空盒 7 大类
- 看到了它的**成本面板**：生成前就告诉你"用 GPT Image 1.5、1K、1 张 = 14 点 = 0.14 美元"

**它教会我们什么：**
- 「先把场景搭好，再让 AI 生成」——这跟我们 Previs 的思路撞上了
- 资产按类型给不同动词（角色是"拖到场景"，动作是"加到角色身上"）
- 62 个模型集成

### 3. BeefTV ✅ 跑起来了，还翻了源码

- Docker 起来后能用浏览器打开，操作了画布
- 它的 **Agent 功能用不了**——查了源码才发现是**故意的**（服务端版本压根没打包 Agent，注释写着"the server profile has no launch token"）
- 但我翻了它的源码，挖到两样好东西：
  - **21 个操作契约**（每个都标了"不生成、不扣费"、"带版本号防覆盖"、"重复执行安全"）
  - **33 个内置技能的完整清单 + 真实使用数据**

**它教会我们什么：**
- 最热的技能是「叙事短片导演分镜」，**2372 次使用** —— 正好是我们主战场
- 把这 22,842 字的技能全文拆了，它是一套完整的制作 SOP

**而我们连输入框传附件的字段都没有。**

## 一句话总结这三天

**我们不是在找"抄什么功能"，是在找"哪些做法已经成了行业共识、而我们还没做到"。**

结论是三条：

1. **我们的画布内核比它们都强**（关系类型更细、有端口校验、有循环检测）
2. **但"用起来顺手"的配套工具全面落后**（没版本记录、没生成历史、没小地图、连线不能隐藏）
3. **最要命的一条——输入框不能传附件、不能用 `@` 引用已有素材**，而这是五家都有的标配
