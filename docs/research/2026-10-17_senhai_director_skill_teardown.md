## 二、🔴 六个可直接搬的机制

### 2.1 「导演意图书」——结构化创作意图

```
【基本信息】作品名 / 集数·场次 / 导演
【叙事目标】核心事件 / 观众情绪目标 / 情绪曲线 / 关键信息揭示
【视觉目标】视觉基调 / 主色调 / 核心镜头语言 / 禁止出现
【声音目标】环境音 / 音乐风格 / 音画关系 / 关键声音时刻
【节奏目标】目标时长 / 节奏型 / 镜头密度 / 节奏标记
【特殊指示】道具锚点 / AI生成重点 / 自检点
```

> 💡 **「禁止出现」这个字段很关键** —— 视觉目标里**既有要什么，也有不要什么**。
> 和我从 handraw-style 学到的「负向约束」是同一条原则。

### 2.2 「导演三问」——每个场景的灵魂拷问

> 1. **这场戏观众知道什么，角色不知道什么？**（→ 悬念、信息不对称）
> 2. **这场戏我想让观众感受到什么情绪？**（→ 景别/节奏/光线/色彩/音乐）
> 3. **这场戏的"电影感"来自什么？**（→ 区别于小说/话剧的独特电影表达）

### 2.3 🔴 「叙事目的」强制字段 —— 我认为最有价值的一条

九列分镜表（实际十列）：

| 镜号 | 时长 | 摄影角度 | 景别 | 画面内容 | 场景 | 声音 | 备注 | **叙事目的** | 所属Clip |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

**「叙事目的」的判定规则（原文）**：

> 「看到某场戏 → 问这个镜头的叙事目的是什么？
> **答不上来 → 考虑删除或合并**；
> 答得上来 → 这个目的是否最优？还是另一镜头更适合？」

**七种叙事目的分类**：建立 Establish / 推进 Advance / 揭示 Reveal /
强调 Emphasize / 过渡 Transition / 情绪 Emotion / 反射 Reflect

### 2.4 🔴🔴 「叙事目的」的好/坏写法对照 —— 这段最值得抄

> **好写法（具体到视听手段）**：
> ✅「用**背对背构图**展现两人关系的疏离感，为后续冲突做铺垫」
> ✅「**视觉奇观升华主旨**，将个体行为扩展为群体现象，隐喻现代都市的复制性」
>
> **坏写法**：
> ❌「展现角色的内心矛盾」（**没说怎么展现**）
> ❌「推进剧情发展」（所有镜头都在推进）
> ❌「表达主题」（主题是结果不是目的）

> 💡 **这解决了 AI 写 skill 最大的病：写空话。**
> 不是要求"要具体"，而是**直接给正反例**。

### 2.5 🔴 技巧库带「AI 适配度星级」—— 聪明到值得单独说

30 技法，每条都标：

> **AI适配度说明**：
> ★★★★★ 极易实现（已有大量训练数据）
> ★★★★ 较易（需精确描述镜头参数）
> ★★★ 可实现（需复杂提示词）
> ★★ 需后期处理或特殊技术

**举例**：
| 技法 | 星级 | 核心 | 提示词 |
| --- | --- | --- | --- |
| 荷兰角 | ★★★★★ | 倾斜画框 = 心理失衡 | `dutch angle, tilted frame` |
| 逆光/剪影 | ★★★★★ | 剥离细节保留形态 | `silhouette, backlit, rim lighting` |
| 隐藏动作 | ★★★★★ | 关键动作画外，声音+反应让观众填补 | `off-screen action, sound driven` |
| 延时拍摄 | ★★ | 时间压缩 | `time-lapse, hyperlapse` |

**并给出质量底线**：
> 「优先调用高 AI 适配度技法（★★★★★：荷兰角、逆光剪影、遮挡切入、过肩、POV、
> 色彩叙事、跳切、J/L切、动作顺接、定格、音画对立、隐藏动作、悬念公式、闪回锚点、限制空间）」

> 🔴 **把"AI 到底能不能做到"量化成星级** —— 这是我从没见过的做法，
> **直接解决了"提示词写得很美但生成不出来"的问题。**

### 2.6 VISUAL DNA —— 项目级一致性约束

```
VISUAL DNA — 《[项目名]》项目级约束
COLOR & LIGHT:
  Color palette: [主色1]+[主色2]+[辅色]
  Color temperature: [K值]
  Contrast ratio: [比例]
  Shadow tone / Highlight tone
CAMERA LANGUAGE:
  Focal length: [mm]   Depth of field: [f值]
  Movement: [运镜方式]  Aspect ratio: [比例]  Frame rate: [fps]
```

> 「**第一集建立、后续复用**，作为所有参考图与提示词的约束底座」

**这就是我们在 LTX 的 Elements、Dashtoon 角色映射里看到的同一件事**，
但它是**用文档模板固化的**，不是靠 UI 字段。

## 三、它的知识库怎么写的（这才是"指导 skill"的实质）

skill 里嵌了 **6 个知识库**，每个都是"给 AI 看的操作手册"：

| 知识库 | 内容 |
| --- | --- |
| **爆款开头公式库** | 4 个公式（误会型/身份反差/时间压力/情绪积累）+ 适配说明 + **「三分钟一个坎」「反转密度=时长÷2」** |
| **叙事模板库 A–F** | 克制式悲剧 / 释放型 / 悬念公式 / 遮蔽叙事 / 循环叙事 / 限制空间，**每个都带具体示例** |
| **叙事目的分析法** | 7 种分类 + 判定流程 + 意象叠加技巧 |
| **镜头组划分 + 漫画式分镜** | 蒙太奇组/递进组/因果组/对比组 + 今敏/浦泽直树的画格理论 |
| **动作-反应结构 12 变体** | 标准型/反应前置/动作并置/反应省略/动作隐藏/反应延迟/同步/反应链/重复渐变/对位/省略动作/链式衔接 |
| **分镜技巧库 50+** | 构图 12 / 镜头运动 10 / 剪辑 7 / 声音 2 / 叙事思维 5，**每条带来源电影 + 掌握星级 + 适用场景** |

**技巧库长这样**：

| 技巧 | 来源 | 掌握 | 适用场景 |
| --- | --- | --- | --- |
| 视线留白与心理空间 | 《教父》 | ⭐⭐⭐⭐⭐ | 对话、情绪场景 |
| 框架式构图 | 《花样年华》 | ⭐⭐⭐⭐☆ | 空间分割、疏离感 |
| 对称构图与打破对称 | 《闪灵》《2001》 | ⭐⭐⭐☆☆ | 压迫感、仪式感 |
| 漫画式分镜 | 今敏/浦泽直树 | ⭐⭐⭐⭐☆ | 情绪外化、节奏控制 |

> 💡 **「来源」这一列很妙** —— 它把抽象技巧锚定到具体电影，
> **AI 和人都能据此理解"这个技巧长什么样"**。

## 四、它的门禁与自检（最硬的纪律）

### 4.1 交互铁律（原文）

> 「**Phase 5、Phase 7 完成后必须停下等用户确认，不得擅自推进高成本阶段；
> 每步完成等用户 [通过/修改/自检]，绝不一次生成所有内容。**」

### 4.2 云端生成铁律

> 「提交即告知"已提交生成"，**禁止主动轮询**；
> 独立任务必须**并行提交**，禁止串行分批；
> 有图片输入**必须用 `image2image`**；
> 引用前序结果前**必须 `resource_status` 确认**」

### 4.3 不可省略环节（原文）

> 「**Phase 4 素材挖掘、Phase 5 Step3 Clip 组合为后段刚需，
> 森海前段虽无亦不得跳过。**」

### 4.4 四类自检

| 自检类 | 检查项 |
| --- | --- |
| **叙事目的** | 每镜有叙事目的？目的具体到视听手段？运用了意象叠加？ |
| **风格** | 符合所选风格？有暗黑童话的讽刺暗喻？有足够的视觉奇观/升华镜头？ |
| **技巧调用** | 调用了技巧库？**有 15–30% 的"出彩"镜头设计？出彩设计有叙事理由？** |
| **AIGC 适配** | 避免了 AI 难生成的复杂物理交互？角色首次出场有完整视觉描述？环境有具体视觉锚点？ |

### 4.5 🔴 「常见问题诊断」表（少见，但很有用）

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| 节奏拖沓 | 镜头太多/时长太长 | 跳切压缩、删除次要镜头 |
| 情绪不到位 | 信息给得太直接 | 遮蔽叙事、克制表达 |
| 风格不统一 | 镜头语言随意变化 | 建立视觉DNA约束 |
| 信息混乱 | 剪辑顺序错误 | 重新梳理信息揭示顺序 |
| 视觉疲劳 | 运动镜头过多 | 加入固定镜头喘息 |
| 情感过载 | 表达过于直白 | 减法：用细节替代直接表达 |

> 💡 **这是"修复分类法"的实例** —— 和 FreeLipSync 的「修复口型同步质量」同一个思路。

### 4.6 追问原则

> 「仅在创意方向不明、风格未定、视频比例/配乐缺失时追问。
> **每次最多 5 个问题**，优先用表单给选项+支持自定义，**禁止连环追问**。
> 规格参数用户已明确则直接用、未明确给推荐默认值供一键确认。
> **能从上下文推断的不追问。**」

## 六、如果我们要做一份同级别的 skill

按这份范本，一份生产级 skill 应该含：

```
1. 角色定位（我是谁，不是什么）
2. 风格基因（参照了谁，默认风格是什么，能否覆盖）
3. 职责矩阵（维度 → 产出）
4. 工具使用规范（什么时候用哪个工具 + 铁律）
5. N 个 Phase（每个带：目标 / 执行步骤 / 产出 / 用户交互门禁）
6. N 个知识库（公式库 / 模板库 / 技法库，每条带来源与示例）
7. 强制字段（如"叙事目的"）
8. 好/坏写法对照（不只说要求，给正反例）
9. 自检清单（分类，可勾选）
10. 常见问题诊断表
11. 追问原则（最多问几个、什么情况问）
12. 全局约束（不可省略的环节 / 质量标准 / 交互纪律）
```

> **对照我们现有的 `ylcraft-interaction-quality`**：
> 它有 1/4/9/12，**缺 2/5/6/7/8/10/11**。
> **下一步如果要升级它，照这张清单补。**

### 两者共有的 8 个骨架（→ 说明这是行业共识）

1. **角色定位**（我是谁、不是什么）
2. **工具使用规范 + 禁止使用清单**
3. **硬性启动条件 / 门禁**
4. **分步流程**（Phase 或 步骤）
5. **强制字段**（叙事目的 / 视觉基因锚定）
6. 🔴 **允许 / 禁止 对照表**
7. **输出结构模板**
8. **确认卡**（每步等用户确认）

### #2 独有的两条，值得单独记

**① 「视觉基因锚定」7 项表**（复刻的是基因，不是画面）

| 锚定项 | 要求 |
| --- | --- |
| 主体识别度 | 人物/产品/角色/空间必须可识别 |
| 色彩气质 | 保留主色、辅色、点缀色的整体关系 |
| 材质逻辑 | 塑料/金属/玻璃/布料/皮肤的表面响应 |
| 光影逻辑 | 主光、辅光、阴影、反射、暗部层次 |
| 构图记忆点 | 最强视觉重心、轮廓、空间张力 |
| 情绪基调 | 冷暖/治愈/神秘/商业/高级 |

> 原文一句很关键：**「分镜需要回归的是视觉基因，不是原图静态构图。」**

**② 🔴 执行阶段要「洗掉 Markdown」**（踩过坑才写得出来）

> 「视频生成阶段**只注入分镜表镜头内容，不注入分镜表以外的信息，
> 不注入 Markdown 表格符号或格式字符。**」

**为什么重要**：分镜表是 Markdown 表格，直接整段喂给视频模型，
`|`、`---`、表头这些符号会污染提示词。

**我们的对应问题**：`frontend/src/pages/agent/index.tsx` 里
`JSON.stringify(step.output)` 直接把结构化数据塞进 UI —— 同一个病，方向相反
（它是**把表格符号喂给模型**，我们是**把原始 JSON 甩给用户**）。

**禁止清单也很硬**（第 2 名原文）：
> 禁止：无依据换世界 / 新增未确认主角 / 新增外部 IP / 新增 Logo /
> 新增品牌文字 / 新增产品标签 / 新增水印 / 生成乱码文字 /
> 使用黑场、白场、渐显、渐隐、叠化、黑屏停顿
