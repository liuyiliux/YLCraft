## 二、真正"完全没有"的 5 个功能

### 1. 🔴 参考板 / Moodboard（ArtCraft 有，我们 0）

**它是什么**：一个看板，把参考图、情绪板、材质、配色收集在一起，
然后**从这块板子直接引导生成**（不是单张图当参考，是整块板当上下文）。

**为什么重要**：我们现在的参考是"单张图 / 单个角色 ID"，
**没法表达"这几张图合起来的这个感觉"**。

**我们的替代品**：`prompt-library`（提示词库）+ `inspiration`（灵感）
——但它们是**文本库**，不是"可喂给模型的视觉上下文"。

### 2. 🔴 画布版本记录（BeefTV 有，我们 2 处）

**它是什么**：画布每次改动留一个版本，能回看、能回滚。

**我们的现状**：有**撤销/重做**（64 处），但那是**当前会话内**的栈，
**关掉就没了**。没有"上周三那版"。

**为什么重要**：Agent 一改就是 9 个文件（我在 BeefTV 里实测看到 `+26 -126`），
**用户没有后悔药**。

### 3. 🔴 分镜脚本行（BeefTV 有 4 个 op，我们 0）

**它是什么**：分镜不是自由文本，是**结构化表格行**——
镜号、时长、画面、台词、机位，**行 ID 和镜号由服务端分配**，
支持批量追加、按行更新、按行删除并**自动重排镜号**。

**我们的现状**：`platform_templates_seed.py` 里有分镜 panel 的 schema
（`duration_seconds` / `camera_motion` / `video_prompt`），
但**没有"行"这个一等公民**，也没有"删一行自动重排镜号"。

**为什么重要**：Agent 想"把第 3 镜删掉"，它只能重写整个分镜。

### 4. 🔴 时间线渲染 → 成片（BeefTV 有，我们 0）

**它是什么**：把画布上的视频节点按时间线拼起来（裁剪、顺序、音量、字幕），
**本地免费渲染**出一支成片。

**我们的现状**：`clip` / `clip-ops` / `player` 页面有，
但**没有"从画布一键出片"**这条路。

**注意**：BeefTV 的 op 描述特意写了「**免费本地渲染**…**不调用付费生成**」
——它把"免费"标在工具签名里。

### 5. 🔴 自动整理节点（BeefTV 有，我们 0）

**它是什么**：一键把乱成一团的节点按依赖关系重新排版。

**为什么重要**：Agent 一次建 9 个节点，位置是它随便放的。
**没有自动整理，用户每次都要手动拖。**

## 四、ArtCraft 有、我们完全没有的 3 个"新玩法"

这三个不是"补功能"，是**新维度**：

### 1. Image to Location —— 把虚拟演员钉进真实场景

**做法**：给一张真实房间照片 → 把 3D 虚拟演员"放"进去 →
不管从哪个机位拍，**演员在房间里的物理位置不变** → 多机位一致性直接解决。

**我们的替代**：Previs 里有机位，但**场景是我们自己搭的 3D**
，不是"真实照片 + 虚拟演员"。

**价值**：这对"实拍场景 + AI 角色"的短剧是刚需。

### 2. Character Posing + Identity Transfer —— 摆好姿势再生成

**做法**：在 3D 人偶上摆姿势（胳膊抬多高、头转多少度、重心在哪只脚）→
用 3D ControlNet 把姿势迁移到生成的角色身上。

**我们有**：ControlNet（74 处命中）、姿势相关能力。

**缺的是**：**"先摆姿势、能看见、再生成"这个交互闭环**。
我们是"写提示词描述姿势"。

### 3. Angles —— 从单张照片生成新机位

**做法**：一张正面照 → 生成侧面、俯拍、背面。

**我们有**：机位生成（Previs），但那是**从 3D 场景算机位**，
不是"从一张图推别的角度"。

**这两个是不同的事**，我们缺后者。

## 五、排序：功能上该补什么

按「用户已经遇到 + 多家一致 + 不改会持续出错」：

| 优先级 | 补什么 | 证据 | 理由 |
| --- | --- | --- | --- |
| **P0** | 🔴 **画布版本记录** | BeefTV 有；Agent 一次改 9 文件 | 用户**没有后悔药**，这是最危险的 |
| **P0** | 🔴 **自动整理节点** | BeefTV 有；Agent 建节点位置随机 | 每次都要手动拖，**高频痛点** |
| **P1** | 🔴 **分镜脚本行**（结构化 + 服务端编号 + 批量操作） | BeefTV 4 个 op | Agent 改分镜只能整块重写 |
| **P1** | **参考板 / Moodboard** | ArtCraft 核心功能 | 我们只有"单张参考"，没法表达"整体感觉" |
| **P2** | **从画布出片**（时间线渲染） | BeefTV 有 + 标"免费" | 现在要跳好几个页面 |
| **P2** | **隐藏连线** | BeefTV 有 | 节点多了看不清 |
| **P3** | **小地图** | BeefTV / Infinite Canvas | 规模还没到 |
| **P3** | **Image to Location** | ArtCraft | 新维度，但工程量大 |
| **P3** | **Angles（图生多机位）** | ArtCraft | 同上 |

## 六、一句话总结

**功能上我们不"空"，是"偏科"。**

- **生成能力很全**（图/视频/音频/3D/口型/水印/抠图，基本都有）
- **创作组织能力很强**（小说→世界→角色→分镜→画布，这条链比他们都长）
- 🔴 **但"改了之后怎么办"几乎空白**：
  - 没有版本记录（改坏了没法回）
  - 没有自动整理（Agent 弄乱了没法理）
  - 没有出片（做完了没法一键成片）

**这三个不是"锦上添花"，是"最后一步落不了地"。**
