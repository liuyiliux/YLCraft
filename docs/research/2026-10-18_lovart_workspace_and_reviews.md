## 一、你说的那条链路，确认成立

> **对话生成图片 → 图落到画布 → 拆分层 → 局部改一层**

三条都能对上：

| 环节 | 证据 |
| --- | --- |
| **对话生成** | 实测截图：左侧画布已有 5 张成品海报，右侧对话里 Agent 说「我来为你制作一张朝牌宣传海报……**让我开始生成：**」 |
| **落到画布** | 生成的图直接铺在画布上，可拖动、可缩放（当前 8%） |
| **拆分层** | 优设测评：**选图 → 【编辑元素】 → 拆成 文字 / 主体 / 背景** |

**优设原文（二手，但描述很具体）：**

> 「给到主体图片参考，让 Lovart 生成海报。得到示例海报后，**选择图片，点击【编辑元素】可拆分**，
> 拆完以后会得到**文字、主体、背景**，成为可编辑素材。
> 后续不用再去重做整个图，**可以单独改某一层不影响其他图层**，复用其他图层或元素也会很方便」

## 二、🔴 画布工具栏（DOM 实读，一手）

```
[选择▾] [标注] [上传▾] [画框] [形状▾] [画笔▾] [文字]  |  [生成图片▾] [生成视频▾] [字体生成]
                                                                        
浮动：[画布背景▾]  [图层]  [文件搜索]  [小地图]        缩放 8%
```

| 按钮 | 作用 |
| --- | --- |
| `Nav select menu` | 选择（带子菜单） |
| `Nav mark` | 标注 |
| `Nav upload menu` | 上传（带子菜单） |
| `Nav frame` | 画框 |
| `Nav shape menu` | 形状 |
| `Nav pen menu` | 画笔 |
| `Nav text` | 文字 |
| **`Generate menu image`** | **在画布上直接生成图片**（不是去别的页面） |
| **`Generate menu video`** | **在画布上直接生成视频** |
| `Nav font gen` | 字体生成 |
| `Canvas background` | 画布背景（带子菜单） |
| 🔴 **`Float layer`** | **图层** |
| `Float file search` | 文件搜索 |
| **`Float minimap toggle`** | **小地图开关** |

> 💡 **关键：生成入口在画布工具栏里**，不在顶部导航。
> 也就是说「我已经在画布上了，想再生成一张」**不用离开画布**。
> 我们现在的生图在 `/image-gen`，要跳页。

### 🔴 生成记录带完整参数

DOM 里抓到每条生成记录的尾巴：

```
GPT Image 2 · 中 · 9:16(4k) · 1 img
```

**模型 · 质量档 · 比例(分辨率) · 张数** —— 一行写全。

> 对照我们：生成记录里**没有统一的一行参数摘要**，
> 用户要回看"这张是用什么参数生成的"得翻配置。

## 四、别人的评论（这是你要的重点）

### 4.1 正面（设计师视角，优设测评）

| 观点 | 原文 |
| --- | --- |
| **接入新模型快** | 「Lovart 接入模型超快」 |
| **分层对设计师友好** | 「新出的图像分层功能也挺好的，对设计师友好，直接在画布里就能拆分编辑和重组」 |
| **成本划算** | 「8 月底开的年会员……Midjourney V7 和 Seedream 4 免费无限，Hailuo 2.3 限时免费无限，**从头到尾一共就花了 130 积分**」 |
| **粗指令也能出好图** | 「**系统提示强过我绞尽脑汁**啊。Lovart 在我非常粗糙的指令下，还是输出了我满意的图片」 |

### 4.2 🔴 缺点（优设也承认的真实问题）

| 问题 | 原文 |
| --- | --- |
| **分层会丢字体效果** | 「拆完以后可能**标题字直接成了纯文字了**，想要保留字体效果，有个简单的办法就是**放大该图片，截图截取标题部分，然后选择【移除背景】抠图**」 |
| **需要手动补光影** | 「如果替换主体，发现将抠好图的主体放上去后**光影完全不融合**」→ 得自己写长提示词补光 |

> 🔴 **这条很重要**：**"分层"不是无损的**。
> 拆出来的文字会变成纯文本，原本的字体设计会丢。
> **官方给的解法是"截图 + 抠图"这种土办法。**

## 六、对我们最有价值的三条

### 1. 🔴 「把成品拆成可编辑元素」——我们是完全空白

**这不是 Photoshop 的图层树，是"逆向拆解生成结果"。**

一张平铺的成品图 → 拆成 文字 / 主体 / 背景 → 单独改一层，其他层不动。

**我们的资产是"平的"**：生成的图就是一张图，改一个字得整张重生。

**这条比"画布版本记录"更值钱**，因为它是**能力**不是**保护**。

### 2. 生成入口在画布工具栏里

「我已经在画布上，想再生成一张」→ 直接在工具栏点「生成图片」，不用跳页。
**我们的生图在 `/image-gen`，要跳页。**

### 3. 🔴 生成记录一行写全参数

`GPT Image 2 · 中 · 9:16(4k) · 1 img`

**对照我们**：没有这个统一摘要。

## 七、我们该避开的

| 别学 | 为什么 |
| --- | --- |
| ❌ **生成 2-3 分钟还硬做"对话流"** | 对话需要秒级响应，2-3 分钟会毁掉节奏。**宁可先告诉我们"这步要等多久"** |
| ❌ **把模型选择藏在 Agent 后面** | 它的「模型选择 2/5」。我们的模型选择是显式的，**这是优势** |
| ❌ **输出管理没搜索** | 它的「输出管理 2/5」。我们素材库有筛选，**这是优势** |
| ❌ **免费的给太少** | 30 积分 ≈ 2.5 张，根本没法评测 |

## 九、一句话

**Lovart 值得学的不是"画布"，是"把生成结果变成可编辑对象"。**

它的画布工具栏其实很朴素（选择/标注/上传/形状/画笔/文字 + 生成）。
真正稀缺的是**「编辑元素」把一张成品拆成文字/主体/背景**——
这个是**从"一次性出图"到"可反复修改"的跨越**。

**但它也证明了这条路的代价**：拆出来会丢字体、光影要手动补、生成慢到毁对话节奏。
**所以抄它不能只抄"能拆"，要连"拆完怎么补"一起想。**
