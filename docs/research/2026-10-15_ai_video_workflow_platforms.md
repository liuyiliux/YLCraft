### 1.1 video-research-lab（由飞书页挖出的真资料）

`github.com/LucianaiB2004/video-research-lab` —— 一手，已读 README 全文。

自我定位：**「Prompt-as-Code templates for video understanding, generation,
transformation, and quality review」**

**10 个提示词工作流**（按**用户想完成的任务**分类，不按模型/供应商分类）：

| # | 功能 | 输入 → 输出 |
| --- | --- | --- |
| 01 | 视频反推 | 参考视频 → 有证据支撑的重建提示词 |
| 02 | 首帧生成视频 | 首帧图 + 运动简述 + 时长 → I2VA 提示词 |
| 03 | 替换主体 | 源视频 + 替换对象 → 两阶段蓝图与重建提示词 |
| 04 | 首尾帧生成视频 | 首帧 + 尾帧 + 时长 → FL2VA 过渡路径 |
| 05 | 视频续写 | 已有视频 + 续写简述 → 从已核实末态起步的提示词 |
| 06 | 替换场景 | 源视频 + 目标场景参考 → 含空间适配的场景重建 |
| 07 | 视频风格转换 | 源视频 + 风格参考 → 含内容连续性约束的重绘 |
| 08 | 动作复刻 | 动作参考视频 + 新主体 → 动作蓝图与迁移提示词 |
| 09 | 运镜复刻 | 运镜参考视频 + 新内容 → 运镜蓝图与构图感知提示词 |
| 10 | 视频提示词检查 | 已有提示词 + 可选参考 → 问题清单、校验矩阵、修复版提示词 |

**7 条设计原则（一手原文，直接可用）**：

1. **Function first** —— 每个目录对应**一个用户可见的成果**。
2. **Direct use** —— 每个提示词文件只含**一个完整的 XML system prompt**，
   正常产出是**一条中文生成提示词**。
3. **Evidence before inference** —— 模板把「可观测事实 / 用户要求的改动 /
   未知信息」**三者分开**。
4. **Timeline integrity** —— 镜头、转场、局部生成时间、源视频时间**显式处理**。
5. **Reference clarity** —— 图片、视频、主体、音频资产获得**稳定的角色**，
   而不是混在一起。
6. **Portable output** —— 不假装通用字段名就是各家供应商的 API。
7. **Honest verification** —— `UNKNOWN`、确认不存在、不适用，**三者保持区分**。

**尤其值得学的诚实**（一手原文）：
> 「There are currently **0 published cases**」「do not interpret its presence in this
> repository as proof of compatibility with every video model or as evidence of a
> successful generation run.」

**对 YLCraft 的意义**：
- 第 5 条「Reference clarity：资产获得**稳定角色**」= 我们资产注入该遵守的规则
- 第 7 条「Honest verification」= 值得直接抄进我们的 skill
- 这 10 个工作流可直接作为我们**视频提示词模板的分类体系**

### 剪映 Hub 是什么（一手原文）

> 「**剪映 Hub**，一个从脚本到成片的一站式工具，**结合了无限画布和 Agent**」
> 「原来我们做 AI 视频，要在好几个软件之间来回切换……但现在，剪映 Hub 把文字、
> 图片、音频、视频的生成和最后的精剪，**全都打通了**」
> 「最关键的是，**它的 Agent 上下文是统一的**」

### 完整工作流（用户实际操作步骤）

**1.1 从一句话到分镜表**
- 打开剪映 Hub → 点**左侧的 Agent** → 从最原始的想法开始
- 「它会选用**内置的 Skill**，先把**剧本框架**搭出来」
- 继续让 Agent **一键拆成分镜表**：「分镜表里面会规划好每个镜头的**时长、情节与画面、
  运镜、台词和音乐与音效**」

**1.2 从分镜到画面**
- 涉及**人物、道具、场景**，「在**右下角**这里，可以直接**一键批量生成**」
- 「生成后，还能快速把这些内容**「保存到资产主体」**，这样整体的**人物、道具就固定好了**」
- 点**「生成分镜提示词」** → 「Agent 就会**按照分镜，引用我们准备好的资产**，
  整理出所有提示词」
- 确认后点**「批量生成视频」**

**1.3 从画面到成片**
- 点**「成片预览」**，「在画布里，它会**按分镜做好视频之间的基础衔接**」

**1.4 从预览到精剪**
- 点**「更多剪辑」** → 「直接进入剪映平时的多轨道剪辑时间线，**完全不用导入导出**」
- 时间线里可**「AI 后编辑」**：「比如镜头时长不够，**让 AI 把镜头延长**一点」

**剪映助手（时间线里的 Agent）**
- **剪口播**：删口误/重复句/过长空白，「原本一个小时的工作，差不多 **10 分钟**就完成了」
- **素材生成**：Agent 生成匹配台词的 B-roll，「**素材直达剪辑时间线**」
- **素材粗剪**：让 Agent「筛选素材、匹配画面，完成一版粗剪」，自动排布到时间线
- **一键包装**：有成熟模板，也可智能设计

**诚实的一句（一手）**：
> 「它也并不是『一键成片』……不过好在它生成的是**可编辑的剪辑轨道**」

### 🔴 对我们的直接冲击

剪映 Hub **已经实现了我们 P0/P1 建议里的两条**：

| 我建议的 | 剪映 Hub 已实现 |
| --- | --- |
| 生成时自动注入角色卡/资产 | ✅ **「保存到资产主体」→「Agent 按分镜引用我们准备好的资产」** |
| 批量生成（把等待变并行） | ✅ **人物/道具/场景一键批量生成、批量生成视频** |
| 资产独立于对话、集中可找 | ✅ 资产主体 + 无限画布 |
| 局部重生成 | ✅ 时间线里「让 AI 把镜头延长」 |

**这不是"未来方向"，是已经上线的产品。** 我们的差异化只能在

## 3. 鱼皮的 AI 宣传片制作器 —— ⭐⭐⭐ 对"怎么做 skill"最有启发

`https://cloud.tencent.com/developer/article/2759179`
《用 AI 全自动做视频，太爽了！开源 AI 视频制作器 + Skill》程序员鱼皮，2026-10-12

开源仓库：`https://github.com/liyupi/ai-promo-video-maker`

### 核心方法论（一手原文）

> 「这个项目里**没有什么复杂的代码，核心是一份写给 AI 看的「工作规范」**，
> 外加一个 Remotion 视频工程模板和十几个辅助脚本。」
> 「**AI 读完规范，就知道一支宣传片该从哪一步开始、每一步要做到什么标准。**」

**这就是我们做 `ylcraft-interaction-quality` 该学的形态。**

### 技术路线：AI 写代码做视频

- 用 **Remotion** 框架：「在它眼里**视频就是一个 React 网页**，
  所以会写前端代码的 AI，天生就会剪视频」
- 流程：AI 写代码做会动的网页 → 逐帧截图 → 拼起来 + 配声
- 「一支 1 分钟、每秒 60 帧的视频，就要截 **3600 张图**」
- 与"AI 视频生成模型"的区别：「**视频生成模型**是直接把画面画出来，
  效果很惊艳，但画面里的**文字和产品界面很难画准**」；
  写代码做的「每个字、每张截图都是精确的」

### 它的工作流（AI 自动执行）

1. AI **自己调研产品**：搞清楚它是干嘛的、卖点、可证明的数据
2. **像产品经理一样主动问需求**：视频多长、给谁看、先讲痛点还是先秀亮点
3. 整理成**需求确认文档**，「**你确认了它才开工**」
4. **给几种风格小样供挑选**（例：纸张拼贴 / 像素通关 / 极简发布会 / 黏土 Q 版）
5. 自动完成写脚本、截图、配乐、剪辑
6. 交付 4K 宣传片 + 附赠动画网站

### 它的铁律（**最该学的部分**）

| 铁律 | 一手原话 |
| --- | --- |
| **真实素材优先** | 「**主角必须是真实产品，不能拿 AI 画的假界面来敷衍**」；每个功能段落至少一张真实界面截图，AI 自己开网站截 4K 图，**需要登录就弹浏览器让你登录** |
| **诚实说明 AI 能力边界** | 「**AI 压根儿听不到声音**……它只能靠分析波形来判断节奏，曲子搭不搭、好不好听，**还得你的耳朵来感受**」→ 所以**让你亲自试听** |
| **校验环节** | 旁白「念完还会把音频重新转成文字，**跟稿子逐句比对，品牌名和网址错一个字都不放过**」 |
| **模型能力要够** | 「一支宣传片要走**十几个步骤**，中间还有好几轮**截图审查和音频校验**，能力弱一点的模型**很容易偷懒跳过校验**，或者不知不觉把每个产品都做成千篇一律的深色科技风」 |

### 踩坑记录是怎么攒的

> 「现在规范里已经攒了 **80 多条踩坑记录**，像**截图被横向压扁、开场铺垫太慢、
> 配乐和画面不搭、旁白把品牌名念错**，**每一条都来自我真实收到过的修改意见**。」

**这是 skill 的正确生长方式：每一条规则都来自一次真实翻车。**

### 可安装成 Skill

```bash
npx skills add liyupi/ai-promo-video-maker -g
```
「装好之后，在你自己的产品仓库里跟 AI 说一句『给这个项目做一支宣传片』就行。
**AI 可以直接读你的源码和文档，拿到的素材比去官网扒的还准。**」

**成本参考**：1 分钟视频「大概**几十块钱**」（「AI 要反复截图、审图、校验，烧的 tokens 可不少」）

## 4. dsh-tool-lipsync —— DSH 对口型视频插件

`https://github.com/yu-wenchao/dsh-tool-lipsync` （master 分支，一手已读 README）

**是什么**：「**免 Key、免登录**的 AI 对口型口播视频生成插件，为 DeepSeek Harness (DSH)
注册 **5 个工具**，使用免费开放 API 生成对口型视频」

**5 个工具**：

| 工具 | 作用 |
| --- | --- |
| `lipsync_list_voices` | 列出预设声音（按语言/关键词筛选） |
| `lipsync_list_samples` | 列出示例人脸/宠物/卡通素材 |
| `lipsync_generate` | 提交对口型口播视频生成任务 |
| `lipsync_status` | 轮询生成状态（5-6 秒/次） |
| `lipsync_download` | 下载成片 MP4 到本地 |

**免费层特性**：无需 API Key / 无需登录；最长 **20 秒**；无水印；
大多数 **1-3 分钟**完成；**3000+ 声音、500+ 语言**；支持自定义人脸图片。

**⚠️ 注意事项（作者自己写的）**：
- 免费层输出为**低清 preview** 版；高清无水印原片需登录/付费
- 依赖第三方免费服务，**免费额度与接口随时可能调整**
- **请注意素材/肖像版权**；后端接口未来可能变动

**安装**：`dsh plugin --profile web add github:yu-wenchao/dsh-tool-lipsync`

**对我们的意义**：这是一个**现成的 DSH 插件范例**——展示了一个能力如何包装成
"5 个工具 + 轮询 + 下载"的 Agent 工具链。**与我们 Agent 工具的设计模式一致**
（提交 → 轮询 → 下载），可作为参考实现。

**另注**：我们目前**没有对口型能力**。如果要做数字人口播，这是个低成本入口
（但要注意"低清 preview"和接口稳定性风险）。

## 本轮结论

### 最该行动的三条

1. **剪映 Hub 已经做了"资产固化 + 自动引用 + 批量生成"** ——
   这是我们建议的 P0/P1，**已是上线产品而非未来方向**。我们的窗口在别处
   （世界地图 / 剧情时间线 / 小说→世界提取）。
2. **skill 的正确写法 = 写给 AI 的工作规范 + 每步验收标准 + 真实踩坑记录** ——
   鱼皮的 80+ 条踩坑记录是范本，**每条都来自一次真实翻车**。
3. **`video-research-lab` 的 7 条原则可直接抄**，尤其
   「Reference clarity（资产获得稳定角色）」和「Honest verification
   （UNKNOWN / 确认不存在 / 不适用要区分）」。

### 需要提醒的

- 飞书 wiki 是**推广导流页**（3 条带邀请码），资料价值低。
- 剪映那篇是**商单**，工作流描述可用，价格/优惠部分不可信。
- `dsh-tool-lipsync` 的免费层是**低清 preview**，且作者自己声明接口可能变动。
