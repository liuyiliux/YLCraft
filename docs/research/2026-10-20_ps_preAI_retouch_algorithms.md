# 一、液化（Liquify）—— 纯几何变换，不是 AI

## 1.1 PS 怎么做的

**网格变形（Mesh Warp）**：

```
原图 → 划分成网格 → 拖拽网格顶点 → 重采样插值 → 变形后的图
```

PS 液化工具里的每一种，本质都是「怎么移动网格顶点」：

| 工具 | 数学本质 |
| --- | --- |
| **向前变形** | 沿鼠标移动方向推顶点（带衰减半径） |
| **膨胀 / 收缩** | 顶点向/背离圆心移动 |
| **左推** | 垂直方向推 |
| **重建** | 把变形量往回拉 |
| **冻结 / 解冻** | 蒙版，锁定不动的区域 |

## 1.2 学术界有现成的经典算法

**MLS 变形（Moving Least Squares，Schaefer 2006）**：
- 《Image Deformation Using Moving Least Squares》，SIGGRAPH 2006
- 三种变体：仿射、相似、刚性
- **只需要「控制点对」（拖动前后位置）就能算出整张图的变形**
- **纯矩阵运算，不需要训练**

另外还有：
- **网格型**（Grid-based warp）：划分网格 + 双线性插值，最简单
- **Bezier 网片**（PS 的变形工具就是这个）

## 1.3 我们能做吗

| 方案 | 难度 | 说明 |
| --- | --- | --- |
| **网格 warp + 双线性插值** | ⭐ 简单 | numpy 就能做，几十行 |
| **径向推挤（膨胀/收缩）** | ⭐ 简单 | 距离衰减函数，几十行 |
| **MLS 相似变形** | ⭐⭐ 中等 | 需要解线性方程组 |
| **WebGL 实时液化** | ⭐⭐ 中等 | 网格顶点位移 + shader 重采样，能拖动实时看 |

**结论：液化完全能本地做，免费。**

**瘦脸 = 液化的一种应用**（在人脸关键点位置向内推）。

## 1.4 关键技术细节

```python
# 网格 warp 的核心
# 1. 建网格 (例如 20x20)
# 2. 每个顶点有一个位移量 (dx, dy)
# 3. 对每个像素，找到它在哪个格子，用双线性插值算位移
# 4. 按位移取源像素（反向映射，避免空洞）

def warp_grid(img, mesh_disp):
    h, w = img.shape[:2]
    yy, xx = np.mgrid[0:h, 0:w].astype(np.float32)
    # 把位移图（稀疏网格）插值成逐像素位移
    dx = cv2.resize(mesh_disp[..., 0], (w, h), interpolation=cv2.INTER_LINEAR)
    dy = cv2.resize(mesh_disp[..., 1], (w, h), interpolation=cv2.INTER_LINEAR)
    # 反向映射采样
    return cv2.remap(img, xx + dx, yy + dy, cv2.INTER_LINEAR)
```

**`cv2.remap` 就是 PS 液化的核心函数。**

# 二、磨皮（Skin Smoothing）—— 纯滤波，不是 AI

## 2.1 PS 传统有 5 种做法，全都不用 AI

### ① 高低频分离（专业修图最常用）⭐⭐ 最该抄

```
低频层 = 高斯模糊（保留颜色和明暗）
高频层 = 原图 - 低频层（保留纹理和细节）

磨皮 = 只修改低频层（把皮肤颜色调匀），高频层（皮肤纹理）原样保留
```

**为什么好**：磨完皮**毛孔还在**，不像 AI 磨皮那种塑料感。

```python
low  = cv2.GaussianBlur(img, (0,0), sigma=8)     # 低频
high = cv2.subtract(img, low) + 128              # 高频
# 磨皮后 = 调整后的 low + high - 128
result = cv2.add(smooth(low), high - 128)
```

### ② 表面模糊（Surface Blur）

保边模糊 —— 只模糊颜色相近的像素，边缘不动。
**Photoshop 自带的滤镜，纯算法。**

实现：双边滤波（Bilateral Filter）就是它的数学基础。

```python
cv2.bilateralFilter(img, d=9, sigmaColor=75, sigmaSpace=75)
```

### ③ 高斯模糊 + 蒙版

最简单：复制一层，高斯模糊，加蒙版只显示皮肤区域。

### ④ 通道法（CMYK / LAB）

通道混合让皮肤通透，纯色彩运算。

### ⑤ 频率分离 + 阈值蒙版

## 2.2 我们能做吗

| 方法 | 难度 | 效果 |
| --- | --- | --- |
| **高低频分离** | ⭐ 简单 | 专业级，纹理保留好 |
| **双边滤波（表面模糊）** | ⭐ 简单 | `cv2.bilateralFilter` 一行 |
| 高斯+蒙版 | ⭐ 极简 | 容易塑料感 |
| 通道法 | ⭐⭐ 中等 | 自然但需要调参 |

**结论：磨皮完全能本地做，免费，而且高低频法的效果比"AI 磨皮"更专业。**

## 2.3 关键：皮肤区域怎么找

磨皮不能全图糊 —— 得先找到皮肤。

| 方式 | 难度 |
| --- | --- |
| **手动蒙版**（用户刷） | ⭐ 简单，我们已经有蒙版了 |
| **肤色检测**（HSV 阈值） | ⭐ 简单，经典算法 |
| 人脸关键点 + 分割 | ⭐⭐⭐ 这个才需要模型 |

**所以「磨皮」不强依赖模型：**
- 用户刷蒙版 → 纯本地
- 肤色自动检测 → 纯本地（HSV 阈值，粗糙但能用）
- 精确人脸分割 → 需要模型（可选升级）

# 三、祛瑕疵 / 祛痘 —— 经典 inpainting，不是 AI

## 3.1 PS 怎么做的

| 工具 | 算法 |
| --- | --- |
| **污点修复画笔** | 周围纹理采样 + 泊松融合 |
| **内容识别填充** | **PatchMatch**（Barnes 2009，超经典） |
| **仿制图章** | 直接复制另一块区域 |
| 修复画笔 | 纹理 + 颜色分开处理 |

## 3.2 PatchMatch 是什么

**核心思想**：找一个和要修补区域"上下文最像"的块，贴过来。

- 不需要训练
- 2009 年的 SIGGRAPH 论文
- 现在很多"AI 去水印"的底层其实就是它

## 3.3 我们能做吗

| 方法 | 难度 |
| --- | --- |
| **仿制图章**（直接复制） | ⭐ 极简 |
| **`cv2.inpaint`**（OpenCV 自带，TELEA/NS 算法） | ⭐ 简单，一行 |
| PatchMatch | ⭐⭐⭐ 难（要自己实现或装库） |

**结论：祛瑕疵的"够用版"完全能本地做（`cv2.inpaint`）。**

# 四、其他「我以为要模型，其实不用」的

| 功能 | PS 传统做法 | 需要模型吗 |
| --- | --- | --- |
| **美白牙齿** | 色相/饱和度局部调整 | ❌ 不要 |
| **祛黑眼圈** | 提亮 + 色相偏移 | ❌ 不要 |
| **瘦脸/瘦身** | 液化 | ❌ 不要 |
| **放大眼睛** | 液化（局部膨胀） | ❌ 不要 |
| **妆容调整** | 颜色层叠加 + 混合模式 | ❌ 不要（要蒙版） |
| **锐化** | USM / 卷积 | ❌ 不要（我们已做） |
| **降噪** | 高斯/中值/双边 | ❌ 不要（我们已做） |
| **闭眼修复** | **这个真的要模型** | ✅ 要 |
| **换表情** | **要模型** | ✅ 要 |
| **AI 超清** | 插值能做但要糊 | ✅ 要真细节就要模型 |

**所以真正需要模型的只有三个：闭眼修复、换表情、真超清。**

## 6.2 但要诚实说清代价

| 项 | 说明 |
| --- | --- |
| **液化要手拖** | 不是"一键瘦脸"，得你拖控制点（除非接人脸关键点模型） |
