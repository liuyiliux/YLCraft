## 1.1 🔴 最有价值的一点：它的信息架构就是「四段流水线」

```
1 剧本创作 → 2 资产库 → 3 批量制作 → 4 智能剪辑
                                  ↑
                        无限画布 / Agent配置 是横向能力，不是第五段
```

这**和 YLCraft 的模块划分是同一套思路**，但人家已经把它做成了导航：

| WorkRally 的一段 | YLCraft 对应 | 我们做到哪 |
| --- | --- | --- |
| 1 剧本创作 | creative-project（小说/短剧/编剧房） | ✅ 有，且 Writer Room 比它细 |
| 2 资产库 | `asset_hub` + 角色同步 | 🟡 有存储，**没做成「参考主体」入口** |
| 3 批量制作 | 画布 L3 / 批量应用预设 | 🟡 原型阶段，`22-batch.js` 只到「一次套 6 镜」 |
| 4 智能剪辑 | ❌ 没有 | 🔴 完全空白 |

## 1.2 ✅ 它把台账里两条「欠」做成了活的（这是我实测才发现的）

台账 `RESEARCH_LEDGER.md` 第三节列着两条一直挂着没做的：

| 台账条目 | 原以为 | WorkRally 实测 |
| --- | --- | --- |
| **#7 工作流存成模板并流通（审美资产）** —— 来自 LibTV | 「我们做了存流程，但没做流通」 | ✅ **作品广场里每个模板都带「复制创作画布」按钮** —— 点一下把别人的整张画布复制成自己的。这就是流通，而且流通的是**画布**不是文件 |
| **#11 Skill 商店 / 插件市场** —— 来自 Toonflow + LibTV + 像素蛋糕 | 「需要更多设计」 | ✅ **已在跑，且带使用次数**：`15秒院线级分镜优化专家 使用 511次`、`资产生成·渐进式审美推演 使用 452次`。还有「专家 Agent」：广告营销 Agent、短剧营销 Agent |

**结论：这两条不用再设计了，照着抄形态就行。** 流通单位是「画布」，Skill 的排序信号是「使用次数」。

# 二、文章讲的全流程（8 节，按原文顺序）

文章开头给了一张「环节 → 工具」对照表：剧本创作=混元；人物文字设定=混元；人物画面设定=WorkRally/Venus/即梦；场景与道具画面设定=WorkRally/混元/即梦；分镜画面生成=WorkRally；动画与音效=WorkRally；配乐=Suno；游戏场景搭建=混元3D世界模型。

| # | 环节 | 工具 | 关键做法 |
| --- | --- | --- | --- |
| 1 | AI 辅助剧本创作 | 混元 | AI 出格式良好的底稿，**人工强参与改了 3 个晚上**，到最后几天仍在微调。作者结论：「亮点和逻辑细节需人工调整」 |
| 2 | AI 文字设定脚本 | 元宝 | 把剧本发给元宝出人物小传，它**自动补**人物关系图、视觉倾向、心理弧光、表演建议 |
| 3 | 人物/场景/道具画面生成 | WorkRally + Venus 接的 GPT-image2 / Nano Banana Pro / 三谦(image2) / 即梦 | 见下面 2.1 |
| 4 | **资产库搭建** | WorkRally | 见下面 2.2（一致性核心） |
| 5 | 动画视频生成 | WorkRally（Zen-07 / Zen-SD2.0） | 见下面 2.3 |
| 6 | 无限画布全工程 | WorkRally | 不是制作环节，是交付形态：给出共享画布链接，别人能看每个分镜细节 |
| 7 | 原创配乐 | Suno | 全片 9 首 = 3 首主题曲（共用一套歌词）+ 6 首情节纯音乐。歌词由元宝读剧本生成，再丢进 Suno 抽卡 |
| 8 | 海报等宣发物料 | WorkRally | 用成片关键帧 + 关键道具做**混合参考**生成；定横版后顺手出竖版和带透明通道的名字图 |

附加：混元 3D 世界模型，把教室场景设定图一键生成可游玩 3D 场景（文中有 00:32 演示）。

## 2.1 第 3 节的三个具体技巧

| 技巧 | 内容 |
| --- | --- |
| **先做参考搜索再出图** | 用元宝检索「05 年左右乡村稻田/人物参考图」，目的是**避免常识错误**：6 月南方农作物形态、稻田是绿是黄、人物与稻子的比例 |
| **角色先定正面，再出三视图** | 三视图存着备用，后面所有镜头拿它当参考 |
| **多接口来回切** | 同一条指令在不同接口效果不同。GPT-image2 擅长千禧年老照片质感、和 Nano Banana 文字生成较好，**但都不是百分百成功，达不到就换接口**。手工龙舟：元宝出平面设定 → Nano Banana Pro 转 3D 风格 |

## 2.2 🔴 第 4 节：角色一致性怎么锁（YLCraft 的核心痛点）

这是全文对我们最有用的一节。**四条，都可迁移：**

| # | 做法 | 能不能搬进 YLCraft |
| --- | --- | --- |
| 1 | 角色卡（形象+服装）→ 生成**三视图**备用 | ✅ 能。我们已有角色同步，缺的是「三视图」这个产物形态 |
| 2 | 所有**已确认**素材入资产库，后续用「**参考主体**」方式生成来锁形象 | ✅ 能。这是 `asset_hub` 该有的用法 —— 资产库不只是存，要当**生成时的输入** |
| 3 | **音色一致性**：先生成一段该角色说话的视频 → 把音色导出 WAV → 存进角色资产库 → 后续参考主体生成时复用 | ✅ 能，而且是我们完全没想到的角度：**音色也是一种资产**，和形象同级入库 |
| 4 | **把「龙」也当角色入库**；反复出现的道具/场景同样入库 | ✅ 能。判据是「跨镜头复现」，不是「是不是人」 |

第 3 条值得单独记一笔：我们讨论一致性时一直只想着**画面**，人家把**声音**纳进了同一套资产库机制。

## 2.3 第 5 节：视频生成的两个硬技巧

| 技巧 | 内容 | 为什么 |
| --- | --- | --- |
| **禁 BGM** | 每个分镜片段生成时都加限定「不要背景音乐，只要人物说话声和音效」 | 长片后期带 BGM 剪辑合成很麻烦，音乐统一在配乐环节做 |
| **无声模型 + 参考主体补音效** | 化龙那段要夸张形变：**Zen-07 做首尾帧变形**（张力够但**没有声音**）→ 把成片当**主体参考视频**，模型换 **Zen-SD2.0** 重跑一遍 → 保留动画、加上音效和细节 | 一个模型的强项和短板可以串起来用：先要画面，再补声音 |
| **负向限定词治惯性** | AI 总自动给龙加翅膀 → 提示词里写「不要翅膀」 | 模型的默认想象会覆盖你的设定 |

抽卡的常见失败（作者原话归纳）：角色与龙位置不对、手工龙舟结构不一致、角色眼泪乱飚。

# 四、作者自己承认的局限（这部分比成功路径更有用）

| 局限 | 原文意思 |
| --- | --- |
| AI 剧本不能直接用 | 只是格式好的底稿，亮点和逻辑细节必须人工，改了 3 晚且持续微调到最后 |
| **单条生成结果无法直接用** | 靠大量抽卡 + 剪辑才凑出可用镜头 |
| Zen-07 无声 | 形变张力够，但必须二次参考主体补音效 |
| 一致性会漂 | 位置错、道具结构不一致、表情失控 |
| 没有万能接口 | GPT-image2 / Nano Banana / 元宝 / 三谦 得来回切 |

## 4.1 ⚠️ 想抄提示词的人注意：**关键提示词全是截图**

化龙、龙消散、稻田海的分镜提示词、海报提示词、Suno 纯音乐提示词 —— **都是图片**，正文抓不到文字（alt 只有「化龙抽卡提示词1」「海报-提示词」这种标题）。

唯一以纯文本给出的完整内容是主题曲《还没做好的龙》的歌词 + 制作规格（演唱：清澈少年音；伴奏：单薄钢琴不加混响；风格：民谣叙事/治愈系忧伤；制作笔记如「钢琴弹得笨一点、左手只弹根音 Do-So-Do-So」）。

要逐条提示词，只能去它的共享画布 `workrally.qq.com/toolbox/canvas/9m043p8x7sdsztvtqrxv15j`（文章给的）或对截图做 OCR。**本次没做。**

## 4.2 文章没给分镜方法论

只说「根据剧本制作每个分镜的动画视频」「镜头数量太多不逐一详述」，细节全指向共享画布。
**所以：能复用的是「资产库 + 参考主体 + 多接口抽卡 + 禁 BGM」这套动画生成范式，不是「剧本怎么切分镜」的规则。** 后者我们还得自己解决。

# 五、对 YLCraft 的取舍

## 采纳

| 采纳 | 怎么用 |
| --- | --- |
| ✅ **四段流水线当导航骨架** | 剧本创作 → 资产库 → 批量制作 → 智能剪辑。我们的画布原型该按这个顺序自检：能不能从剧本一路走到剪辑 |
| ✅ **资产库 = 生成时的输入，不是仓库** | `asset_hub` 要能以「参考主体」的身份被调用。这是我们目前最大的形态差距 |
| ✅ **音色入库** | 角色资产不只形象，还有音色样本 |
| ✅ **「跨镜头复现」是入库判据** | 非人角色（龙）、道具、场景，只要复现就入库 |
| ✅ **先参考搜索再出图** | 出图前先查实物参考，防常识错误（季节、比例、材质） |
| ✅ **模板流通单位 = 画布** | 台账 #7 的直接答案：一键复制整张画布 |
| ✅ **Skill 商店排序信号 = 使用次数** | 台账 #11 的直接答案 |
| ✅ **生成片段统一禁 BGM** | 音乐留到最后一环统一做 |
| ✅ **无声模型 → 参考主体补音效** | 两段式串模型的通用套路，不限于视频 |

## 不采纳 / 不适用

| 项 | 原因 |
| --- | --- |
| ❌ WorkRally 本身 | 腾讯的闭源平台，**我们接不进来，也不该接**。只借方法论和形态 |
| ❌ 它的「专家 Agent」（广告营销/短剧营销） | 那是对外营销场景，我们是自用创作工具，不做运营 |
| ❌ 作品广场 / 发布作品 | 自用定位，不做社区分发 |
| ⚠️ 智能剪辑这一段 | 我们完全没有。这是**真空白**，但要不要做、做到什么程度，需要你定 —— 不是这次调研能决定的 |
