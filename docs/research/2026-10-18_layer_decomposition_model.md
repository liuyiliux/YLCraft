## 一、Lovart 的拆分到底给了什么（一手截图）

### 菜单三层

```
图层拆分 ›
    ├─ 自动拆分      ⚡5
    └─ 自定义拆分    ⚡8/层
```

### 拆解过程

点完出现 **「图层分离中」** 状态，右侧生成一张模糊占位，原图 `2160 × 3840`。

### 拆解结果（关键）

三张图并排：

| 位置 | 内容 |
| --- | --- |
| 左 | **原图**（拍平的海报） |
| 中 | **背景层** —— 🔴 **文字被抹掉了**：红章变成空白椭圆、大标题消失、底部图标变成灰圆点，**并用周围纹理补好了** |
| 右 | **文字层** —— 透明底，只有 奉天逸洋 / 朝牌 / 老面烤饼 / 传统烤饼·老面发酵 / 酥香可口 麦香浓郁 |

**所以它做的是三件事：**
1. **文字检测**
2. **inpaint 把文字从背景里抹掉并补洞**
3. **文字单独成透明层**

> 🔴 **注意中间那张**：它不是"挖空留白"，是**把洞补成了完整背景**
> （红章位置被补成了干净的深红椭圆，底部图标位被补成了底色）。
> **这就是"分层"和"抠图"的区别。**

## 二、🔴 底层模型：Qwen-Image-Layered

**用户猜的"混元"方向对，但具体是阿里的 Qwen。**

| 项 | 值 |
| --- | --- |
| 项目 | **`QwenLM/Qwen-Image-Layered`** |
| Star | **2,141** |
| 许可 | ✅ **Apache-2.0（可商用）** |
| 发布 | 2025-12-19 |
| 论文 | arXiv **2512.15603**（CVPR 2026） |
| 能力 | **一张 RGB 图 → N 张 RGBA 透明层** |

### 它凭什么能做

三个关键设计（论文术语）：
- **RGBA-VAE** —— 统一 RGB 输入和 RGBA 输出的表示
- **VLD-MMDiT** —— 支持**可变层数**（不同图拆成不同层数）
- **多阶段训练** —— 从**真实 PSD 文件**里抽层做训练数据

### 用法

```python
from diffusers import QwenImageLayeredPipeline
pipe = QwenImageLayeredPipeline.from_pretrained("Qwen/Qwen-Image-Layered").to("cuda", torch.bfloat16)
out = pipe(image=Image.open("x.png").convert("RGBA"),
           layers=4, resolution=640, num_inference_steps=50, true_cfg_scale=4.0)
# out.images[0] = 一组 RGBA 层，index 0 = 背景，从下往上
```

**输出契约**：N 张 RGBA PNG，**index 0 = 背景**，由下往上排。
**可递归**：任一层可以再拆。

### ⚠️ 跑不动

**权重 57GB+**。有实测报告：Colab T4 直接 OOM，磁盘吃到 90GB。
**本机绝无可能，只能走云端 API。**

## 四、🔴🔴 最重要的发现：这条路有质量天花板

这是那份研究报告里最值钱的部分（标为**二手，但对方做了真金实测**）。

### 4.1 CVPR 2026 盲评结果（来自 MRT/Canva Research）

> **Lovart 在"拆解质量"上排最差（poor decomposition quality）。**
> RoboNeo 有伪影。
> Qwen-Image-Layered / LayerD 会**过度合并图层**。
> 质量最强的 **MRT**（20B）是**纯研究，无代码无权重无 API，今天用不了**。

> ⚠️ 注：这个盲评由 MRT 作者发布，**含自评偏向**，但方向可信。

### 4.2 为什么有天花板（原理性）

> **拆"已经拍平的图" = 逆向去烘焙。**
> 影子、头发/毛发/玻璃/动态模糊的软边、反光、重叠纠缠——
> 这些信息在拍平那一刻就已经糊在一起了，**再聪明的模型也只能猜，必出残影/糊边**。

### 4.3 实测边界（对方花的真钱，~$1.15 / 28 次生成）

| 能力 | 结果 |
| --- | --- |
| 多元素拆解（角色+灯+海报+墙） | ✅ **优**：干净拆成各独立透明层 |
| **文字作为元素隔离** | ✅ **成**：标题独立成层，可挪可替换 |
| 画面内移动元素 | ✅ **优**：光照一致、背景自愈、**无鬼影** |
| 删除元素→背景自愈 | ✅ **优** |
| 层数无损可复原 | ✅ 成（n=2/4/6/8 叠回都还原） |
| **双人分离** | ⚠️ **要调高 n**：n=5 把人并进背景，**n=8 才分开** |
| **遮挡补全** | ⚠️ **有限**：被挡的身体下半部补不全 |
| **分辨率** | ⚠️ **天花板**：输入 896×1200 → 分层后降到 **544×736** |

**后两条要特别注意**：
- 拆完会**掉分辨率**（长边只剩 ~0.6x），**必须后接超清**
- 多人场景**默认要用高层数**

## 五、🔴🔴 那"改字"呢？不需要新模型

研究报告里一个很关键的发现：

> 「用 **nano-banana** 直接说'把 RONIN 改成 SHOGUN，字体/金属质感/位置/其余全不变'，
> **效果惊艳**。
> → Lovart 的改字能力 = **定向改图，已在手**，**不需要拆文字层、不需要新模型**。」

**也就是说：**

| 需求 | 真需要分层吗 | 更省的解法 |
| --- | --- | --- |
| **改掉图里的字** | ❌ 不需要 | 直接让改图模型"改这个字，其他不变" |
| 挪文字位置 | ⚠️ 需要 | 分层或直接重画 |
| 换背景 | ✅ 需要 | 分层 |
| 挪人物站位 | ✅ 需要 | 分层 + 重打光 |

## 六、🔴 对 YLCraft 的判断：我们该 compose 还是 decompose

那份研究给 Nomi 的结论，对我们**同样成立，而且更强**：

> **Lovart 必须 decompose，是因为它的用户上传的是已拍平的成品图。**
> **我们是生成工具——不必先烘焙再拆，可以从一开始就让元素分开生成、各自成层。**
> **没烘焙过 = 没有残影/糊边 = 天然接近完美。**

### 我们三个场景分别该用哪条

| 场景 | 输入是什么 | 建议 |
| --- | --- | --- |
| **短剧分镜**（我们主战场） | 我们自己生成的 | 🔴 **compose**：角色/背景分开生成，天然分层 |
| **COSER 精修** | 用户上传的实拍/成片 | **decompose**（只能拆，但要诚实标注质量） |
| **摄影后期** | 用户拍摄的原片 | 一般不需要分层，直接调色 |

### 具体建议

**1. 短剧线走 compose（质量上限高、还省钱）**
- 生成分镜时角色用**透明底**单独出（`nano-banana-2-transparent` 一类）
- 背景单独生成
- 画布上天然两层 → 角色可挪站位、跨镜复用
- **完全不花拆分的钱**

**2. COSER 线走 decompose（$0.03–0.05/张，可接受）**
- 接 Replicate `qwen/qwen-image-layered`（$0.03 更便宜）
- **必须做两件事**：拆完自动超清、多人场景默认高层数
- **UI 上要诚实**：「拆解可能有残影，尤其影子和毛发」

**3. 改字不要拆层**
- 直接调改图模型「只改这个字，其他不变」
- 我们已经有 image-edit 通路

## 七、成本对照

| 动作 | 单价 | 我们的承受度 |
| --- | --- | --- |
| 拆分层（Replicate） | **≈ $0.03/张** | ✅ 便宜 |
| 拆分层（fal） | ≈ $0.05/张 | ✅ 便宜 |
| Lovart 自动拆分 | ⚡5（≈$0.05?） | 它自己的定价 |
| 改字（改图模型） | ≈ $0.034/张 | ✅ |

**结论：拆分本身很便宜（3-5 美分），贵的是后续的超清和重试。**

## 八、我建议的落点

```
短剧分镜（主路）
   └─ compose：角色透明底生成 + 背景单独生成
      → 天然分层，零拆分成本，无残影
      ← 这条最该先做

COSER（辅路）
   └─ decompose：qwen-image-layered @ Replicate ($0.03)
      → 后接超清 + 高层数 + 诚实提示
      ← 第二条做

改字（任何场景）
   └─ 不拆层，直接改图模型
      ← 最省，先做
```
