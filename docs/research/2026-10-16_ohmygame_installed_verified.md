## 二、🔴 文档没写、但我看到的三个东西

### 2.1 它有插件市场（README 完全没提）

```
data/plugins/installed/marketplace/ohmygame/img2threejs/1.5.1/
  ├─ assets  docs  forge  grimoire  integrations  scripts  skills  CHANGELOG.md  CLAUDE.md
```

**`grimoire/`、`forge/`、`integrations/` 这套目录命名我第一次见。**
它还内置了 `pi-agent/skills/plugin-creator/SKILL.md` —— **它自带一个"造插件"的 skill**。

### 2.2 服务商入口不是统一的

| 服务商 | 登录（OAuth） | API 密钥 |
| --- | --- | --- |
| OpenAI / Anthropic / OpenRouter | ✅ 有 | ✅ 有 |
| **Google / DeepSeek** | ❌ **没有** | ✅ 有 |

**README 只说「可以直接登录已有订阅」，没说哪些支持。实测发现只有 3 家支持 OAuth。**

### 2.3 首屏那个框的完整结构

```
今天想做点什么?
┌────────────────────────────────────────────────────┐
│ 描述你想做的游戏…                                    │
│ +  新文件夹▾   🌐 网页游戏▾     没有语言模型 ▾    ↑  │
└────────────────────────────────────────────────────┘
+ 从空白开始
```

🔴 **「没有语言模型 ▾」是常驻在下拉框里的**，不是报错弹窗。
发送键灰色不可用。**这是"状态透明"的做法。**

## 三、真实界面（截图实测）

### 3.1 引导第 2 步：选服务商

- 标题「**选择你的服务商。**」
- 搜索框（带 `+` 加自定义接口）
- 5 个带 logo 的服务商，右侧是 `登录` / `API 密钥`
- `更多服务商 (36)`
- 底部：**「开始创作」（灰色）** + 「**跳过并开始**」

### 3.2 主界面（首页）

**左栏（两段）**
```
首页 / 项目 / 素材库 / 社区
── 工作室 ──
网页游戏 / 互动故事 / Godot / 素材画布 / 通用游戏
──
登录 / ⋯
```

**主区**
- 大标题「**今天想做点什么？**」← 不是"新建项目"
- 一个输入框（同 §2.3）
- 「从空白开始」次级入口
- 「最近的项目 → 还没有项目」
- 「**探索**」区：4 张社区作品缩略图，每张带「**试玩**」按钮

### 3.3 素材画布入口

- 一个带网格纹理的虚线大框：`+ 新建素材画布 / 从空白工作流开始`
- 「**快速开始**」：🔴 **两个维度分开**
  - **媒介**：图像 / 视频 / 3D
  - **模型**：GPT Image 2.5 / Nano Banana 2 / Seedance 2.0 / Seedance 2.5
- 「最近的画布 → 还没有素材画布」

> 💡 **先选媒介、再选模型**，是两个独立维度 —— 跟海螺/可灵"一行 chip 里混着模型+参数"是不同思路。

## 四、验证 / 未验证的结论

### ✅ 升级为「直接证据」

| 结论 | 依据 |
| --- | --- |
| 「一个输入框 + 左下角常驻状态」是行业收敛形态 | OhMyGame 与即梦/可灵/海螺**完全一致** |
| **缺依赖时要"明示缺什么"，不要只报错** | 三个下拉空着 + 「没有语言模型」常驻 |
| 服务商选择要在**第一步**就做，且允许跳过 | 引导第 2 步实测 |
| 媒介与模型是**两个独立维度** | 画布入口实测 |
| 存档状态要常驻 | `✓ 已保存` |

### ⚠️ 仍未能验证（诚实记录）

| 结论 | 为什么没验到 |
| --- | --- |
| 「画布卡片显示**实时缩略图**」 | **没有模型 → 生成不出内容**，卡片是空的 |
| 「Agent 试玩→发现→修复→再试」 | 同上 |
| 「**没有 inspector**，在预览上指/画」 | 只进了素材画布，**没进 Scene Workbench** |
| 「选中节点高亮上下游」 | 没连过线 |
| 「双术语对照表」 | 需要进互动故事编辑器 |
| 多项目/撤销重做/JSON 导入导出 | 未逐个测 |

> **诚实结论**：我拿到了**布局和空状态下的界面**，
> **但没拿到"有内容时"的界面** —— 而后者才是设计的关键。

## 五、这一轮的方法论收获（可复用）

**装 Electron 应用并读它的 DOM：**

```powershell
# 1. 用 --remote-debugging-port 启动（无需改代码）
Start-Process OhMyGame.exe -ArgumentList "--remote-debugging-port=9222"

# 2. 拿到页面的 CDP 地址
Invoke-RestMethod "http://127.0.0.1:9222/json"

# 3. 用 node + WebSocket 发 Runtime.evaluate / Page.captureScreenshot
```

**意义**：以后遇到任何 Electron 桌面应用，**都能这样看真实界面**，
不用再依赖文档描述或二手评测。
