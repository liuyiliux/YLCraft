# YLCraft 收敛版验收方案

这份方案用于下一台电脑或其他 AI 接手后的快速验收。不要使用 Codex 内置浏览器；页面验收使用外部 Chrome/Patchright。

## 1. 数据库与启动

在 `backend` 目录执行：

```powershell
 .\venv_win\Scripts\python.exe ..\tools\check_migration_state.py --json
```

预期：返回 `state=current`，当前版本为 `008_add_project_publish_records`。启动服务后不应自动执行 `create_all`、`ALTER TABLE` 或 `stamp`。

## 2. 后端回归

```powershell
 .\venv_win\Scripts\python.exe -m pytest tests/test_agent_center.py -q

先单独执行 Agent 中心，必须看到完整收集结果；不能只运行其中少量测试。
该文件的 agent_session fixture 使用临时 SQLite，并创建所需表，不应连接正式 PostgreSQL。若输出显示只收集少量测试，检查 pytest 参数、测试文件路径和 testpaths，不要据此宣称 Agent 已通过。

其余后端回归再执行：
 .\venv_win\Scripts\python.exe -m pytest tests -q
```

重点关注：Agent 多轮上下文；创作项目和连续性事实；提示词参考库；异步生图任务、轮询、入库和诊断；Asset Hub CRUD 与血缘；番茄客户端离线行为。

当前已知基线：Agent 106 passed，Asset Hub focused 30 passed。若全量仍失败，先记录失败文件和首个 traceback；不要直接修改生产数据库或回滚迁移。

## 3. 前端静态检查

```powershell
cd frontend
npx tsc --noEmit
npm run build
```

预期：无 TypeScript 错误，构建成功。chunk 体积提示不作为失败。

## 4. 外部浏览器人工验收

启动前后端后，用外部 Chrome/Patchright 检查：

1. `/agent`：新建对话，连续发送两条互相引用的消息；刷新后继续第三条，确认 thread、消息和上下文仍在。
2. `/story`：创建项目，生成大纲、章节规划和正文；确认项目内容、章节数量和正文版本一致。
3. `/prompt-library`：本地筛选标签、切换多图、打开详情；确认不因筛选重复请求远程数据。
4. `/canvas`：创建文本、Prompt、图片、图片处理和生图节点；确认端口可连线、类型匹配、运行 trace 可见、图片结果可回流 Asset Hub。
5. `/assets`：确认图片/视频/文本分页加载，筛选条件彼此独立，图片预览和多图切换正常。
6. 设置页：确认文本、图片生成、图片编辑和视频模型从已配置连接器选择，并传入实际运行请求。

## 5. 真实供应商验收

- 使用可用图片连接器完成一次文生图，确认任务完成、结果入 Asset Hub、项目关联和 `derived_from` 血缘存在。
- 使用可用视频连接器完成一次分镜视频生成，确认结果回流原项目。
- 使用番茄登录 Cookie 发布测试章节；失败时只保留脱敏日志，不提交 Cookie、Token 或远程返回原文。

## 6. 验收边界

- 远程 PostgreSQL 是正式数据库，禁止测试中执行 `create_all`、删表、`git reset --hard` 或 `alembic stamp` 冒充升级。
- 真实供应商失败属于外部依赖，不应误判为本地代码失败。
- 每次改 API、数据库、Agent Tool 或 Skill 后，必须同步架构文档、API 清单、相关 OpenSpec 和测试。
当前已知基线：Agent 106 passed，Asset Hub focused 30 passed。若全量仍失败，先记录失败文件和首个 traceback；不要直接修改生产数据库或回滚迁移。若测试意外连接远程 PostgreSQL，应立即停止并检查环境变量。
