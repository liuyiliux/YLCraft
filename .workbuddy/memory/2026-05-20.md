## 关键发现

### 1. 弹幕（Danmaku）≠ 字幕（Subtitle）
- **弹幕**：B站核心特色，用户实时发送的飘屏评论，使用 **gRPC + Protobuf** 协议
- **字幕**：视频底部台词/翻译，YLCraft 已有（`services/subtitle/`）
- **YLCraft 现状**：完全没有弹幕功能，这是最重要的差异化功能

### 2. B站高清视频下载需要 WBI 签名
- 4K/8K/HDR 视频需要通过 `https://api.bilibili.com/x/player/wbi/playurl` 获取 DASH URL
- 需要 **WBI 签名算法**（B站反爬机制）
- YLCraft 目前可能只支持普通 MP4 格式

### 3. BiliTools 登录认证完整
- 支持：二维码登录、短信登录、密码登录、Cookie 刷新
- API 端点：`https://passport.bilibili.com/x/passport-login/web/...`
- 使用 HMAC-SHA256 对请求签名（`XgwSnGZ1p` 为 key）

## 技术决策记录

### ADR-001: B站弹幕功能实现方式
- **决策**：使用 gRPC + Protobuf 调用 B站 `dm.v1.Dm` 服务
- **理由**：B站弹幕 API 使用 Protobuf 编码，REST API 无法获取
- **参考**：`SocialSisterYi/bilibili-API-collect` 仓库的 proto 定义
- **风险**：需要研究 B站 gRPC 认证机制（可能需要特殊 Header）

### ADR-002: 不开源协议选择
- **决策**：YLCraft 不使用 GPL 协议，避免被 BiliTools "感染"
- **理由**：BiliTools 使用 GPL-3.0-or-later，直接复制代码会导致 YLCraft 必须开源
- **替代方案**：研究功能思路，自己重新实现代码
