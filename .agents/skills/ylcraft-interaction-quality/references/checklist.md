## 交付前检查清单

改完界面 / Agent / 生成链路，逐条过：

**产物呈现**
- [ ] 工具返回的对象里，有"用户会回头再看"的内容（url/path/图/视频）→ 必须渲染
- [ ] 图像/视频结果在界面上**可见**，不是文字摘要
- [ ] 点得开大图 / 能存进素材库
- [ ] 没有把对象压成 `返回字段：xxx、yyy` 这种占位文字

**🗣 说人话（最容易跳过，但最影响"在不在点"）**
- [ ] 界面上**没有内部术语**（`source_node_id` / `relation: sequence` / 字段名列表）
- [ ] 按钮/菜单名是**用户会说的话**，不是系统模块名
- [ ] 关键概念有**一句文案**帮用户判断，而不是只给一个 key

**风格/场景定义**
- [ ] 有**编号**（能直接引用，不用描述）
- [ ] 有**一句 evocative 文案**（帮用户挑，不是只给名字）
- [ ] 喂模型的提示词是**中英双名**（模型认英文）
- [ ] 定义里含**负向约束**（"避免什么"），不只说"要什么"

**画布 / 依赖可视化**
- [ ] 节点卡片上能看到**实际产出**（缩略图/预览），不是抽象图表
- [ ] 选中节点时**高亮上下游**
- [ ] **断链有标记**（指向不存在的东西要能被看见）
- [ ] 共享组件**不单独占一张卡片**（避免噪音）

**🎚 验证状态（写文档/汇报时必答）**
- [ ] 本次改动到了 **L0~L4 哪一级**？（见「元规则」五级表）
- [ ] 只到 L1/L2 时，文案里写了**「未验证」**吗？
- [ ] L3（跑通）与 L4（用户认可）**分开报**了吗？

**错误与状态**
- [ ] 错误信息说人话，**不出现 SQL / 堆栈 / 异常类名**
- [ ] 错误旁边有可操作的下一步（重试/修复/换模型）
- [ ] 生成中/失败/成功三种状态都明确

**确认流程**
- [ ] 同页面同一动作**只有一个**按钮
- [ ] 待确认项绑定**当前**对话，不串台
- [ ] 点确认后状态**真的变化**（用后端 assets/logs 独立验证，别只看界面）

**一致性**
- [ ] 生成请求是否**自动带入**角色卡/风格/参考资产
- [ ] 用户是否需要**重复描述**同一个角色

**等待**
- [ ] 生成期间用户能做别的（或能批量排队）

**参数诚信**
- [ ] 界面显示的参数都**真的生效**
- [ ] 实际用了哪个供应商/模型**可见**

**真实性与诚实**
- [ ] 展示/宣传类内容用的是**真实产出**，不是 AI 编的假界面
- [ ] AI 判断不了的（如好不好听、好不好看）**交回给人**
- [ ] `未知` / `确认不存在` / `不适用` 三种状态**没有混成一个"无"**
