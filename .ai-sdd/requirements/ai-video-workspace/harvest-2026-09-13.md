## 二、术语与业务对象（2 项 ✅ 新增）

| 术语 | 定义 |
|---|---|
| **视频任务账本（`VideoGenerationTask`）** | 与图片（同步快操作）不同，视频是**异步长任务**：提交立即返回 `task_id` 与 `status=pending`，轮询 `GET /videos/tasks/{id}` 取终态；账本保留请求/结果/状态/Asset Hub 与可选项目溯源 |
| **能力约束（capabilities / constraints）** | 后端在 `/videos/backends` 声明每个 provider 的**真实约束**（`max_duration`、`supported_durations`、`supported_resolutions`、`supported_aspect_ratios`、`image_requires_public_url` 等），前端据此**禁用不支持的控件**而非让用户试错 |

---

## 三、业务规则（4 项 ✅ 新增）

| 规则 | 内容 |
|---|---|
| **提交不阻塞** | `/videos/generate` 立即返回 provider 任务 id，不等待完成；这是与图片生成（同步）最本质的区别 |
| **终态轮询只入库一次** | 终态时把本地视频导入 Asset Hub **且仅一次**，并保留项目谱系 |
| **项目谱系用 `role=output`** | 与生图路径的 `role=generated` **不同名**（见下方易错点） |
| **能力约束由后端声明、前端口径一致** | 前端不得自行假定支持哪些时长/分辨率/比例，必须以 `/videos/backends` 的 `constraints` 为准 |

## 四、API（1 项 ✅ 新增）

```text
GET  /api/v1/videos/backends              可用视频后端 + capabilities/constraints
POST /api/v1/videos/generate              异步提交（立即返回 task_id）
GET  /api/v1/videos/tasks/{task_id}       轮询状态
GET  /api/v1/videos/history               历史与待处理任务
GET  /api/v1/videos/tasks/{task_id}/file  播放已下载的视频文件
```

`VideoGenerateRequest` 支持项目上下文：`project_id` / `content_id` / `chapter_number` /
`source_index` / `source_type` / `source_title` / `production_plan_id` / `production_node_id` / `planning_summary`。

## 六、工程约束与踩坑（5 项 ✅ 新增）

1. **视频的项目 `role` 是 `output`，不是 `generated`**。实测视频生成完成后，`GET /creative-projects/{id}/assets` 返回 `role=output` + `relation=derived_from`。**按 `role=generated` 断言会误判"没有谱系"**（本项目首次跑就踩到）。生图路径才是 `generated`。
2. **`useWebSocket` 曾硬编码 `wss://`**（`frontend/src/hooks/useWebSocket.ts`），开发环境页面与后端都是明文 HTTP，握手必然失败（`ERR_SSL_PROTOCOL_ERROR`），**实时任务进度在本地静默失效**。受影响页面：任务中心 `/tasks`、`/video-gen`、Live2D。**WebSocket 协议必须跟随页面协议**（同库 `api/comfyui.ts`、`pages/accounts/index.tsx` 已是正确写法）。
3. **Agnes 的 `image_requires_public_url=true`**：图生视频需要首帧**公网可达**；本地 `127.0.0.1` 不行（与 3D 绑骨同理）。**文生视频无此约束**，是本地验证的最省事路径。
4. **视频文件校验用 `ftypisom` 魔数**：`GET /videos/tasks/{id}/file` 返回的前 12 字节为 `ftypisom`，可据此确认是合法 MP4，不必下载整个文件。
5. **真实视频生成耗时可观**：Agnes 文生视频 5s / 720p 实测 **75 秒**完成，轮询间隔 10s 较合适。
