## 三、业务规则与校验逻辑（5 项 ✅ 新增）

| 规则 | 内容 |
|---|---|
| **提示词引用不自动入素材库** | 选中/插入提示词引用**不会**自动成为 Asset Hub 条目；只有**生成的图片**才入资产中枢并带谱系 | 任务 #23 |

## 四、API 知识（1 项 ✅ 新增）

| 端点 | 关键参数 / 用途 |
|---|---|
| `GET /api/v1/image-prompts/sources` | 来源列表（含同步状态、上次同步时间） |
| `GET /api/v1/image-prompts/references` | 检索：**`keyword`**（title/prompt/category）、`tag`、`category`、`source_id`、**`model_group`**、`page`、`page_size`（≤100） |
| `GET /api/v1/image-prompts/references/{id}` | 详情（含多图） |
| `POST /api/v1/image-prompts/references/{id}/save-as-asset` | 存为素材 |
| `POST /api/v1/image-prompts/references` | 用户自建引用 |
| `GET /api/v1/image-prompts/media/{source_id}/{item_id}/{filename}` | 缓存提示词图片的本地媒体端点 |

- **Agent 侧**：读工具（search / detail / source 列表）+ 显式写工具（refresh、save-as-asset），风险分级在任务 #12/#13 落地。
- **参数名陷阱**：检索关键词参数是 **`keyword`**，不是 `q` / `search` / `query` / `text`——用错名字会被**静默忽略**并返回全量结果，极易误判为"过滤失效"。

## 七、工程约束与踩坑（5 项 ✅ 新增）

1. **大数据量标签筛选要走 PostgreSQL JSONB 聚合**：避免 Python 侧冷扫描；分面建议必须基于**全量过滤结果集**而非当前页（任务 #40、#40.1、#40.4）。否则分面会随翻页漂移。
2. **非法 `model_group` 被静默忽略**：`model_group=nanobanana`（小写、非规范值）返回**全量**结果而非空集或 400。**建议**：非法枚举值应返回空集或校验错误，否则"过滤已生效"的错觉会导致误判数据。
3. **测试选择器会过时**：任务 #42 记录的画布选择器 `[data-canvas-open-node]` **在当前源码已不存在**，实际是 `data-canvas-node-id` / `data-canvas-node-title` / `data-canvas-node-type`。**引用测试选择器前必须在源码里复核**，否则 smoke 会假失败/假通过。
4. **`npm run smoke:pages` 是源码 marker 扫描**，不挂载页面也不启动浏览器；真实 UI 验证须用 `patchright` + Chromium。
5. **缓存媒体本地优先**：有本地缓存时优先用本地 URL，远端 URL 仅兜底——避免上游链接失效导致图库大面积空白。

## 八、设计决策（3 项 ✅ 新增）

| 决策 | 理由 | 被否决的方案 |
|---|---|---|
| **提示词库与 `PlatformTemplate` 分离** | 平台模板是"发布格式模板"，提示词库是"创作素材"；混在一起会让两者语义都被污染 | 复用 `PlatformTemplate` 存提示词 |
| **提示词引用不进素材库** | 素材库是**项目产出**的记忆；提示词是**输入素材**，自动入库会淹没产出 | 插入引用即入 Asset Hub |
| **同步默认本地优先** | 远端仓库不稳定且易触发限流；本地已有数据应可直接用 | 每次刷新都打远端 |
