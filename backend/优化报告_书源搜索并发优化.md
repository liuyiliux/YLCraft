**修改位置**: `book_source_manager.py` 第451-531行

**优化内容**:
- 将串行搜索改为并发搜索
- 使用 `asyncio.Semaphore` 控制并发数（默认10）
- 参考 Legado 的 `mapParallelSafe` 实现

**性能提升**:
- 之前：154个书源需要 7-12分钟（一个接一个）

**代码示例**:
```python

    semaphore = asyncio.Semaphore(max_concurrent)
    
    async def search_with_semaphore(source):

            results = await self._search_single_source(source, keyword)
```

### 3. 超时 + 重试逻辑（参考 Legado withTimeout + retry）
**修改位置**: `_search_single_source()` 方法（第533-582行）

**优化内容**:
- 可配置超时时间（默认30秒，与 Legado 一致）
- 可配置重试次数（默认3次）
- 指数退避重试（1秒、2秒、4秒...）
- 对403/429/503/504等错误特殊处理

**重试逻辑示例**:
```python
for attempt in range(max_retries):
    try:
        # 发起请求
        response = await client.get(search_url, headers=headers)
        # 处理响应
        return results
    except httpx.TimeoutException:
        print(f"请求超时 (尝试 {attempt + 1}/{max_retries})")
        await asyncio.sleep(1 * (attempt + 1))  # 指数退避
        continue
    except httpx.HTTPStatusError as e:
        if e.response.status_code == 403:
            print(f"HTTP 403 被拒绝，可能需要登录")
            return []  # 403 不重试
        elif e.response.status_code in [429, 503, 504]:
            await asyncio.sleep(2 * (attempt + 1))  # 重试
            continue
```
