## ⚠️ 关于引入的第三方混淆 JS（安全审查已做）

抖音评论**必须** a_bogus 签名。决定性对照（同一 cookie/视频/时刻）：

    不带 a_bogus → HTTP 200，**响应体 0 字节**
    带 a_bogus   → HTTP 200，19 条评论

用的是 MediaCrawler 的 `libs/douyin.js`（15KB）。
因为它是**混淆 JS**（肉眼无法确认行为），引入前做了静态审查：

| 检查项 | 结果 |
|--------|------|
| 网络请求（XMLHttpRequest/fetch/sendBeacon/WebSocket） | **0** |
| 文件/系统（require/child_process/fs/process） | **0** |
| 动态执行（eval / new Function） | **0** |
| DOM/全局（document/window/navigator/localStorage） | **0** |

结论：**纯计算**（RC4/SM3 加密 + 签名拼接），不联网、不读文件、不执行命令。
与 2026-09-26 拒绝的 528KB `dy_ab.js` **不是同一个文件**（这份小 35 倍）。
审查结论写进了 `douyin/sign.py` 的 docstring。

运行时用 `py_mini_racer`（已装，纯 Python 绑定 V8，不需要 Node.js）。

## 实现要点（实测）

  · 最小参数集只要 `aweme_id/cursor/count/item_type` + a_bogus
  · **失败模式是 200 + 空 body**，不是错误码 → 显式判空并给明确原因
    （否则按现有重试逻辑会试 3 次全失败，看起来像风控）
  · Cookie 必需（去掉也是空响应）
  · 分页用 cursor + has_more
  · ⚠️ 与搜索不同：搜索不需要 a_bogus，评论需要（别照搬结论）
