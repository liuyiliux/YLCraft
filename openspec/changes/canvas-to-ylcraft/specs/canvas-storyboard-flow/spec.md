## ADDED Requirements

### Requirement: 分镜文本 LLM 拆分

系统 SHALL 提供「拆分分镜」能力：把文本节点中的分镜文本经后端 LLM 端点拆为镜头数组，前端生成镜头卡网格与分镜表节点；不在前端硬编码规则拆分。

#### Scenario: 拆分成功
- **WHEN** 用户对含分镜文本的节点触发拆分
- **THEN** 画布生成镜头卡（3 列网格）与一张分镜表节点
- **AND** 每张镜头卡带序号、时长、分辨率角标与景别标签（中景/特写/远景/全景…）

#### Scenario: 拆分失败
- **WHEN** LLM 端点失败或返回无法解析
- **THEN** 界面给出明确错误与重试入口，不静默、不产出半套卡片

### Requirement: 整组重跑与镜头统计

镜头组 SHALL 支持整组重跑与镜头统计（时长汇总），入口挂在画布顶栏工具带。

#### Scenario: 整组重跑
- **WHEN** 用户在工具带触发整组重跑
- **THEN** 组内未锁定镜头逐张走现有生图 API 重新生成
- **AND** 锁定镜头跳过并保持原内容（对齐 asset-canvas-loop 的锁定语义）

#### Scenario: 镜头统计
- **WHEN** 镜头组存在且工具带统计可见
- **THEN** 显示镜头数量与时长汇总，数值与卡片角标一致

### Requirement: 画布版本记录

画布 SHALL 支持版本记录：手动存一版、回到这版、删除；生成/整组重跑/跑连线图后 SHALL 自动存版，上限 12 版，超出按最旧淘汰。

#### Scenario: 回到历史版本
- **WHEN** 用户在版本记录中选「回到这版」
- **THEN** 画布节点与连线恢复为该版本内容
- **AND** 当前版本不丢失（回到历史前自动另存一版或明确提示）

### Requirement: 画布小地图

画布 SHALL 提供小地图：节点按类型着色、显示当前视口框，支持点击/拖拽导航并跟随缩放与滚动联动。

#### Scenario: 小地图导航
- **WHEN** 用户在小地图点击或拖动视口框
- **THEN** 主画布视口移动到对应区域
- **AND** 主画布平移/缩放时小地图视口框实时同步
