# 内容生产方案与导演 Agent 编排

## 背景

YLCraft 已经有独立的文本、图片、视频、3D、图片编辑、素材中枢、创作画布和创作项目能力。当前缺少一层稳定的“内容生产方案”协议，导致短剧、漫画、绘本、科普和平台图文容易被误解为互相独立的页面或固定流水线。

同时，外部成熟实践通常由一个导演型 Agent 负责理解目标，再组合编剧、分镜、视觉、角色、平台适配等 Skill，和用户通过对话共同推进。YLCraft 已具备 Agent Supervisor、Team Template、Writer Room 和任务观测基础，需要把这些能力收敛到内容生产场景。

## 目标

1. 保持所有基础能力可独立使用，结果通过 Asset Hub、任务中心和血缘关系回流。
2. 用可配置的 `ContentProductionProfile` 描述短剧、故事漫画、童话绘本、科普内容、平台图文、小说等方案，而不是把每种内容硬编码成新的页面。
3. 允许用户通过导演 Agent 对话推进：提出目标、确认计划、生成脚本、生成视觉参考、批量生产和审核。
4. 将图片/视频生成中的“规划摘要、参考资产、提示词、模型参数、输出版本”结构化保存，不暴露或依赖不可审计的隐藏思维链。
5. 将 `watermarks-remover` 作为可选的本地 AI 来源标记/文件元数据清理 Skill，明确只处理用户拥有或获授权的内容。

## 非目标

- 不把小红书等平台再做成新的内容生产线；它们属于输出适配器，复用现有多平台生图与图片编辑器。
- 不默认强制经过正文、细纲或完整小说阶段。
- 不在第一阶段实现通用“清除画面品牌水印”的视觉修复模型；外部项目主要处理 AI provenance marks、Unicode/文本标记及文件元数据。
