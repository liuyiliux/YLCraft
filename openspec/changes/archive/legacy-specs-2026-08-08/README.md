# Archived legacy specifications

The dated OpenSpec changes that predate the current PostgreSQL, Asset Hub and
Agent runtime architecture are retained under `openspec/archive/` for history
only. They are deliberately outside `openspec/changes/`, so the active
validator does not treat obsolete specifications as current work.

Current engineering truth lives in:

- `AGENTS.md`
- `docs/README.md`
- `docs/DESIGN.md`
- `docs/architecture/YLCRAFT_SYSTEM_ARCHITECTURE.md`
- active changes under `openspec/changes/*`

Archived files are historical evidence, not implementation status. Use git
history when an old design decision needs to be investigated.
