# 区域几何重构（region-geometry-rework）

## Why

「区域」的语义建错了。当前区域渲染为**成员据点围成的凸包**——等于把"福贵的房子"当成"村子的城墙角"：

- 据点一动，区域形状就跟着变形（形状不该由点推导）；
- 凸包画不出凹形（村子绕过山头的边界、海湾、城墙拐角都无法表达）；
- 结果是"散点 + 色块"，一点都不像"一个真实的地方"（对照 Azgaar Fantasy-Map-Generator）。

正确的层级是：**区域 = 有形状的地理范围（村子/县城/势力范围）；据点 = 区域内的一个位置（福贵的房子）**。
形状独立存在，据点只**引用**区域——与既有的「引用不复制」纪律一致。

## What

把区域从"据点围合"改为**独立几何 + 可控生成 + 手绘微调**：

1. **数据模型**：区域新增 `shape`（mode / seed / 语义参数 / 顶点 ≤64）与 `parent_id`（支持不限层嵌套）。
2. **可控生成**：形状由「成员据点 + 语义参数 + seed」经**确定性算法**展开——不是随机世界生成，
   不引入 Azgaar 的生成管线，只借鉴其有机轮廓思路（扰动 + 平滑）。同参数同 seed 必得同形状（可重放）。
3. **AI 只管语义**：AI/Agent 输出形态意象（自然 × 聚落 × 人工构筑）与参数，**不输出几何**；
   几何交给算法。触发为独立动作（用户点或 Agent 调工具），可预览、可重放。
4. **手绘微调**：顶点可拖、可增删；一旦手绘即固化为 `manual`（重新生成会提示覆盖）。
5. **层级渲染**：不限层嵌套，按深度自动算视觉权重——默认**父淡子艳**，选中提亮。
6. **据点类型扩展**：kind 从 5 种扩到 20 种，每种配内联 SVG 图标（参考 Azgaar 的 marker 分类）。
7. **数据清理**：现有 `world_maps` / `world_map_revisions` 全部清空（测试数据，不备份，已确认）。

## Impact

| 范围 | 影响 |
|---|---|
| 数据 | 区域结构变更（新增字段，旧字段保留）；地图数据全清，无需迁移 |
| 后端 | 新增区域形状生成端点 + LLM 语义推断；新增 Agent 工具（与真人共用 service）；导出与 `/render` 支持 shape |
| 前端 | 新增形状展开算法（纯函数，可单测）；画布改为渲染 shape + 层级；新增顶点编辑交互；据点 20 种图标 |
| 纪律 | 不变：结构化数据是正典、revision CAS、append-only 版本历史、Agent 工具与真人共用 service |

## 非目标

- **不做**随机世界生成（大陆/海岸线/河流）——与"结构化数据是正典"冲突，本次不涉及。
- **不做**区域形状的自动几何归属（据点落在形状内就自动改 `region_id`）——用户已选"引用为准，位置仅提示"。
- **不做**图层显示顺序拖拽、装饰笔刷等远期项。
