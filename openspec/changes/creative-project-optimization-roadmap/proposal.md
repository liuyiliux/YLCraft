# Proposal: Creative Project Optimization Roadmap

## What

基于当前创作项目闭环现状，规划下一阶段优化：角色立绘提示词、参考卡、分镜 prompt、世界观素材、批量生产队列和多智能体剧情推演。

这不是替换 `creative-project-closed-loop`，而是在现有闭环之上补充“更可控、更可追溯、更适合漫画化生产”的路线图。

## Why

当前项目已经能完成基础链路，但生成质量和可控性主要受限于：

- 角色设定没有完全资产化，立绘和后续分镜图之间的一致性不足。
- 分镜 prompt 偏文本描述，缺少 blocking、机位、场景空间、动作路线和构图结构。
- 世界观仍是大纲字段，无法像素材一样被角色、场景、分镜和智能体复用。
- 批量生成缺少清晰队列、失败续跑和人工审核节点。
- 多智能体想法还没有产品化入口。

## Goals

- 建立角色卡/立绘卡标准，使人物外观、服装、表情、姿态和禁忌项可复用。
- 将世界观拆成可关联素材：地图、规则、势力、地点、超能力/科技/金融/大事件。
- 将分镜升级为生产级 schema，支持镜头语言、blocking、参考资产和完整生图 prompt。
- 让素材库和画布成为世界观、角色、场景、分镜、图片的中枢。
- 规划角色智能体、导演/天意智能体、编辑智能体的 MVP 推演流程。

## Non-goals

- 不立即实现完整自动写整本小说。
- 不立即实现真正 3D blocking 编辑器。
- 不自建云端生成或云端素材缓存。
- 不复制参考项目 UI 或代码，只吸收工作流思想。
