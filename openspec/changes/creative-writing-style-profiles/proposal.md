# Creative Writing Style Profiles

## Why

YLCraft already has deterministic style measurements and Writer Room prose passes, but
style guidance is currently split between project fields, file-backed Skills and long
prompts. A user can ask for a more humorous, restrained or classical voice, yet there
is no versioned, reviewable object that can be extracted from a source, reused across
projects and audited by both a human and an Agent.

The first supplied article identifies industrial AI-text signals: mechanical
sectioning, forced three-part structures, abstract uplift, template transitions and
explanation replacing concrete action. The second describes style Skills as reusable
method packages that learn expression mechanisms without copying a source novel. This
change turns those principles into a product contract.

## Goals

- Make anti-template writing checks evidence-driven instead of a blacklist.
- Add a versioned `WritingStyleProfile` domain for abstract, reusable expression rules.
- Reuse source snapshots and existing style measurements without storing a source novel
  inside a prompt or style record.
- Let humans and Agents use the same preview, confirmation, activation and promotion
  boundaries.
- Keep style subordinate to project canon, character facts, scene intent and prose
  quality.
- Support importing/exporting a Markdown Skill as an interoperability format while
  keeping the internal profile as the source of truth.

## Non-goals

- No author imitation or "copy this author's voice" default.
- No storage or injection of long source excerpts, distinctive phrases, characters,
  settings, plots or chapter structures.
- No automatic activation of an extracted profile.
- No automatic replacement of approved prose or locked canon.
- No claim that a style score alone proves quality or human authorship.
